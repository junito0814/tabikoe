# F-AD-01 管理者ログイン — タスク分割

> 出典: [admin-login.md](../../../user-stories/admin/admin-login.md)

各タスクの詳細・テスト要件は個別ファイルを参照。Task 1 が土台、Task 2 は Task 1 に依存する。Task 3 は Task 1・2 の結合後に実施する。認証方式自体（Google OAuth）・`is_admin` カラムは F-AC-01 で既に実装済みのため、本ストーリーでは扱わない。

Task 4〜9 は **2026-09-29 に追加**した二段階確認（要件 3.10.1 の改訂）。Task 1〜3 は既に実装済みで、その上に積む。
