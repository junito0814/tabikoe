## 実装内容

## 成果物

- 検証結果の記録

## テスト要件

### 単体テスト
- 対象外（本タスクはE2E検証が主目的）

### 結合テスト
- 対象外（Task 1で実施済み）

### E2Eテスト
以下のシナリオを実施する。

1. `is_admin=true`のユーザーで管理者ダッシュボードを開き、「お知らせ管理」「通報一覧・対応」の2ボタンが表示されることを確認する
2. 「お知らせ管理」を押し、お知らせ管理画面（SC-17）に遷移することを確認する
3. 「通報一覧・対応」を押し、通報一覧画面（SC-18）に遷移することを確認する
4. `is_admin=false`のユーザーでダッシュボードのURLへ直接アクセスし、404が表示されることを確認する

## 関連する受入条件

- 管理者ダッシュボード（SC-16）に、お知らせ管理（SC-17）・通報一覧（SC-18）への遷移ボタンが表示されること
- 各ボタンから対応する画面へ正しく遷移できること
- `is_admin`がfalse、または未ログインの状態でダッシュボードのURLへ直接アクセスすると404が返ること
