# Task 3: 通報対応UI（SC-18・対応操作部分）

> 出典: [report-handling.md](../../../user-stories/admin/report-handling.md)
> インデックス: [report-handling](00-index.md)

## 依存

- [Task 1: 通報対応操作 Route Handler（非公開化／削除／問題なし）](01-report-action-handler.md)

## 実装内容

- 通報詳細画面（SC-18の詳細部分、report-list Task2の一覧UIから遷移）に、「非公開化」「削除」「問題なし」の対応操作ボタンと、対応理由（任意メモ）の入力欄を実装する
- 「削除」操作は復元不可であることを操作前に明示する確認ダイアログを表示する

## 成果物

- `app/admin/reports/[id]/page.tsx`（対応操作UI）

## テスト要件

### 単体テスト
- 「削除」操作時に確認ダイアログが表示され、確定操作を経ないとAPIが呼ばれないことを検証する

### 結合テスト
- テスト用DBに対して画面から各対応操作を実行し、Task1のAPIが正しいパラメータで呼び出されることを確認する

### E2Eテスト
- なし（[Task 4: 受入テスト（E2E）](04-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 通報対象に対して「非公開化」「削除」「問題なし」のいずれかの対応を実行できること
- 対応した管理者・対応日時・対応理由（任意メモ）が記録されること
