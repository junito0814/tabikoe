## テスト要件

### 単体テスト
- 対象外（本タスクはE2E検証が主目的）

### 結合テスト
- 対象外（Task 1〜3で実施済み）

### E2Eテスト
以下のシナリオを実施する。

1. 投稿への通報を「非公開化」で対応し、当該投稿が一般ユーザーから見えなくなること、および管理画面から復元できることを確認する
2. コメントへの通報を「削除」で対応し、コメントが削除され復元できないこと、通報者へアプリ内通知が送られることを確認する
3. ユーザーへの通報を「非公開化」で対応し、通報者へ通知が送られないこと、被通報者へも通知が送られないことを確認する
4. スポットへの通報を対応し、当該スポット情報が非公開化されることを確認する
5. アルバムへの通報を対応し、当該アルバムが非公開化されることを確認する
6. いずれの対応でも、対応した管理者・対応日時・対応理由が記録として確認できることを確認する

## 関連する受入条件

- 通報対象に対して「非公開化」「削除」「問題なし」のいずれかの対応を実行できること
- 「非公開化」で対応した対象が、一般ユーザーから見えなくなり、かつ復元できること
- 「削除」で対応した対象が削除され、復元できないこと。この対応の場合のみ通報者へアプリ内通知が送られること
- 「問題なし」「非公開化」の場合は通報者へ通知が送られないこと。被通報者への通知はいずれの対応でも送られないこと
- 対応した管理者・対応日時・対応理由（任意メモ）が記録されること
- ユーザー・スポット・アルバムへの通報について、それぞれ規定の対応（アカウント一時停止／スポット非公開化／アルバム非公開化）に読み替えられること
