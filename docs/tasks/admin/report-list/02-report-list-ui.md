# Task 2: 通報一覧画面UI（SC-18・一覧部分）

> 出典: [report-list.md](../../../user-stories/admin/report-list.md)
> インデックス: [report-list](00-index.md)

## 依存

- [Task 1: 通報一覧取得・絞り込み Route Handler](01-report-list-handler.md)

## 実装内容

- 通報一覧画面（SC-18）の一覧・絞り込みUIを実装する（対応状態・通報理由・対象種別・通報日時の絞り込みコントロール）
- 一覧の各行から通報詳細（対象の内容）へ遷移する導線を実装する
- 対応操作（非公開化／削除／問題なし）自体はreport-handling（F-AD-05）が実装する。本タスクは一覧・絞り込み・詳細確認までを対象とする
- 管理者ダッシュボード（SC-16）からの遷移導線に対応する

## 成果物

- `app/admin/reports/page.tsx`

## テスト要件

### 単体テスト
- 絞り込み条件のUI操作が、Task1のAPIへ正しいクエリパラメータで反映されることを検証する

### 結合テスト
- テスト用DBに対して画面から絞り込みを行い、期待した通報のみが表示されることを確認する
- 一覧から詳細への遷移が正しく機能することを確認する

### E2Eテスト
- なし（[Task 3: 受入テスト（E2E）](03-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 対応状態・通報理由・対象種別・通報日時で通報一覧を絞り込めること
- 一覧から通報対象（投稿・写真・動画・コメント等）の内容を確認する画面へ遷移できること
- 管理者ダッシュボード（SC-16）から通報一覧画面（SC-18）へ遷移できること
