## 実装内容

- 投稿詳細画面（SC-05）にコメント欄を実装する。コメント入力フォーム、コメント一覧（新着順・20件ずつ）、「もっと見る」ボタン、削除ボタン（本人のコメントのみ表示）で構成する
- コメント入力欄に4,000文字までの入力制限を表示する
- 本コンポーネントは[post-detail-view Task2](../post-detail-view/02-post-detail-ui.md)から組み込まれる想定で実装する

## 成果物

- コメント欄コンポーネント（投稿詳細画面に組み込み）

## テスト要件

### 単体テスト
- 自分のコメントにのみ削除ボタンが表示されることを検証する
- 「もっと見る」押下で追加のコメントが表示されることを検証する

### 結合テスト
- Task 1〜3のAPIと連携し、投稿・削除・ページングが画面上で正しく動作することを確認する

### E2Eテスト
- なし（[Task 7: 受入テスト（E2E）](07-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 投稿にコメントを書き込めること（全角4,000文字まで）
- コメント一覧が1回につき20件読み込まれ、「もっと見る」で追加読み込みできること
- コメント投稿者本人のみがコメントを削除できること
- コメントを編集する機能がないこと
