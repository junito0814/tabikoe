# Task 3: コメント一覧取得API（ページング）

> 出典: [comments.md](../../../user-stories/browsing/comments.md)
> インデックス: [comments](00-index.md)

## 依存

- [Task 1: コメント投稿 Route Handler（バリデーション・エスケープ処理）](01-comment-create-handler.md)

## 実装内容

- 投稿に紐づくコメント一覧を取得するRoute Handlerを実装する（例：`GET /api/posts/{id}/comments`）
- 1回につき20件を返し、カーソルまたはオフセットベースのページングに対応する
- 新着順（投稿日時降順）で返す

## 成果物

- `app/api/posts/[id]/comments/route.ts`（GET）

## テスト要件

### 単体テスト
- コメントが21件以上ある投稿で、1回目の取得が20件、2回目の取得（ページング）で残りが取得できることを検証する
- コメントが新着順で返ることを検証する

### 結合テスト
- テスト用DBで実際に複数件のコメントを作成し、ページングが正しく機能することを確認する

### E2Eテスト
- なし（[Task 7: 受入テスト（E2E）](07-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- コメント一覧が1回につき20件読み込まれ、「もっと見る」で追加読み込みできること
