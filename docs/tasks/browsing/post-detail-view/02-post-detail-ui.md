# Task 2: 投稿詳細画面UI（SC-05）実装

> 出典: [post-detail-view.md](../../../user-stories/browsing/post-detail-view.md)
> インデックス: [post-detail-view](00-index.md)

## 依存

- [Task 1: 投稿詳細取得・非公開アクセス制御 Route Handler（GET /api/posts/{id}）](01-post-detail-handler.md)

## 実装内容

- 投稿詳細画面（SC-05）を実装し、投稿の全項目（スポット名・カテゴリ・日付・滞在時間・費用・星評価・写真・動画・感想・投稿者・投稿日時）を表示する。旅行タイトルは表示しない
- 写真・動画の表示は共通レイアウト（[shared-ui/media-layout](../../shared-ui/media-layout/00-index.md)）を再利用する
- コメント欄は[comments](../comments/00-index.md)のUIコンポーネントを組み込む（本タスクでは組み込みのみ、コメント自体のロジックは対象外）
- 「行きたい」保存ボタンを設置する。押下時の保存処理は records カテゴリ（`records/wishlist`、別途作成）のAPIを呼び出す想定でボタン・導線のみ実装する

## 成果物

- 投稿詳細画面（SC-05）コンポーネント一式

## テスト要件

### 単体テスト
- 投稿の全項目が画面に表示されることを検証する（スナップショット等）
- 旅行タイトルが画面のどこにも表示されないことを検証する

### 結合テスト
- Task 1のAPIから取得したデータが画面に正しく反映されることを確認する

### E2Eテスト
- なし（[Task 4: 受入テスト（E2E）](04-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 投稿詳細画面に、投稿の全項目（スポット名・カテゴリ・日付・滞在時間・費用・星評価・写真・動画・感想・投稿者・投稿日時）とコメント欄が表示されること
- 投稿詳細画面に旅行タイトルが表示されないこと
- 投稿詳細画面から、当該スポットを「行きたい」に保存できること
