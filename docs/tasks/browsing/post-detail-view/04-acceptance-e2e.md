## テスト要件

### 単体テスト
- 対象外（本タスクはE2E検証が主目的）

### 結合テスト
- 対象外（Task 1〜3で実施済み）

### E2Eテスト
以下のシナリオを実施する。

1. 公開投稿の詳細画面を開き、全項目とコメント欄が表示され、旅行タイトルが表示されないことを確認する
2. 投稿詳細画面から「行きたい」ボタンを押し、保存導線が正しく動作することを確認する
3. アルバムメンバーとして、他メンバーの非公開投稿の詳細画面にアクセスでき、非メンバーの第三者としてアクセスすると404になることを確認する
4. 未ログイン状態で投稿詳細画面のURLに直接アクセスし、ログイン画面へ誘導され、ログイン完了後に元の投稿詳細画面へ戻ることを確認する

## 関連する受入条件

- 投稿詳細画面に、投稿の全項目（スポット名・カテゴリ・日付・滞在時間・費用・星評価・写真・動画・感想・投稿者・投稿日時）とコメント欄が表示されること
- 投稿詳細画面に旅行タイトルが表示されないこと
- 投稿詳細画面から、当該スポットを「行きたい」に保存できること
- 非公開設定の投稿が、投稿者本人・アルバムメンバー以外の他ユーザーの地図・検索結果・投稿一覧・スポット写真一覧に表示されないこと。一方でアルバムメンバーには表示されること
- 未ログイン状態で投稿詳細画面に直接アクセスすると、ログイン画面へ誘導され、ログイン完了後に元の投稿詳細画面へ戻ること
