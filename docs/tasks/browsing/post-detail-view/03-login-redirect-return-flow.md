# Task 3: 未ログイン時のログイン誘導・遷移復帰処理

> 出典: [post-detail-view.md](../../../user-stories/browsing/post-detail-view.md)、[requirement.md](../../../requirement.md) 3.5.4
> インデックス: [post-detail-view](00-index.md)

## 依存

- session-management [Task1: セッション検証Middlewareの実装](../../account/session-management/01-session-verification-middleware.md)

## 実装内容

- session-managementのMiddleware（Task1）は、未ログインリクエストを「未ログイン扱い」と判定するところまでを実装済み。本タスクでは、その判定結果を受けて「ログイン画面（SC-01）へリダイレクトし、ログイン完了後に元のアクセス先へ戻す」画面遷移の仕組みを実装する
- 元のアクセス先（パス・クエリ）をリダイレクトURLのパラメータ等で保持し、ログイン完了（OAuthコールバック処理）後にそのアクセス先へ遷移させる
- 本ストーリーでは投稿詳細画面（SC-05）を対象に実装するが、他のログイン必須画面（マップ・マイページ等、未作成のストーリーを含む）からも再利用できる共通処理として実装する

## 成果物

- ログインリダイレクト・復帰処理の共通ユーティリティ
- OAuthコールバック処理（F-AC-01）への復帰先パラメータの受け渡し統合

## テスト要件

### 単体テスト
- 未ログイン状態で投稿詳細画面のURLに直接アクセスした場合、ログイン画面へのリダイレクトURLに元のアクセス先が正しく含まれることを検証する
- ログイン完了後、保持していたアクセス先へ正しく遷移することを検証する

### 結合テスト
- 実際のCookie未設定リクエストで、投稿詳細画面へのアクセスがログイン画面へリダイレクトされることを確認する
- ログイン完了後、元の投稿詳細画面へ実際に遷移することを確認する

### E2Eテスト
- なし（[Task 4: 受入テスト（E2E）](04-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 未ログイン状態で投稿詳細画面に直接アクセスすると、ログイン画面へ誘導され、ログイン完了後に元の投稿詳細画面へ戻ること
