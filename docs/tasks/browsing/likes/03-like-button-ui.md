# Task 3: いいねボタンUI（投稿カード・投稿詳細）

> 出典: [likes.md](../../../user-stories/browsing/likes.md)
> インデックス: [likes](00-index.md)

## 依存

- [Task 1: いいね付与・取り消し Route Handler](01-like-toggle-handler.md)

## 実装内容

- 投稿カード一覧（SC-04）・投稿詳細画面（SC-05、[post-detail-view](../post-detail-view/00-index.md)）にいいねボタンを設置する
- いいね済み／未いいねの状態を視覚的に区別して表示する
- ボタン押下でTask 1のAPIを呼び出し、成功時に表示状態をトグルする

## 成果物

- いいねボタンコンポーネント（投稿カード・投稿詳細で共用）

## テスト要件

### 単体テスト
- いいね済み状態・未いいね状態それぞれで、ボタンの表示が正しく切り替わることを検証する

### 結合テスト
- Task 1のAPIと連携し、ボタン押下後に状態が正しく反映されることを確認する

### E2Eテスト
- なし（[Task 4: 受入テスト（E2E）](04-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 投稿にいいねを付与・取り消しできること
