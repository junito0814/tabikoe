# Task 1: ファビコンとホーム画面のアイコンを入れ替える

> 出典: [brand-logo.md](../../../user-stories/shared-ui/brand-logo.md)
> インデックス: [brand-logo](00-index.md)
> 要件定義書 4.5.9

## 実装内容

- `src/app/icon.svg` を新規追加する（ブラウザのタブに出るアイコン）。中身は 4.5.9 の数値どおり。
  - 【初心者向け】Next.js は `src/app/` に置いた `icon.svg` を見つけて、自動で `<link rel="icon">` を全ページに入れてくれる。自分で `<head>` を書く必要は無い
- `src/app/favicon.ico` を**削除する**。Next.js の初期状態のまま残っているもので、これがあるとブラウザが `/favicon.ico` を先に読んでしまい、追加した `icon.svg` が使われない
- `src/app/apple-icon.png` を新規追加する（180 × 180。スマホのホーム画面に追加したときのアイコン）
  - 同じ形を書き出すが、**角丸は付けず四隅まで青で塗る**。ホーム画面では iOS が自分で角を丸めるので、角丸を付けると四隅が透明のまま残り、端末によっては黒く出てしまう
  - 書き出しはヘッドレス Chrome（`--screenshot --window-size=180,180`）で 1 回だけ行い、出来た PNG を置く
- 生成に使ったスクリプトは `scripts/` に置かず、SVG の中身をそのまま `icon.svg` に書く（後から数値を直せるようにするため）

## テスト要件

### 単体テスト
- `src/app/icon.svg` が存在し、`src/app/favicon.ico` が存在しないこと（ファイルの有無の確認）
- `icon.svg` に 4.5.9 の数値（地 `#2F7FD8`・円の半径 11.5・輪の半径 22 と 30）が含まれること

### 手動確認
- ブラウザのタブにアイコンが出ること（開発サーバーを開き直して確認。ブラウザがアイコンを覚えているので、強制再読み込みが必要な場合がある）
- スマホで「ホーム画面に追加」してアイコンが出ること
