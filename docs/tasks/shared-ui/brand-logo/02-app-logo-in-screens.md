# Task 2: ログイン画面・ホームのロゴを差し替える

> 出典: [brand-logo.md](../../../user-stories/shared-ui/brand-logo.md)
> インデックス: [brand-logo](00-index.md)
> 要件定義書 4.5.9

## 実装内容

- `src/components/auth/AuthScreen.tsx` の `AppLogoIcon` の中身を 4.5.9 の形に差し替える
  - 今の中身（半透明の丸＋放射状の 3 本の線＋小さな丸 4 つ）は間に合わせで作ったもので、ファビコンと形が違う
  - この部品はログイン画面（SC-01）と未ログインのホーム（SC-00）の両方で使われているので、1 か所直せば両方変わる
- `icon.svg` と**同じ数値**を書く。形が 2 つに分かれると、タブとログイン画面で違うロゴが出てしまう

## テスト要件

### 単体テスト
- `AuthScreen`: ロゴの中に 4.5.9 の数値（円の半径 11.5・輪の半径 22 と 30）が描かれていること
- 既存の `AuthScreen` のテストが通ること（ロゴは `aria-hidden` なので読み上げ対象は変わらない）

### 手動確認
- ログイン画面と未ログインのホームで、タブのアイコンと同じ形が出ていること
- ダークモードでもロゴが背景に溶けないこと
