# Task 1: 投稿作成・編集画面への注意文表示

> インデックス: [upload-notice](00-index.md)

## 依存

- post-creation [投稿作成フォームUI（SC-03）基本実装](../../posts/post-creation/02-post-form-ui.md)
- post-edit [投稿編集画面UI（SC-03 編集モード）](../../posts/post-edit/03-post-edit-ui.md)

## 実装内容

- 写真・動画アップロードUIに、以下2つの注意文を表示する共通コンポーネントを追加する
  - 他人が写り込んだ写真・動画は、本人の同意を得てから投稿してください
  - 個人が特定できる情報（車のナンバー等）が写っていないか確認してください
- 投稿作成画面（SC-03新規作成）・投稿編集画面（SC-03編集モード）の両方に組み込む

## 成果物

- 注意喚起メッセージ共通コンポーネント（`UploadNotice`等）

## テスト要件

### 単体テスト
- コンポーネントが規定の2つの注意文をレンダリングすることを検証する

### 結合テスト
- 投稿作成画面・投稿編集画面それぞれで、写真・動画アップロードUIの近傍に注意文が表示されることを確認する

### E2Eテスト
- なし（[Task 2: 受入テスト（E2E）](02-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 写真・動画のアップロード操作時に、上記2つの注意文が表示されること
- 注意文は投稿作成・投稿編集の両方（写真・動画を追加する操作）で表示されること
