## 実装内容

- Task 1の統合後、本ストーリーの受入条件2項目を検証する

## 成果物

- E2Eテストシナリオ（手動 or 自動、Playwright等）
- 検証結果の記録

## テスト要件

### 単体テスト
- 対象外（本タスクはE2E検証が主目的）

### 結合テスト
- 対象外（Task 1で実施済み）

### E2Eテスト
以下のシナリオを実施する。

1. 投稿作成画面で写真・動画アップロードUIを開き、規定の注意文が表示されることを確認する
2. 投稿編集画面で写真・動画を追加しようとした際に、同様の注意文が表示されることを確認する

## 関連する受入条件

- 写真・動画のアップロード操作時に、上記2つの注意文が表示されること
- 注意文は投稿作成・投稿編集の両方（写真・動画を追加する操作）で表示されること
