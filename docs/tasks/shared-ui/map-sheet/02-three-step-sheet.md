# Task 2: シートを 3 段階にする

> インデックス: [map-sheet](00-index.md)

## 依存

- [Task 1](01-pinch-and-zoom-controls.md)（地図を広げても触れる状態にしてから入れる）

## 実装内容

- `MapSheetLayout` の吸い付き点を 3 つにする（地図 2/3 ／ 地図 1/3（既定） ／ 全画面）。今は地図の高さを 34dvh 固定にし、ページ先頭とシート上端の 2 点で吸い付いているので、地図の高さを段階で変える形に組み替える
- 既定は今までどおり地図 1/3。画面を開いた直後はここ
- `use-sheet-drag`: 指を離した位置から近い段階へ。速いフリックは方向に従う。取っ手の Enter／Space は次の段階へ進み、いちばん上まで行ったら既定に戻る
- 地図を広くしたとき、シートには見出しの 1 行だけを見せる（`MapSheetLayout` に `summary` を足し、4 画面それぞれが渡す）
- SC-03（投稿作成・編集）は 2 段階のまま（`steps` を指定できるようにする）。なお SC-03 は今のところ `MapSheetLayout` を使わず自前の組み方なので、`steps` は将来この部品に寄せたときのための口になる
- パソコン幅は今までどおり左右分割で、スライドは無効

## テスト要件

### 単体テスト
- 3 段階の吸い付き（近い段階へ／フリックの方向／いちばん下からさらに下へは縮まない）
- 取っ手のキーボード操作で段階が進み、いちばん上の次は既定に戻ること
- `steps` を 2 段階にすると、地図を広くする段階が無いこと（SC-03）
- 地図を広くしたときに `summary` が見え、既定に戻すと本文が見えること
