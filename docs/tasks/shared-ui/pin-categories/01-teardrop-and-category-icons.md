# Task 1: ピンをしずく型にし、カテゴリの色と記号・状態バッジを描けるようにする

> 出典: [pin-categories.md](../../../user-stories/shared-ui/pin-categories.md)
> インデックス: [pin-categories](00-index.md)
> 要件定義書 4.5.3

## 実装内容

- `pin-styles.ts`
  - カテゴリごとの色と記号の対応を足す（7 つ＋カテゴリ無し）。色はテーマ変数に載せる（`globals.css` に `--pin-food` などを追加し、`resolvePinColor` で読む）
  - 種別（`PinType`）から「形・色・記号」を出す今の作りを、「**形は全部しずく**（下書き＝破線、クラスタ＝丸）、**色と記号はカテゴリ**、**状態はバッジ**」の形に整理する
- `PinIcon.tsx` と `pin-marker-icon.ts`（画面用の React と、Google マップのマーカー用の SVG 文字列）
  - しずく型の輪郭にする。**先端が座標を指す**ので、マーカーの `anchor` を中央（16, 16）から**下端（16, 32）**に変える
  - カテゴリの記号 7 つを描く（フォークとナイフ・カメラ・山・旗・チケット・買い物袋・ベッド）
  - 右肩のバッジ（赤いハート＝保存済み、緑のチェック＝自分の投稿）を描けるようにする。バッジは 1 つだけ
  - 2 つの定義がずれないよう、今ある「両者の一致を見る単体テスト」を新しい形に合わせて残す
- `MapLegend.tsx`: 凡例は**状態だけ**にする（みんなの投稿・保存済み・下書き）。カテゴリの色は凡例に出さない（数が多く地図が埋まるため）
- `PinCallout.tsx`: 吹き出しに**カテゴリ名**を出す（凡例に出さない代わりに、ここで確かめられるようにする）

## テスト要件

### 単体テスト
- `pin-styles`: カテゴリ 7 つ＋カテゴリ無しの色と記号が 4.5.3 の表どおりであること
- `pin-marker-icon` と `PinIcon`: 同じ種別・カテゴリで同じ図形（色以外）になること（既存のテストの作り直し）
- `pin-marker-icon`: 保存済みでハート、自分の投稿でチェックのバッジが入ること。両方ならハートだけになること
- `MapLegend`: カテゴリの色が凡例に出ないこと。状態 3 つが出ること
- マーカーの `anchor` が下端になっていること（先端が座標を指す）
