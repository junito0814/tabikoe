# Task 2: スポットのカテゴリを決めて地図のピンに渡す

> 出典: [pin-categories.md](../../../user-stories/shared-ui/pin-categories.md)
> インデックス: [pin-categories](00-index.md)
> 要件定義書 4.5.3「スポットのカテゴリの決め方」

## 実装内容

- カテゴリを決める純粋な関数を作る（例: `src/lib/map/spot-category.ts`）
  - 入力はそのスポットの公開投稿の `{ category, createdAt }` の一覧
  - **いちばん多いカテゴリ**。同数なら**新しい方**（最後に投稿された方）。1 件も無ければ `null`
  - 【初心者向け】判断の中身を関数に切り出しておくと、地図やデータの取り方を変えてもここだけテストすれば済む
- `get-map-pins.ts`: ピンを組み立てるときに上の関数でカテゴリを決め、`category` をピンに乗せる
  - すでに公開投稿の一覧（星の平均を出すために取っている）があるので、**新しい問い合わせは足さない**
- `MapScreen`・`MyMapScreen`: ピンに `category` を渡す
- しおりの地図（番号ピン）はカテゴリを使わない（変更しない）

## テスト要件

### 単体テスト
- いちばん多いカテゴリが選ばれること
- 同数のときは新しい方が選ばれること
- 公開投稿が無ければ `null`（カテゴリ無しの灰色）になること
- 非公開・下書き・非表示の投稿を数に入れないこと
- `get-map-pins`: ピンに `category` が乗ること
