# Task 1: ピン種別ごとのアイコン・色定義

> 出典: [pin-display-rules.md](../../../user-stories/shared-ui/pin-display-rules.md)
> インデックス: [pin-display-rules](00-index.md)

## 依存

なし（土台タスク）

## 実装内容

- 通常／「行きたい」／投稿済みの3種類のピンについて、色および形状・アイコンの組み合わせを定義する
- 色のみに依存せず、形状・アイコンでも判別できるようにする（7.7 アクセシビリティ準拠）

## 成果物

- ピンアイコンコンポーネント／デザイントークン定義（例：`PinIcon.tsx`、`pin-styles.ts`）

## テスト要件

### 単体テスト
- 3種別それぞれに異なる形状・アイコンが割り当てられることを検証する
- 色情報を取り除いた状態（グレースケール変換等）でも3種別が形状・アイコンにより判別可能であることを検証する

### 結合テスト
- なし（本タスクは単独のUIコンポーネント定義のため）

### E2Eテスト
- なし（[Task 3: 受入テスト（E2E）](03-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- ピンの区別が色のみに依存していない（形状・アイコンでも判別できる）こと
