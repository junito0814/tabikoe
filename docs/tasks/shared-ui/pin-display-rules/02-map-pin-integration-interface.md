# Task 2: 地図コンポーネントへのピン種別表示の組み込み

> 出典: [pin-display-rules.md](../../../user-stories/shared-ui/pin-display-rules.md)
> インデックス: [pin-display-rules](00-index.md)

## 依存

- [Task 1: ピン種別ごとのアイコン・色定義](01-pin-icon-definitions.md)

## 実装内容

- Task1のピンアイコンを、SC-02（全体マップ）・SC-12（マイマップ）で利用する共通地図コンポーネントに組み込む
- ピン種別（通常／「行きたい」／投稿済み）を受け取り、対応するアイコンを描画するインターフェースとして提供する
- 実際のピン取得・地図表示ロジック（地図・検索機能 F-MP-01、マイマップ機能 F-RC-06）は本タスクの対象外とし、それぞれの実装時に本インターフェースを利用する前提とする

## 成果物

- 地図コンポーネントのピン描画インターフェース（種別propを受け取りアイコンを描画）

## テスト要件

### 単体テスト
- 種別prop（`normal`／`wishlist`／`posted`）に応じて、Task1で定義した正しいアイコンが選択されることを検証する

### 結合テスト
- モックのピンデータ（3種別混在）を用いて地図コンポーネントに渡し、それぞれ正しいアイコンで描画されることを確認する

### E2Eテスト
- なし（[Task 3: 受入テスト（E2E）](03-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- SC-02「全体」タブで、公開投稿があるスポットが通常ピンとして表示されること
- SC-02「行きたい」タブで、「行きたい」保存したスポットのみがピン表示されること
- SC-12（マイマップ）で、投稿済みピンと「行きたい」ピンが色・形状の両方で区別されること
