## 実装内容

- Task 1・2の統合後、モックデータを用いて本ストーリーの受入条件を検証する
- 実データ（実際のピン取得ロジック）を用いた最終確認は、地図・検索機能（F-MP-01）・マイマップ機能（F-RC-06）のE2Eタスクで改めて実施する

## 成果物

- E2Eテストシナリオ（手動 or 自動、Playwright等、モックデータ使用）
- 検証結果の記録

## テスト要件

### 単体テスト
- 対象外（本タスクはE2E検証が主目的）

### 結合テスト
- 対象外（Task 1・2で実施済み）

### E2Eテスト
モックデータを用いて以下のシナリオを実施する。

1. SC-02「全体」タブで、公開投稿ありのモックスポットが通常ピンとして表示されることを確認する
2. SC-02「行きたい」タブで、「行きたい」保存済みのモックスポットのみが表示されることを確認する
3. SC-12で、投稿済み・「行きたい」の両方に該当するモックスポットが「投稿済み」ピンとして表示され、単なる「行きたい」ピンとは色・形状が異なることを確認する
4. スクリーンショットをグレースケール変換し、3種類のピンが形状のみでも判別できることを確認する

## 関連する受入条件

- SC-02「全体」タブで、公開投稿があるスポットが通常ピンとして表示されること
- SC-02「行きたい」タブで、「行きたい」保存したスポットのみがピン表示されること
- SC-12（マイマップ）で、投稿済みピンと「行きたい」ピンが色・形状の両方で区別されること
- ピンの区別が色のみに依存していない（形状・アイコンでも判別できる）こと
