# Task 3: 受入テスト（E2E）

> 出典: [media-layout.md](../../../user-stories/shared-ui/media-layout.md)
> インデックス: [media-layout-v3](00-index.md)

## 依存

- Task 1〜2 すべて

## 実装内容

- 写真・動画のモーダルと投稿フォームのサムネイル の受入条件を、ブラウザ操作で一連に検証する E2E テストを書く
- テスト用データ（ユーザー・投稿・スポット・しおり）を seed で用意し、テスト後に片付ける
- スマートフォン幅（390px）とパソコン幅（1280px）の両方で実行する

## 成果物

- `e2e/<story>.spec.ts`（Playwright。E2E 環境が未整備の間は手動テスト手順書 `docs/tasks/.../NN-acceptance-e2e.md` の手順どおりに確認し、PR の Test plan に結果を書く）

## テスト要件

### 単体テスト
- なし

### 結合テスト
- なし

### E2Eテスト
- 本ストーリーの受入条件を上から順にすべて検証する

## 関連する受入条件

- 写真・動画のタップでモーダルが開き、左右で前後に送れ、動画がモーダル内で再生されること
