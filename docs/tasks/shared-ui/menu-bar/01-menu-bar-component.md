# Task 1: 共通メニューバーコンポーネントの実装

> 出典: [menu-bar.md](../../../user-stories/shared-ui/menu-bar.md)
> インデックス: [menu-bar](00-index.md)

## 依存

- F-AC-02 [セッション検証Middlewareの実装](../../account/session-management/01-session-verification-middleware.md)（ログイン状態・画面種別に応じた表示制御に利用）

## 実装内容

- 全画面共通のメニューバー（トップページ・ログイン画面・管理画面を除く）を実装する
- 全体マップ（SC-02）・新規投稿（SC-03）・通知（SC-14）・マイページ（SC-06）の4項目への遷移リンクを配置する
- スマートフォン・PCブラウザ両方のレイアウトに対応する（2.3 対応環境準拠）
- トップページ・ログイン画面・管理画面（/admin配下）では非表示にする

## 成果物

- 共通レイアウトコンポーネント（例：`components/AppMenuBar.tsx`）

## テスト要件

### 単体テスト
- 4項目（全体マップ・新規投稿・通知・マイページ）それぞれのリンク先が仕様通りであることを検証する
- トップページ・ログイン画面・管理画面のパスでは非表示になる判定ロジックを検証する

### 結合テスト
- 実際のルーティングと連携し、各項目押下で対応する画面へ遷移することを確認する

### E2Eテスト
- なし（[Task 4: 受入テスト（E2E）](04-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- トップページ・ログイン画面・管理画面を除く全画面で、共通メニューバーが表示されること
- メニューバーから全体マップ・新規投稿・通知・マイページへ遷移できること
