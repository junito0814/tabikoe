# Task 3: 管理画面への導線制御（is_admin判定）

> 出典: [menu-bar.md](../../../user-stories/shared-ui/menu-bar.md)
> インデックス: [menu-bar](00-index.md)

## 依存

- [Task 1: 共通メニューバーコンポーネントの実装](01-menu-bar-component.md)
- F-AC-04 [プロフィール編集](../../account/profile-edit/00-index.md)（プロフィール画面からの管理画面導線に利用）

## 実装内容

- 一般ユーザーのメニューバーには管理画面（SC-15〜18）への導線を表示しない
- `is_admin=true`のユーザーは、プロフィール編集画面（SC-07）等の別導線から管理画面（/admin配下）へアクセスできるようにする（3.10.1準拠）
- 管理画面へのアクセス制御自体（404を返す等）はMiddleware側の実装（3.10.1）に委ね、本タスクは導線の表示制御のみを対象とする

## 成果物

- `is_admin`判定に基づく管理画面導線の表示制御

## テスト要件

### 単体テスト
- `is_admin=false`のユーザーに対し、メニューバー・プロフィール画面のいずれにも管理画面リンクが表示されないことを検証する
- `is_admin=true`のユーザーに対し、プロフィール画面に管理画面への導線が表示されることを検証する

### 結合テスト
- テスト用DBで`is_admin=true`のユーザーがプロフィール画面から実際に`/admin`配下へ遷移できることを確認する

### E2Eテスト
- なし（[Task 4: 受入テスト（E2E）](04-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 一般ユーザーのメニューバーに管理画面への導線が表示されないこと
- is_adminユーザーがプロフィール画面等の導線から管理画面へ到達できること
