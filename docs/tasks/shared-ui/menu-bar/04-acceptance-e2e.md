- E2Eテストシナリオ（手動 or 自動、Playwright等）

## テスト要件

### 単体テスト
- 対象外（本タスクはE2E検証が主目的）

### 結合テスト
- 対象外（Task 1〜3で実施済み）

### E2Eテスト
以下のシナリオを実施する。

1. マイページ・投稿詳細等の対象画面でメニューバーが表示され、4項目それぞれから対応する画面へ遷移できることを確認する
2. トップページ・ログイン画面・管理画面ではメニューバーが表示されないことを確認する
3. 未読通知がある状態でログインし、通知アイコンにバッジが表示されることを確認する
4. 一般ユーザーでログインし、メニューバー・プロフィール画面のいずれにも管理画面への導線がないことを確認する
5. `is_admin=true`のユーザーでログインし、プロフィール画面から管理画面（/admin配下）へ到達できることを確認する

## 関連する受入条件

- トップページ・ログイン画面・管理画面を除く全画面で、共通メニューバーが表示されること
- メニューバーから全体マップ・新規投稿・通知・マイページへ遷移できること
- 通知アイコンに未読件数バッジが表示されること
- 一般ユーザーのメニューバーに管理画面への導線が表示されないこと
- is_adminユーザーがプロフィール画面等の導線から管理画面へ到達できること
