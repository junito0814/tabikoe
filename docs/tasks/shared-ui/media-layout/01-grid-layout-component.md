# Task 1: 添付点数に応じたグリッドレイアウトコンポーネント実装

> 出典: [media-layout.md](../../../user-stories/shared-ui/media-layout.md)
> インデックス: [media-layout](00-index.md)

## 依存

なし（土台タスク）

## 実装内容

- 添付点数に応じて以下のレイアウトを適用するコンポーネントを実装する
  - 1点：全幅表示
  - 2点：左右2分割
  - 3点：左に1点（大）＋右を上下2分割
  - 4点以上：2×2グリッド
- 1点目を代表画像とし、グリッド内では左上（または最も大きい枠）に配置する
- 投稿カード一覧・投稿詳細など複数画面で共通利用できるコンポーネントとして設計する（7.6 保守性準拠）
- 各要素に代替テキスト（`alt`属性）を設定する（7.7 アクセシビリティ準拠）。空文字ではなく内容を説明する文言を設定できるよう、呼び出し元から渡す必須項目として設計する

## 成果物

- `MediaGrid`共通コンポーネント

## テスト要件

### 単体テスト
- 添付点数1／2／3／4／5点それぞれの入力に対し、規定のレイアウト構造（要素数・配置）が生成されることを検証する
- 1点目が常に代表位置（左上または最大枠）に配置されることを検証する
- 各要素に、呼び出し元から渡した代替テキストが`alt`属性として設定されることを検証する

### 結合テスト
- 実際の投稿データ（写真・動画混在）を用いてレンダリングし、想定通りのレイアウトになることを確認する

### E2Eテスト
- なし（[Task 4: 受入テスト（E2E）](04-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 添付点数が1／2／3／4点以上の各パターンで、規定のレイアウト（全幅／2分割／3分割／2×2グリッド）が適用されること
- 1点目が代表画像として左上（または最大枠）に表示されること
