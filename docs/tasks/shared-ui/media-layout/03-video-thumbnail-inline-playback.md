# Task 3: 動画サムネイル・再生アイコン表示とインライン再生

> 出典: [media-layout.md](../../../user-stories/shared-ui/media-layout.md)
> インデックス: [media-layout](00-index.md)

## 依存

- [Task 1: 添付点数に応じたグリッドレイアウトコンポーネント実装](01-grid-layout-component.md)

## 実装内容

- `media_type='video'`の要素について、サムネイル画像（先頭フレーム）の中央に再生アイコンを重ねて表示する
- 並び替え・代表画像の判定・枚数バッジの扱いは写真と同一のルールに従う（動画が1点目であれば代表サムネイルとなる）
- タップすると、投稿詳細画面内でインライン再生する

## 成果物

- 動画サムネイル表示・インライン再生コンポーネント

## テスト要件

### 単体テスト
- `media_type`に応じて再生アイコンの重畳表示有無が切り替わることを検証する
- 動画が1点目の場合に代表サムネイルとして配置されることを検証する

### 結合テスト
- 実際の投稿データ（動画含む）を用いて、サムネイルURL・動画URLが正しく取得・表示されることを確認する
- タップ操作でインライン再生が開始されることを確認する

### E2Eテスト
- なし（[Task 4: 受入テスト（E2E）](04-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 動画サムネイルに再生アイコンが重畳表示され、写真と視覚的に区別できること
- 動画タップで投稿詳細画面内にインライン再生されること
