## テスト要件

### 単体テスト
- 対象外（本タスクはE2E検証が主目的）

### 結合テスト
- 対象外（Task 1〜3で実施済み）

### E2Eテスト
以下のシナリオを実施する。

1. 写真1点／2点／3点／4点の投稿をそれぞれ作成し、投稿カード一覧・投稿詳細で規定のレイアウトが表示されることを確認する
2. 写真・動画あわせて6点以上添付した投稿を作成し、「+N」バッジが表示されることを確認する
3. 1点目に動画を含む投稿で、代表サムネイルとして表示され、再生アイコンが重畳されていることを確認する
4. 動画をタップし、投稿詳細画面内でインライン再生されることを確認する

## 関連する受入条件

- 添付点数が1／2／3／4点以上の各パターンで、規定のレイアウト（全幅／2分割／3分割／2×2グリッド）が適用されること
- 5点目以降で「+N」バッジが右下枠に表示されること
- 1点目が代表画像として左上（または最大枠）に表示されること
- 動画サムネイルに再生アイコンが重畳表示され、写真と視覚的に区別できること
- 動画タップで投稿詳細画面内にインライン再生されること
