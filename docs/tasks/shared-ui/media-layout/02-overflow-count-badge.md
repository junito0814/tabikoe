# Task 2: 5点以上時の「+N」バッジ表示

> 出典: [media-layout.md](../../../user-stories/shared-ui/media-layout.md)
> インデックス: [media-layout](00-index.md)

## 依存

- [Task 1: 添付点数に応じたグリッドレイアウトコンポーネント実装](01-grid-layout-component.md)

## 実装内容

- 添付点数が5点以上の場合、2×2グリッドの右下枠に「+N」（Nは表示しきれない残り点数）の枚数バッジを重ねて表示する

## 成果物

- `MediaGrid`コンポーネントへのバッジ表示機能追加

## テスト要件

### 単体テスト
- 添付点数nに対して、バッジに表示される数値（N = n - 3等、表示済み枚数を除いた残数）の計算ロジックを検証する
- 4点以下ではバッジが表示されないことを検証する

### 結合テスト
- 実際の投稿データ（6点以上添付）でレンダリングし、右下枠にバッジが表示されることを確認する

### E2Eテスト
- なし（[Task 4: 受入テスト（E2E）](04-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 5点目以降で「+N」バッジが右下枠に表示されること
