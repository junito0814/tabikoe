## 実装内容（見極めが通ったら）

### 8-1. 骨組みが本物に受け渡す

`loading.tsx` の中身を退く側に、`page.tsx` の中身を現れる側に包む。

- 骨組み: 下に 10px ずれながら薄くなって消える（**150ms**）
- 本物: 下から 10px 上がりながら現れる（**現れる 210ms**。骨組みが消えてから始める。**移動は 400ms**）
- 先に消し、あとからゆっくり出すのは、古いものが注意を引かないようにするため

対象は要件 4.5.11 の表で「置く」とした 16 ルート。

### 8-2. 写真が繋がって育つ

一覧の写真と投稿詳細の写真を**同じ名前**で包む。押した写真がそのまま詳細の大きな写真になる。

- 対象は投稿カードの写真（`MediaGrid`）と投稿詳細の写真（`PostDetailScreen`）
- 名前は投稿の id を使い、**1 画面に同じ名前が 2 つ出ないようにする**（写真タブのように同じ投稿が複数出る場所に注意）

### やらないこと

**進む・戻るの左右スライド**（要件 4.5.11 の場面 5 に取り消し線で記録）。43 枚すべての `page.tsx` を包み、リンク 1 本ずつに印を付ける必要があるうえ（レイアウトに置いても効かない）、**30 秒以内に戻ったときは既に瞬時に出る**（7.1 の `staleTimes`）のに 400 ミリ秒を足すと遅くなる。
