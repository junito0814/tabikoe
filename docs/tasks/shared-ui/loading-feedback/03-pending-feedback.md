# Task 3: 押したとき・条件を変えたときの待ち表示

> 出典: [loading-feedback.md](../../../user-stories/shared-ui/loading-feedback.md)
> インデックス: [loading-feedback](00-index.md)
> 要件定義書 4.5.11 の場面 3・4

## 依存

なし（Task 1・2 とは別の場所を触る）

## 背景

いちばん多いのが「`disabled` にするだけ」。利用者からは押せていないのか処理中なのか区別が付かない。直す対象を**利用者が必ず通る動線**に絞る。

## 実装内容

### 3-1. しおり詳細（`src/components/itineraries/ItineraryDetailScreen.tsx`）

**この画面には待ち状態の変数が 1 つも無い**（`error` と `toast` だけ）。スポットを外す・Day を移す・並べ替える・名前を変える・しおりを消すは、API と再取得の 2 往復が終わるまで完全に無反応。

- 「どの操作が処理中か」を持つ状態を足す（`null` か操作の種類）
- 処理中の操作のボタンの文言を「〜中…」に変え、同時に押せなくする
- 再取得（`reload()`）の間も処理中のままにする（2 往復目で無反応に戻らないように）
- 時刻・メモ・チェックは今までどおり楽観更新のまま（取り消せる操作。要件 4.5.11）

### 3-2. 保存シート（`src/components/save/SaveSheet.tsx`）

チェックの状態をレスポンスの後に変えているため、押してもチェックが入らない。

- 行きたいの ON/OFF・しおりへの追加と削除・Day の変更を**楽観更新**にする（押した瞬間に見た目を変え、失敗したら戻して理由を出す）
- 新しいしおりを作って追加する操作だけは作成の結果を待つ必要があるので、ボタンの文言を「作成中…」に変える

### 3-3. 投稿画面（`src/components/posts/PostComposeScreen.tsx`）

- **「下書きに保存」**: 文言を「保存中…」に変える。写真・動画のアップロードを含むため最も長い待ちになる
- **既存写真の削除**: いま状態も `disabled` も無い。削除中はその写真を薄くし、二重に押せないようにする

### 3-4. 一覧の条件変更（3 画面）

`src/components/posts/PostSearchScreen.tsx`・`src/components/posts/SpotSearchScreen.tsx`・`src/components/mypage/MyPostsList.tsx`。

いまの待ち表示は「もっと見る」にしか効いていない。絞り込み・並び替え・旅行を変えたときは**古い一覧がそのまま残る**ので、条件を変えていないように見える。

- 条件を変えたときは一覧を空にし、骨組み（`CardListSkeleton`）に差し替える
- 追加読み込み（スクロール・「もっと見る」）は今までどおり末尾に「読み込み中…」を出す。**この 2 つを混同しない**（追加読み込みで一覧を消してはいけない）

### 触らないもの

要件 4.5.11 の範囲外、またはストーリーで「今回はやらない」としたもの。管理画面すべて、しおりのダイアログ（期間・メンバー・招待リンク）、アルバムの各操作、入力補助の候補取得、いいね・行きたいボタン（既に楽観更新）。

## テスト要件

### 単体テスト
- しおり詳細: スポットを外す操作の間、そのボタンの文言が「〜中…」になること。再取得が終わるまで戻らないこと。失敗したらエラーが出て文言が戻ること
- 保存シート: チェックを押した直後にチェックが入ること（レスポンスを待たない）。失敗したら元に戻り、理由が出ること
- 投稿画面: 「下書きに保存」の文言が「保存中…」に変わること。写真の削除中はその写真が二重に押せないこと
- 一覧 3 画面: 条件を変えたら一覧が空になり骨組みが出ること。**追加読み込みでは一覧が消えないこと**
- 取り消せない操作（投稿する・削除する）が今までどおり結果を待ってから画面を変えること

### 結合テスト
- なし（画面の状態だけで完結する）

### E2Eテスト
- 実機で、要件 8 章 87・88 の操作を一通り行い、押した直後に必ず画面が変わること

## 関連する受入条件

- しおり詳細の 4 操作、投稿画面の下書き保存と写真削除、保存シートのチェックで、押した直後に画面が変わること
- 投稿一覧・スポット一覧・マイページの投稿で条件を変えたとき、古い一覧が残らず骨組みに差し替わること
