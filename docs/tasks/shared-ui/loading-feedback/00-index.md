# 読み込み中の見せ方（loading-feedback）— タスク分割

> カテゴリ: `shared-ui` / ストーリー: [loading-feedback](../../../user-stories/shared-ui/loading-feedback.md)
> 要件定義書 4.5.11・8 章 85〜88

**利用者が触れる画面だけ**を扱う。管理画面は 2026-09-30 に保留（要件 9 章 未決定事項 No.14）。

| # | タスク | 依存 | 要件 8 章 |
|---|---|---|---|
| 1 | [起動直後の色（マニフェストと帯の色）](01-app-shell-color.md) | なし | 85 |
| 2 | [読み込み中に「ありません」と言わない](02-no-false-empty.md) | なし | 86 |
| 3 | [押したとき・条件を変えたときの待ち表示](03-pending-feedback.md) | なし | 87・88 |

3 つに依存関係は無い。**1 → 2 → 3 の順に入れる**。1 は設定だけでリスクが無く見た目に効く、2 は事実と違う案内を直すもので待ち表示より重い、3 は範囲が広く時間がかかる、という順番。

各タスクファイルは「依存」「実装内容」「成果物」「テスト要件（単体／結合／E2E）」「関連する受入条件」の構成で統一している（[rule.md](../../../rule.md)のテストルール区分に準拠）。
