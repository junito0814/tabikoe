# Task 7: 写真がふわっと出るようにする

> 出典: [loading-feedback.md](../../../user-stories/shared-ui/loading-feedback.md)
> インデックス: [loading-feedback](00-index.md)
> 要件定義書 4.5.11 の場面 5、8 章 94

## 依存

なし（Task 8 の遷移の演出とは**別の仕組み**。React の `<ViewTransition>` を使わない）

## 背景

写真は灰色の四角から**ぱっと切り替わる**。一覧・写真タブ・投稿詳細と、利用者がいちばん多く見る場所で毎回起きる。届いた瞬間に薄く重なって出すだけで、切り替わりの硬さが消える。

**時間あたりの効きがいちばん大きい。** CSS だけで済み、データの持ち方も React の仕組みも変えない。

## 実装内容

写真を出している部品に、読み込みが終わったら透明度を上げる動きを付ける。

- `next/image` の `onLoad` で「届いた」を受け取り、`opacity` を 0 → 1 にする
- 時間は **210ms**（要件 4.5.11 の場面 5 で決めた「現れる」の時間と揃える）
- **下地の灰色はそのまま残す**。写真が来るまでの場所取りは今までどおり（`aspect-square` などで確保済み）
- `prefers-reduced-motion` が指定されていたら動かさず、すぐ出す

**同じ処理を写真の部品ごとに書かない**（AGENTS.md 14）。共通の小さな部品にまとめ、次の 3 か所から使う。

| 場所 | ファイル |
|---|---|
| 投稿カード・写真タブ・アルバムの写真 | `src/components/media/MediaGrid.tsx` |
| 投稿画面で選んだ写真 | `src/components/media/SelectedMediaThumbnails.tsx` |
| マイページの投稿の小さな写真 | `src/components/mypage/MyPostsList.tsx` |

**既にブラウザの記憶にある写真では動かさない。** 戻ってきたときに毎回ふわっとすると、かえって遅く見える。`complete` が true なら最初から出す。

## 成果物

- 共通の部品（`src/components/media/FadeInImage.tsx` 程度）
- 上の 3 ファイルの差し替え
- テスト

## テスト要件

### 単体テスト
- 読み込みが終わる前は透明で、終わったら出ること
- 既に記憶にある写真（`complete` が true）では最初から出ていること
- `prefers-reduced-motion` のときは動かさずすぐ出ること
- 場所取り（下地の灰色と縦横比）が今までどおりであること

### 結合テスト
- なし

### E2Eテスト
- 実機で、投稿一覧を開いたときに写真がふわっと出ること（要件 8 章 94）

## 関連する受入条件

- 写真が届いたとき、灰色の四角からぱっと切り替わらず、薄く重なって出ること
