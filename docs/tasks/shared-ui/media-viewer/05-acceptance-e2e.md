## テスト要件

### E2Eテスト
1. 写真3点＋動画1点の投稿の詳細（SC-05）で2点目をタップする
   - 「2 / 4」から開き、→で動画に進むと再生され、Escで閉じて元の位置に戻ること
2. 6点以上の投稿で「+N」枠をタップする
   - 4点目から開き、→で5点目以降に進めること
3. スポットの「写真」タブ（SC-13）でサムネイルをタップする
   - 一覧全体を←→で移動でき、「この投稿を見る」で投稿詳細へ遷移できること
4. 投稿一覧（SC-04）・検索結果・マイページ・アルバムのカードでサムネイルをタップする
   - その投稿の全点がモーダルで開き、カードの文字部分のタップは従来どおり投稿詳細へ遷移すること
5. スマートフォンで左右スワイプ、PCで矢印キーによる移動
