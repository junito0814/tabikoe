なし（土台タスク）

## 実装内容

- エリア内エラーメッセージ表示（地図エリア内表示・画面全体表示の両パターンに対応）と、任意で再読み込みボタンを持つ共通コンポーネントを実装する
- メッセージ文言・再読み込みボタンの有無をpropsで切り替えられるようにする

## 成果物

- `ErrorNotice`共通コンポーネント

## テスト要件

### 単体テスト
- メッセージ文言がpropsに応じて表示されることを検証する
- 再読み込みボタンの表示有無がpropsで切り替えられることを検証する
- 再読み込みボタン押下時に指定のコールバックが呼び出されることを検証する
