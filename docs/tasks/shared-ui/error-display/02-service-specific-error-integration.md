# Task 2: 各外部サービス障害時のエラーメッセージ組み込み

> 出典: [error-display.md](../../../user-stories/shared-ui/error-display.md)
> インデックス: [error-display](00-index.md)

## 依存

- [Task 1: 共通エラー表示コンポーネントの実装](01-error-notice-component.md)

## 実装内容

要件定義書6章の各外部サービス仕様に準拠し、Task1のコンポーネントと規定メッセージを以下の障害検知箇所に組み込む。

- Google Maps JavaScript API障害時（6.1）：地図エリアに「地図を読み込めませんでした」と表示する
- Google Places API障害時（6.2）：「スポット検索が一時的に利用できません」と表示する。この場合もSC-19（手動登録）は利用可能な状態を維持する
- OAuth認証障害時（6.4）：「ログインに失敗しました。時間をおいて再度お試しください」と表示する
- Supabase（DB）障害時（6.5）：「データを読み込めませんでした。時間をおいて再度お試しください」と表示し、再読み込みボタンを設ける

## 成果物

- 各機能箇所へのエラー表示組み込み

## テスト要件

### 単体テスト
- 各障害ケース（地図・スポット検索・OAuth・DB）に対応するエラーメッセージ・再読み込みボタン有無の組み合わせが仕様通りであることを検証する

### 結合テスト
- 各外部API呼び出し箇所でエラーレスポンス（モック）を返し、対応するメッセージが実際に表示されることを確認する
- スポット検索API障害時、エラーメッセージ表示と同時にSC-19（手動登録）への導線が引き続き機能することを確認する

### E2Eテスト
- なし（[Task 3: 受入テスト（E2E）](03-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 地図読み込み失敗時、地図エリアに規定のエラーメッセージが表示されること
- スポット検索API障害時、規定のエラーメッセージが表示され、SC-19（手動登録）は引き続き利用できること
- OAuth認証失敗時、規定のエラーメッセージが表示されること
- DB読み込み失敗時、規定のエラーメッセージと再読み込みボタンが表示されること
