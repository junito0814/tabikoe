## テスト要件

### 単体テスト
- 対象外（本タスクはE2E検証が主目的）

### 結合テスト
- 対象外（Task 1・2で実施済み）

### E2Eテスト
外部サービスをモックで障害化させ、以下を確認する。

1. Google Maps JavaScript APIを障害化させ、地図エリアに「地図を読み込めませんでした」と表示されることを確認する
2. Google Places APIを障害化させ、「スポット検索が一時的に利用できません」と表示された上で、SC-19（手動登録）から投稿にスポットを設定できることを確認する
3. OAuth認証を失敗させ、「ログインに失敗しました。時間をおいて再度お試しください」と表示されることを確認する
4. Supabase（DB）呼び出しを失敗させ、「データを読み込めませんでした。時間をおいて再度お試しください」と再読み込みボタンが表示され、ボタン押下で再試行されることを確認する

## 関連する受入条件

- 地図読み込み失敗時、地図エリアに規定のエラーメッセージが表示されること
- スポット検索API障害時、規定のエラーメッセージが表示され、SC-19（手動登録）は引き続き利用できること
- OAuth認証失敗時、規定のエラーメッセージが表示されること
- DB読み込み失敗時、規定のエラーメッセージと再読み込みボタンが表示されること
