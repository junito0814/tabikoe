# Task 3: ブロック操作・一覧UI（プロフィール編集画面への追加）

> 出典: [blocking.md](../../../user-stories/safety/blocking.md)
> インデックス: [blocking](00-index.md)

## 依存

- [Task 1: ブロック／解除 Route Handler](01-block-unblock-handler.md)
- F-AC-04 [プロフィール編集](../../account/profile-edit/00-index.md)（SC-07への追加のため）

## 実装内容

- 他ユーザーのプロフィール・投稿詳細等から「ブロックする」を実行できる導線を追加する
- プロフィール編集画面（SC-07）に「ブロック中のユーザー一覧」セクションを追加し、一覧からの解除操作を提供する
- ブロック実行時は確認ダイアログを表示する（誤操作防止）

## 成果物

- ブロック実行導線（プロフィール・投稿詳細等）
- SC-07内のブロック一覧・解除UI

## テスト要件

### 単体テスト
- ブロック確認ダイアログの表示・キャンセル時に処理が実行されないことを検証する

### 結合テスト
- SC-07のブロック一覧が、実際の`blocks`テーブルの内容と一致して表示されることを確認する
- 一覧から解除操作を行うと、Task1のDELETE APIが呼ばれ、一覧から即座に消えることを確認する

### E2Eテスト
- なし（[Task 4: 受入テスト（E2E）](04-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- ユーザーをブロックすると、そのユーザーの投稿・コメント・プロフィール・アルバムが相互に表示されなくなること
- ブロックをいつでも解除できること
