## 背景

絞り込みシート（`FilterSheet`）の中で、**選び方が 2 通りに分かれている**（2026-10-03 の相談）。

| | 選び方 | やめ方 |
|---|---|---|
| カテゴリ（複数選択） | 押して選ぶ | もう一度押す |
| 予算・期間・滞在時間・距離・評価 | 押して選ぶ | **先頭の「指定なし」に戻す** |

同じ見た目の丸いチップが縦に並んでいるのに動きが違う。スマホの幅（390px）では「指定なし」のぶん選択肢が 1 つ増え、**予算は 4 つなのに 2 行に折り返していた**。

## 実装内容

### 5-1. 「指定なし」を外し、もう一度タップで解除にする

対象は**シートの中の 1 つだけ選ぶ条件すべて**。

| 条件 | 画面 |
|---|---|
| 予算 | 両方 |
| 滞在時間 | 両方 |
| 評価（平均） | 地図だけ |
| 期間（訪問日） | 投稿一覧だけ |
| 距離 | 投稿一覧だけ |

**地図と投稿一覧の両方**に効かせる。同じシートなので、片方だけ変えると同じ見た目で操作が食い違う。

条件を全部やめるのは、下の**「条件をクリア」**が担う（今もある）。

### 5-2. ラジオボタンをチェックボックスに変える

**ラジオボタンは一度選ぶと外せない**（HTML の決まり）。カテゴリと同じ `type="checkbox"` に変え、「選んだものをもう一度押したら `null` に戻す」を自分で書く。1 つ選ぶと他が外れる動きは残す（`checked` を 1 つだけにする）。

- 見た目・文字・寸法は変えない（丸いチップのまま）
- `name` でまとめる必要が無くなるので外す
- ラベルと `input` の組み（読み上げ・キーボード操作）は今までどおり

### 5-3. 「条件をクリア」は今までどおり

クリアで消えるもの（キーワード・カテゴリ・予算・期間・日付・距離・評価・タビコエだけの場所・写真グリッド）と、消えないもの（並び替え）は変えない。

## テスト要件

### 単体テスト
- シートに「指定なし」が**出ないこと**（地図・投稿一覧の両方）
- 選んだチップをもう一度押すと**解除される**こと（予算・滞在時間・評価・期間・距離）
- 別のチップを押すと**乗り換わる**こと（2 つ同時に選ばれない）
- カテゴリは今までどおり複数選べること
- 「条件をクリア」で全部やめられること

### 結合テスト
- なし

### E2Eテスト
- **実機で確かめる**。①予算を選んでもう一度押すと外れる ②予算が 1 行に収まる ③地図と投稿一覧で同じ操作になっている
