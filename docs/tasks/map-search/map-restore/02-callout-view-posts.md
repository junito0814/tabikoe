# Task 2: 吹き出しの「投稿する」を「投稿を見る」に変える

> 出典: [map-restore.md](../../../user-stories/map-search/map-restore.md)
> インデックス: [map-restore](00-index.md)
> 要件定義書 3.4.4「既存ピンのタップ」

## 実装内容

- `PinCallout` の「投稿する」を **「投稿を見る」** に変え、行き先をそのスポットの投稿一覧（本体タップと同じ `/spots/[id]`、`back=` つき）にする
- 吹き出しからの投稿（`composeHref`）は廃止する。「＋」（保存先シート）はそのまま残す
- 下書きピンの「続きを書く」、長押しの「ここに投稿」は変更しない

## テスト要件

### 単体テスト
- 吹き出しに「投稿を見る」があり、投稿一覧（`back=` つき）を指すこと
- 「投稿する」が無いこと
- 本体タップの行き先が変わっていないこと

## 関連する受入条件

- 要件定義書 8 章 46（吹き出しの導線）
