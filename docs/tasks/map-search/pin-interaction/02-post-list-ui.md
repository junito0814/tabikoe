### 結合テスト

- 投稿0件のスポットで「まだ投稿がありません」と表示されることを確認する

### E2Eテスト
- なし（[Task 4: 受入テスト（E2E）](04-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件
