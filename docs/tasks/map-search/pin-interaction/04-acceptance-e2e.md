## テスト要件

### 単体テスト
- 対象外（本タスクはE2E検証が主目的）

### 結合テスト
- 対象外（Task 1〜3で実施済み）

### E2Eテスト
以下のシナリオを実施する。

1. 投稿があるスポットのピンをタップし、投稿一覧が表示されることを確認する
2. 並び替えを新着順／評価順／いいね順に切り替え、それぞれ正しい順序で表示されることを確認する
3. 投稿カードをタップし、投稿詳細画面へ遷移することを確認する
4. 投稿が1件もないスポットのピンをタップし、「まだ投稿がありません」と表示されることを確認する

## 関連する受入条件

- ピンをタップすると、そのスポットの投稿一覧が表示されること
- 投稿一覧を新着順／評価順／いいね順で並び替えられること
- 投稿がないスポットでは「まだ投稿がありません」と表示されること
- 投稿一覧内の投稿カードをタップすると投稿詳細画面へ遷移すること
