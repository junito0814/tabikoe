## テスト要件

### 単体テスト
- 対象外（本タスクはE2E検証が主目的）

### 結合テスト
- 対象外（Task 1〜4で実施済み）

### E2Eテスト
以下のシナリオを実施する。

1. SC-04で「写真」タグをタップし、SC-13が表示されることを確認する
2. SC-13で写真・動画が新着順のグリッドで表示され、動画に再生アイコンが重畳されていることを確認する
3. 40点を超えるデータでスクロールし、追加読み込みされることを確認する
4. 写真・動画をタップし、元の投稿詳細画面（SC-05）へ遷移することを確認する
5. 非公開投稿の写真・動画が一覧に含まれないことを確認する

## 関連する受入条件

- 投稿一覧画面から「写真」タグを押すと、そのスポットの全公開投稿の写真・動画がグリッドで一覧表示されること
- 動画は再生アイコンを重畳したサムネイルで表示されること
- 表示が新着順であり、1回40点のページングでスクロールに応じて追加読み込みされること
- 写真・動画をタップすると元の投稿詳細画面へ遷移すること
- 非公開設定の投稿の写真・動画は一覧に含まれないこと
