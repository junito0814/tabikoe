# Task 2: スポット写真一覧画面（SC-13）UI実装

> 出典: [spot-photo-gallery.md](../../../user-stories/map-search/spot-photo-gallery.md)
> インデックス: [spot-photo-gallery](00-index.md)

## 依存

- [Task 1: スポット写真一覧取得 Route Handler](01-spot-photos-handler.md)
- shared-ui/media-layout（動画サムネイルへの再生アイコン重畳表示。既存コンポーネントを再利用する）

## 実装内容

- SC-13を実装し、正方形サムネイルのグリッド表示（列数は画面幅に応じて可変）を行う
- 動画は、shared-ui/media-layoutの動画サムネイル表示コンポーネントを再利用し、再生アイコンを重畳する
- スクロールに応じて追加読み込みする無限スクロールを実装する

## 成果物

- SC-13 スポット写真一覧画面

## テスト要件

### 単体テスト
- 画面幅に応じたグリッド列数の切り替えロジックを検証する

### 結合テスト
- Task1のAPIと接続し、写真・動画が正しくグリッド表示されることを確認する
- 動画に再生アイコンが重畳表示されることを確認する
- スクロールに応じて次の40点が追加読み込みされることを確認する

### E2Eテスト
- なし（[Task 5: 受入テスト（E2E）](05-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 投稿一覧画面から「写真」タグを押すと、そのスポットの全公開投稿の写真・動画がグリッドで一覧表示されること
- 動画は再生アイコンを重畳したサムネイルで表示されること
- 表示が新着順であり、1回40点のページングでスクロールに応じて追加読み込みされること
