## テスト要件

### 単体テスト
- 対象外（本タスクはE2E検証が主目的）

### 結合テスト
- 対象外（Task 1・2で実施済み）

### E2Eテスト
以下のシナリオを実施する。

1. キーワード・カテゴリ・距離・費用・滞在時間を組み合わせて絞り込み、期待通りの投稿のみが表示されることを確認する
2. 費用未入力の投稿が、費用による絞り込み結果に含まれないことを確認する
3. 非公開設定の投稿が、いずれの絞り込み結果にも含まれないことを確認する
4. 20件を超える結果に対し、スクロールで追加読み込みされることを確認する

## 関連する受入条件

- キーワード（スポット名）・カテゴリ・距離・費用・滞在時間による絞り込みが動作すること
- 費用未入力の投稿が費用による絞り込み結果から除外されること
- 非公開設定の投稿が絞り込み結果に含まれないこと
- 1回につき20件のページングで、スクロールに応じて追加読み込みされること
