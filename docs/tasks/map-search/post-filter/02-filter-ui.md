## 実装内容

- SC-04にキーワード検索欄と絞り込みパネル（カテゴリ・距離・費用・滞在時間）を実装する
- スクロールに応じて追加読み込みする無限スクロールを実装する

## 成果物

- SC-04の絞り込みUI・無限スクロール

## テスト要件

### 単体テスト
- 絞り込み条件の選択状態がTask1へのリクエストパラメータに正しく反映されることを検証する

### 結合テスト
- Task1のAPIと接続し、条件変更時に一覧が正しく更新されることを確認する
- スクロールに応じて次の20件が追加読み込みされることを確認する

### E2Eテスト
- なし（[Task 3: 受入テスト（E2E）](03-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- キーワード（スポット名）・カテゴリ・距離・費用・滞在時間による絞り込みが動作すること
- 1回につき20件のページングで、スクロールに応じて追加読み込みされること
