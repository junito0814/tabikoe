# Task 4: 旅行タイトル入力UI（オートコンプリート付き）

> 出典: [trip-title.md](../../../user-stories/posts/trip-title.md)
> インデックス: [trip-title](00-index.md)

## 依存

- [Task 1: 旅行タイトル オートコンプリート候補取得 Route Handler](01-trip-title-autocomplete-handler.md)

## 実装内容

- Task1の候補取得APIを呼び出すオートコンプリート付き入力欄を実装する
- 200文字までの文字数制限（書記素クラスタ単位）をクライアント側でも検証する
- 投稿作成画面（SC-03）に組み込めるコンポーネントとして実装する

## 成果物

- 旅行タイトル入力コンポーネント（SC-03へ組み込み用）

## テスト要件

### 単体テスト
- 入力に応じて候補一覧（モック）が表示されることを検証する
- 候補選択時に選択値が入力欄へ反映されることを検証する
- 200文字を超える入力に対して警告表示されることを検証する

### 結合テスト
- 実際の候補取得APIと連携し、入力に応じた候補が表示されることを確認する

### E2Eテスト
- なし（[Task 6: 受入テスト（E2E）](06-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 過去に作成した旅行タイトルがオートコンプリート候補として表示されること
