# Task 5: 表示範囲の制御（マイページ・アルバム画面のみ表示）

> 出典: [trip-title.md](../../../user-stories/posts/trip-title.md)
> インデックス: [trip-title](00-index.md)

## 依存

- post-creation [投稿関連テーブルのスキーマ定義・マイグレーション](../post-creation/01-post-schema-migration.md)

## 実装内容

- マイページ投稿一覧（SC-06）・アルバム画面（SC-09）では旅行タイトルを表示する
- 投稿カード一覧（SC-04）・投稿詳細（SC-05）・スポット写真一覧（SC-13）・他ユーザーのプロフィール画面では旅行タイトルを表示しないよう、各画面のAPIレスポンス・コンポーネントの実装を確認・調整する

## 成果物

- 各画面コンポーネント／APIレスポンスにおける旅行タイトルの表示制御

## テスト要件

### 単体テスト
- SC-06・SC-09のコンポーネントが旅行タイトルを表示することを検証する
- SC-04・SC-05・SC-13および他ユーザープロフィールのコンポーネントが旅行タイトルを表示しない（該当propsを受け取らない、または表示しない）ことを検証する

### 結合テスト
- 対象外（表示可否はコンポーネント単位の単体テストで担保する）

### E2Eテスト
- SC-04・SC-05・SC-13・他ユーザープロフィール画面を実際に開き、旅行タイトルが表示されないことを確認する
- SC-06・SC-09で旅行タイトルが表示されることを確認する

## 関連する受入条件

- マイページの投稿一覧に旅行タイトルが表示され、それ以外の画面（投稿カード一覧・投稿詳細・スポット写真一覧・他ユーザープロフィール）には表示されないこと
