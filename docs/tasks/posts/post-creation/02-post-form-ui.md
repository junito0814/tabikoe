# Task 2: 投稿作成フォームUI（SC-03）基本実装

> 出典: [post-creation.md](../../../user-stories/posts/post-creation.md)
> インデックス: [post-creation](00-index.md)

## 依存

- [Task 1: 投稿関連テーブルのスキーマ定義・マイグレーション](01-post-schema-migration.md)

## 実装内容

- カテゴリ・日付・滞在時間・費用・星評価・感想・公開設定の入力コンポーネントを実装する（旅行タイトル・スポット名の入力欄は、それぞれ[trip-title](../trip-title/00-index.md)・[spot-selection](../spot-selection/00-index.md)の成果物を組み込む前提とし、本タスクではプレースホルダとする）
- 各フィールドのクライアント側バリデーションを実装する
  - 費用：0〜999,999の整数
  - 星評価：1〜5の整数
  - 感想：1,000文字まで（書記素クラスタ単位でカウント）
  - 日付：投稿時点までの過去日（当日含む）のみ選択可、JST固定

## 成果物

- `SC-03`投稿作成画面の基本フォームコンポーネント

## テスト要件

### 単体テスト
- 費用に範囲外の値（負数、1,000,000以上、小数）を入力した場合にエラー表示されることを検証する
- 星評価が1〜5の整数以外選択できないことを検証する
- 感想の文字数カウントが書記素クラスタ単位（絵文字・結合文字を1文字扱い）であることを検証する
- 未来日を選択できないことを検証する

### 結合テスト
- フォーム入力からRoute Handlersへ送信するペイロードが仕様通りの形式で構築されることを確認する

### E2Eテスト
- なし（[Task 6: 投稿作成フローの画面統合・受入テスト（E2E）](06-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 感想が1,000文字（書記素クラスタ単位）を超える場合は保存できないこと
- 公開設定のデフォルトが「公開」であること
