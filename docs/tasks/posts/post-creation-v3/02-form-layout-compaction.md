## 実装内容

- `PostForm` の配置を変える：旅行タイトル・スポット名はラベルと入力欄を横並び、日付／滞在時間と費用／星評価は 2 列、カテゴリ・滞在時間はチップ列からドロップダウン（`<select>`）へ、注意文（`UploadNotice`）は 1 行に畳んで「詳しく」で全文、感想は 2 行から自動で伸びる、公開設定は感想のラベル行の右端
- 入力項目・順序・必須条件・バリデーション表示は変えない
- 写真 1〜3 点の状態で 560px の高さにスクロールなしで収まることを確認する

- 既存の必須検証（旅行タイトル・スポット・星・写真）が変わらず動くこと
