# Task 4: 投稿削除UI（確認ダイアログ含む）

> 出典: [post-delete.md](../../../user-stories/posts/post-delete.md)
> インデックス: [post-delete](00-index.md)

## 依存

- [Task 1: 投稿削除 Route Handler（カスケード削除）](01-post-delete-handler.md)

## 実装内容

- 投稿詳細画面（SC-05）・投稿編集画面（SC-03編集モード）に削除ボタンを設置する（投稿者本人にのみ表示）
- 削除ボタン押下時、確認ダイアログを表示し、確認後にTask1のAPIを呼び出す
- 削除成功後、投稿一覧または元の画面へ遷移する

## 成果物

- 投稿削除ボタン・確認ダイアログコンポーネント

## テスト要件

### 単体テスト
- 投稿者本人以外には削除ボタンが表示されないことを検証する
- 確認ダイアログでキャンセルした場合、削除APIが呼び出されないことを検証する
- 確認ダイアログで確定した場合、削除API（モック）が呼び出されることを検証する

### 結合テスト
- 実際のAPIと連携し、削除成功後に画面遷移・一覧からの除外が反映されることを確認する

### E2Eテスト
- なし（[Task 5: 受入テスト（E2E）](05-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 投稿者本人が投稿を削除できること（投稿者本人以外は削除できない）
