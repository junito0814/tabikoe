# Task 2: アルバム一覧表示のゼロ件時非表示ロジック

> 出典: [post-delete.md](../../../user-stories/posts/post-delete.md)
> インデックス: [post-delete](00-index.md)

## 依存

- [Task 1: 投稿削除 Route Handler（カスケード削除）](01-post-delete-handler.md)

## 実装内容

- アルバム一覧取得クエリ（マイページのアルバム一覧・SC-09関連）に、紐づく投稿件数が1件以上であることを条件として組み込む
- 投稿削除により紐づく投稿が0件になった旅行（`trips`）は、アルバム一覧の取得結果から除外されるようにする
- `trips`レコード自体は削除しない（3.6.2の仕様に準拠）

## 成果物

- アルバム一覧取得クエリの条件追加（`HAVING COUNT(posts) > 0`相当）

## テスト要件

### 単体テスト
- クエリビルダー／ORMレベルで、投稿0件の旅行が結果セットから除外される条件式が正しく組み立てられることを検証する

### 結合テスト
- テスト用DBで、ある旅行の投稿を全て削除した後、アルバム一覧取得APIのレスポンスに当該旅行が含まれないことを確認する
- 同じ旅行に新たに投稿を作成すると、再びアルバム一覧に表示されることを確認する

### E2Eテスト
- なし（[Task 5: 受入テスト（E2E）](05-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 削除により紐づく投稿が0件になった旅行（アルバム）は、アルバム一覧に表示されなくなること
