# Task 4: スポット手動登録画面（SC-19）UI実装

> 出典: [spot-selection.md](../../../user-stories/posts/spot-selection.md)
> インデックス: [spot-selection](00-index.md)

## 依存

- [Task 3: スポット名オートコンプリートUI](03-spot-autocomplete-ui.md)

## 実装内容

- SC-03から開くモーダルとしてSC-19を実装する（独立URLは持たない）
- SC-02の全体マップと同じGoogle Mapsコンポーネントを再利用し、現在地を初期表示とする
- 画面中央に固定されたピンに対し、地図側をドラッグ・ピンチ操作してピンの指す位置を調整する「中央固定ピン」方式を実装する
- 右上に現在地ボタンを設置し、いつでも現在地に地図を戻せるようにする
- 「この位置でスポットを登録」ボタン押下で、その時点の地図中心の緯度経度を[Task 5: スポット手動登録 Route Handler](05-manual-spot-registration-handler.md)のAPIへ送信する

## 成果物

- `SC-19`スポット手動登録モーダルコンポーネント

## テスト要件

### 単体テスト
- 地図のドラッグ・ピンチ操作に応じて、地図中心座標（＝ピンの指す位置）が正しく更新されることを検証する
- 現在地ボタン押下で地図が現在地に戻ることを検証する

### 結合テスト
- SC-02で利用している地図コンポーネントを共通利用できていることを確認する（コンポーネントの再利用性の検証）

### E2Eテスト
- なし（[Task 7: 受入テスト（E2E）](07-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- スポット候補が見つからない場合、SC-19の地図上でピンを操作して新規スポットを登録できること
