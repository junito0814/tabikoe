# Task 3: スポット名オートコンプリートUI

> 出典: [spot-selection.md](../../../user-stories/posts/spot-selection.md)
> インデックス: [spot-selection](00-index.md)

## 依存

- [Task 2: スポット候補検索 Route Handler](02-spot-search-handler.md)

## 実装内容

- Task2のAPIを呼び出すスポット名入力欄（オートコンプリート）を実装する
- 候補選択で投稿にスポットID（Google Places由来の場合は登録処理を経て採番されたID）を設定する
- 候補に該当がない場合、「候補が見つかりません。地図でスポットを登録する」の導線を表示し、[Task 4: スポット手動登録画面（SC-19）UI実装](04-manual-spot-registration-ui.md)のモーダルを開けるようにする
- 投稿作成画面（SC-03）に組み込めるコンポーネントとして実装する

## 成果物

- スポット名入力コンポーネント（SC-03へ組み込み用）

## テスト要件

### 単体テスト
- 入力に応じて候補一覧（モック）が表示されることを検証する
- 候補選択時に選択値・スポットIDが入力欄／フォーム状態へ反映されることを検証する
- 候補が0件の場合、手動登録への導線が表示されることを検証する

### 結合テスト
- 実際の候補検索APIと連携し、入力に応じた候補が表示されることを確認する

### E2Eテスト
- なし（[Task 7: 受入テスト（E2E）](07-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- Google Places候補からのスポット選択ができること
