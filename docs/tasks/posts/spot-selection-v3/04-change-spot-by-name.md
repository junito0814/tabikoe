## 実装内容

- スポット名欄の「変更」で `SpotAutocompleteInput` を開き、候補を選ぶと地図をそのスポットへ移動して `lockedPosition` にする。「新しい場所」を選ぶと固定を解除して中央固定ピンに戻る
- スポット名の任意入力（新しい場所の名前）欄を置く
- 候補の吹き出しに「この付近の新しい場所」を置き、押すと固定を外して中央固定ピンに戻す（地図はその候補の位置のまま）。現地にいなくても登録の無い場所を決められる
- **自宅の保護**：現在地から開き（`?lat&lng` が現在地由来）、`moved` が false で、登録スポットも選ばず「新しい場所」のまま「投稿する」を押したときは確認ダイアログ「この位置に新しいスポットを登録して公開します。自宅など公開したくない場所ではありませんか？」［投稿する］［場所を変える］を出す。地図を動かした・既存スポットを選んだ・下書き保存では出さない

## テスト要件

### 単体テスト
- 候補選択で地図の中心と固定状態が変わること
- 「新しい場所」で固定が解除されること
- 「この付近の新しい場所」で候補の位置のまま固定が外れること
- 自宅保護の確認が「現在地由来・未移動・新しい場所」のときだけ出ること（4 分岐）

### 結合テスト
- なし

### E2Eテスト
- なし（[Task 5: 受入テスト（E2E）](05-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 「変更」から名前で候補を検索して選ぶと、地図がそのスポットへ移動し位置が固定されること
- 現在地から開いた投稿画面で地図を動かさず「新しい場所」のまま投稿すると自宅保護の確認が出て、地図を動かした場合や既存スポットを選んだ場合は出ないこと（受入条件70）
- 「変更」の候補から「この付近の新しい場所」で固定を外し、現地にいなくても登録の無い場所に投稿できること（受入条件70）
