## テスト要件

### 単体テスト
- 対象外（本タスクはE2E検証が主目的）

### 結合テスト
- 対象外（Task 1〜5で実施済み）

### E2Eテスト

1. 未読の個人向け通知・お知らせが混在する状態で通知一覧を開く
   - 新着順に統合表示され、お知らせに種別ラベルが表示されること
   - 個人向け通知が既読になり、メニューバーの未読件数バッジが更新されること
   - お知らせは未読件数に影響しないこと
2. コメント通知をタップし、対象投稿の詳細画面へ遷移することを確認する
3. 21件以上の通知がある状態でスクロールし、20件区切りで追加読み込みされることを確認する
4. 90日より前に作成された通知が一覧に表示されないことを確認する

## 関連する受入条件

- 個人向け通知とお知らせが新着順に統合表示され、お知らせに種別ラベルが付与されること
- 通知一覧を開くと、表示された個人向け通知が既読になり、メニューバーの未読件数バッジが更新されること
- お知らせは既読管理の対象外として常に表示され、未読件数の集計に含まれないこと
- 通知の種類に応じて、タップ時に関連する画面へ遷移すること
- 1回につき20件を読み込み、スクロールに応じて追加読み込みされること
- 90日を超えた個人向け通知が一覧の表示対象から除外されること
