# Task 5: 90日保存期間の除外ロジック

> 出典: [notification-list.md](../../../user-stories/notifications/notification-list.md)
> インデックス: [notification-list](00-index.md)

## 依存

- [Task 1: 通知一覧取得API](01-notification-list-api.md)

## 実装内容

- 個人向け通知（`notifications`）のうち、`created_at`が現在時刻から90日を超えるものを一覧取得APIの結果から除外する
- お知らせ（`system_announcements`）は本フィルタの対象外とし、常に表示する（要件定義書9章 未決定事項#3により、お知らせへの適用要否・物理削除の要否は未確定のため、現時点では「非表示（クエリ条件での除外）」のみを実装し、物理削除は対象としない）

## 成果物

- 90日フィルタを含む一覧取得クエリの実装

## テスト要件

### 単体テスト
- 作成から90日を超えた個人向け通知が結果に含まれないことを検証する
- 90日以内の通知およびお知らせが除外されないことを検証する

### 結合テスト
- テスト用DBに90日超・90日以内の通知を混在させ、APIレスポンスが期待どおりフィルタされることを確認する

### E2Eテスト
- なし（[Task 6: 受入テスト（E2E）](06-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 90日を超えた個人向け通知が一覧の表示対象から除外されること

## 備考

要件定義書9章 未決定事項#3（90日経過後の扱い：非表示のみか物理削除も行うか）が確定した際は、本タスクの実装方針（現状は非表示のみ）を見直す。
