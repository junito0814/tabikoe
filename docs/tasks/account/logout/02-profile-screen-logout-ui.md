# Task 2: プロフィール編集画面（SC-07）のログアウトUI実装

> 出典: [logout.md](../../../user-stories/account/logout.md)
> インデックス: [logout](00-index.md)

## 依存

- [Task 1: ログアウト Route Handler（/api/auth/logout）](01-logout-route-handler.md)

## 実装内容

- プロフィール編集画面（SC-07）にログアウトボタンを設置する
- ボタン押下でTask1のログアウトAPIを呼び出す
- 成功後、未ログイン状態でも閲覧可能な画面（トップページ等）へ遷移する

## 成果物

- SC-07内のログアウトボタンコンポーネント

## テスト要件

### 単体テスト
- ログアウトボタン押下で、ログアウトAPI（モック）が呼び出されることを検証する
- API呼び出し成功時に、遷移処理（トップページへのリダイレクト等）が実行されることを検証する

### 結合テスト
- 実際のログアウトAPIエンドポイントに対してボタン押下相当のリクエストを送り、レスポンス後にクライアント側の認証状態（保持しているユーザー情報等）がクリアされることを確認する

### E2Eテスト
- プロフィール編集画面でログアウトボタンをクリックし、未ログイン状態の画面へ遷移することを確認する

## 関連する受入条件

- プロフィール編集画面からログアウト操作ができること
