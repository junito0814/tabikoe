# Task 4: 退会確認ダイアログUI実装

> 出典: [account-deletion.md](../../../user-stories/account/account-deletion.md)
> インデックス: [account-deletion](00-index.md)

## 依存

- [Task 1: 退会実行 Route Handler（ユーザー匿名化・関連データ削除）](01-deactivation-handler.md)
- [Task 3: 管理者退会時の引き継ぎ確認フロー](03-admin-handover-confirmation.md)

## 実装内容

- プロフィール編集画面（SC-07）等に退会操作の起点を設置する
- 退会実行前に確認ダイアログを表示し、以下を明示する
  - 投稿・コメントは残るがユーザー名は匿名化される旨
  - オーナーを務めるアルバムがある場合はオーナー権限が自動的に移譲される旨
- `is_admin`ユーザーの場合は、Task3の確認チェックボックスを追加表示する
- 確認後、Task1（Task2・Task3を含む）の退会実行APIを呼び出す

## 成果物

- SC-07内の退会確認ダイアログコンポーネント

## テスト要件

### 単体テスト
- ダイアログに規定の説明文（匿名化・オーナー移譲の旨）が表示されることを検証する
- `is_admin`ユーザーの場合のみ、追加の管理者引き継ぎ確認チェックボックスが表示されることを検証する
- 確認未完了状態では「退会する」ボタンが無効化されることを検証する

### 結合テスト
- 確認完了後にボタン押下で退会API（モック）が呼び出されることを確認する

### E2Eテスト
- 退会確認ダイアログを表示し、内容を確認した上で退会を実行できることを確認する

## 関連する受入条件

- 退会実行前に、データの扱いを説明する確認ダイアログが表示されること
