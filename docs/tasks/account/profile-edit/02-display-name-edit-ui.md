# Task 2: ユーザー名編集UI実装（SC-07）

> 出典: [profile-edit.md](../../../user-stories/account/profile-edit.md)
> インデックス: [profile-edit](00-index.md)

## 依存

- [Task 1: ユーザー名更新 Route Handler実装](01-display-name-update-handler.md)

## 実装内容

- プロフィール編集画面（SC-07）にユーザー名入力欄を設置する
- 入力に応じてリアルタイムで残り文字数を表示する（書記素クラスタ単位でカウント）
- 保存ボタン押下でTask1のAPIを呼び出す
- 200文字を超える入力を試みた場合、クライアント側でも警告表示・保存無効化を行う

## 成果物

- SC-07内のユーザー名編集フォームコンポーネント

## テスト要件

### 単体テスト
- 文字数カウント表示ロジックについて、絵文字・結合文字を1文字としてカウントすることを検証する
- 200文字超過時に保存ボタンが無効化される、またはエラーメッセージが表示されることを検証する
- 保存ボタン押下でAPI（モック）が呼び出されることを検証する

### 結合テスト
- 実際のAPIエンドポイントに更新リクエストを送り、成功時に画面上の表示が更新されることを確認する

### E2Eテスト
- プロフィール編集画面でユーザー名を変更し、保存後に新しい名前が画面に反映されることを確認する

## 関連する受入条件

- ユーザー名を200文字以内で変更できること
