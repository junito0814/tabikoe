- E2Eテストシナリオ（手動 or 自動、Playwright等）
- 検証結果の記録

## テスト要件

### 単体テスト
- 対象外（本タスクはE2E検証が主目的）

### 結合テスト
- 対象外（Task 1〜5で実施済み）

### E2Eテスト
以下のシナリオを実施する。

1. プロフィール編集画面でユーザー名を200文字ちょうどに変更し、保存できることを確認する
2. 201文字以上（絵文字を含む場合も書記素クラスタ単位で判定）を入力した場合、保存が拒否されることを確認する
3. プロフィール編集画面でアイコン画像（GPS付きEXIFを含むJPEG）をアップロードし、保存後に新しいアイコンが表示されることを確認する
4. アップロードした画像のメタデータを確認し、GPS情報が除去されていることを確認する（ダウンロードした画像のEXIF検証等）

## 関連する受入条件

- ユーザー名を200文字以内で変更できること
- アイコン画像をアップロードして変更できること
- アップロードした画像がEXIF位置情報除去・縮小画像生成など5.4の規則に従って処理されること
