# Task 3: 画像アップロード共通処理（EXIF除去・向き補正・縮小画像生成）の実装

> 出典: [profile-edit.md](../../../user-stories/account/profile-edit.md)
> インデックス: [profile-edit](00-index.md)

## 依存

なし（土台タスク）

## 実装内容

要件定義書5.4「画像・動画の取り扱い」に準拠する共通処理をRoute Handlers内に実装する。

- 受付形式（JPEG／PNGのみ）をファイルの実体ベースで検証する
- サイズ上限（1点あたり10MB）を検証する
- sharpライブラリを用いてEXIF位置情報（GPS情報）を除去する
- 長辺1200pxの縮小画像を自動生成する
- 元画像の向き情報（EXIF Orientation）を考慮し、正しい向きで縮小画像を生成する
- Supabase Storageへ原本・縮小画像の両方を保存し、それぞれのURLを返す

> 本関数は将来的に投稿の写真アップロード（F-PO）でも再利用する想定の共通モジュールとする。

## 成果物

- 画像アップロード共通処理関数（例：`lib/image/processUpload.ts`）

## テスト要件

### 単体テスト
- JPEG／PNG以外の形式（例：GIF、拡張子偽装ファイル）を拒否することを検証する
- 10MBを超えるファイルを拒否することを検証する
- GPS情報を含むテスト画像を入力し、出力画像からGPS情報が除去されていることを検証する
- EXIF Orientationが回転を示すテスト画像を入力し、出力される縮小画像が正しい向きになることを検証する
- 出力される縮小画像の長辺が1200pxであることを検証する

### 結合テスト
- テスト用Supabase Storageバケットへ原本・縮小画像が実際にアップロードされ、それぞれのURLが取得できることを確認する

### E2Eテスト
- なし（[Task 6: 受入テスト（E2E）](06-acceptance-e2e.md)で、実際のアップロードフローの一部として検証する）

## 関連する受入条件

- アップロードした画像がEXIF位置情報除去・縮小画像生成など5.4の規則に従って処理されること
