# Task 5: アイコン画像アップロードUI実装（SC-07）

> 出典: [profile-edit.md](../../../user-stories/account/profile-edit.md)
> インデックス: [profile-edit](00-index.md)

## 依存

- [Task 4: アイコン画像アップロード Route Handler実装](04-avatar-upload-handler.md)

## 実装内容

- プロフィール編集画面（SC-07）に、現在のアイコン画像のプレビューとファイル選択UIを設置する
- 選択した画像をアップロード前にプレビュー表示する
- アップロードボタン押下でTask4のAPIを呼び出し、成功後に画面上のアイコン表示を更新する
- 受付形式・サイズ上限を超えるファイルを選択した場合、クライアント側でも警告表示する

## 成果物

- SC-07内のアイコンアップロードコンポーネント

## テスト要件

### 単体テスト
- 対応形式外のファイル（JPEG／PNG以外）を選択した場合に警告が表示されることを検証する
- 10MBを超えるファイルを選択した場合に警告が表示されることを検証する
- アップロードボタン押下でAPI（モック）が呼び出されることを検証する

### 結合テスト
- 実際のAPIエンドポイントに画像をアップロードし、成功時に画面上のアイコン表示が更新されることを確認する

### E2Eテスト
- プロフィール編集画面でアイコン画像をアップロードし、保存後に新しいアイコンが画面（プロフィール編集画面・マイページ等）に反映されることを確認する

## 関連する受入条件

- アイコン画像をアップロードして変更できること
