## 背景

絵のデータは Task 1 で入った。**それを描く部品を 1 つ作り、バッジ画面とトーストの両方から使う**（約束 14 ── 同じ絵を 2 か所に書かない）。

## 実装内容

### 2-1. `src/components/badges/PrefectureBadgeIcon.tsx`（新規）

県名と大きさを受け取り、**金の二重の輪＋中の絵**を SVG で返す。

| | 値 | なぜ |
|---|---|---|
| 外側の輪 | 半径 47・線幅 5 | — |
| 内側の輪 | 半径 38・線幅 2.4 | 二重にするだけでメダルに見える（要件 4.5.20） |
| 輪の色 | 金 `#d4a52a` | 🏅 のまま残すほかのバッジと形がそろう |
| 輪の中の塗り | 金の 12% | — |
| 絵の大きさ | **0.70 倍**（中心を軸に縮める） | 内側の輪にぶつからない |
| 既定の大きさ | **56px** | 48px では細かい絵が潰れた（要件 4.5.20） |

**絵が無い県（`prefectureMotif` が null）のときは、この部品自体を描かない。** 呼ぶ側が 🏅 に落とす（要件 8 章 102）。

### 2-2. `src/components/badges/BadgeScreen.tsx`

都道府県の節だけ、🏅 を `PrefectureBadgeIcon` に差し替える。

- **ほかの 3 節（投稿数・いいね数・スポット登録）は 🏅 のまま**（要件 4.5.14）
- 未獲得は **`grayscale(1)` と `opacity(.45)`** を絵全体に掛ける（いまの `grayscale opacity-50` と同じ考え方）
- 絵が 56px になるので、**札の高さが変わる**。3 列・札の幅 109px は変えない
- 都道府県の節では **`label` の文字（県名）は札の下にそのまま置く**（絵の中には書かない。規則 4）

### 2-3. `src/components/badges/BadgeToast.tsx`

獲得したのが都道府県バッジのときだけ、🏅 を `PrefectureBadgeIcon` に差し替える。**トーストでの大きさは 40px**（帯の高さに収めるため。56px では帯が伸びる）。
