# Task 4: ステータスバッジ画面（SC-10）

> 出典: [status-badges.md](../../../user-stories/badges/status-badges.md)
> インデックス: [status-badges](00-index.md)

## 依存

- [Task 1: バッジ種別・獲得閾値の定義（共通カタログ）](01-badge-catalog-definition.md)

## 実装内容

- SC-10画面を実装し、Task1のカタログに定義された全バッジ種別を一覧表示する
- 獲得済みバッジは`badges`テーブルの当該ユーザーのレコードと突合し、獲得日時とともに強調表示する
- 未獲得バッジはグレーアウト等で区別して表示する（都道府県バッジは、まだ投稿のない都道府県も含めて全都道府県を一覧表示する）
- マイページ（F-RC-01、本バッチで並行作成中）の遷移メニューからSC-10への導線を設ける前提とし、本タスクでは画面自体とデータ取得APIを実装する

## 成果物

- SC-10画面コンポーネント
- バッジ一覧取得API（`GET /api/badges`：全バッジ種別と、当該ユーザーの獲得状況をマージして返す）

## テスト要件

### 単体テスト
- 獲得済み・未獲得バッジの表示区分ロジックを検証する

### 結合テスト
- テスト用DBで、一部バッジのみ獲得済みのユーザーに対し、獲得済み・未獲得が正しく描き分けられることを確認する

### E2Eテスト
- なし（[Task 6: 受入テスト（E2E）](06-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- ステータスバッジ画面（SC-10）で、獲得済み・未獲得のバッジが一覧確認できること
