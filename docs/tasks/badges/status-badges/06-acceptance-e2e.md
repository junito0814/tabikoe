## テスト要件

### 単体テスト
- 対象外（本タスクはE2E検証が主目的）

### 結合テスト
- 対象外（Task 1〜5で実施済み）

### E2Eテスト
以下のシナリオを実施する。

1. 投稿数が9件のユーザーが10件目の投稿を作成する
   - 投稿完了後にトーストで投稿数バッジ（10件）の獲得が表示されること
   - ステータスバッジ画面（SC-10）で当該バッジが獲得済みとして表示されること
2. 初めて訪れる都道府県のスポットに投稿する
   - 都道府県バッジが付与され、SC-10で確認できること
3. 累計いいね数が49件のユーザーの投稿に、別ユーザーがいいねを付けて50件になる
   - `badges`テーブルにいいね数バッジ（50件）が付与されること（通知一覧には表示されないことも確認する）
4. 投稿数バッジを獲得済みのユーザーが、獲得条件を下回るまで投稿を削除する
   - SC-10で当該バッジが引き続き獲得済みのまま表示されること（[posts/post-delete Task3](../../posts/post-delete/03-badge-retention-regression-test.md)の回帰テストと重複確認）

## 関連する受入条件

- 都道府県バッジが、スポット登録時のサーバー側逆ジオコーディング結果に基づいて正しく判定されること
- 投稿数バッジ（1／10／50／100件）が、累計投稿数の到達時点で正しく付与されること
- いいね数バッジ（1／10／50／100／200件）が、累計獲得いいね数の到達時点で正しく付与されること
- ステータスバッジ画面（SC-10）で、獲得済み・未獲得のバッジが一覧確認できること
- バッジを新たに獲得した際、その場でトースト表示され、通知一覧（SC-14）には残らないこと
- 投稿削除によりバッジの獲得条件を下回っても、獲得済みバッジは失われないこと
