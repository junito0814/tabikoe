# Task 3: 「アカウントの状態」の廃止

> インデックス: [my-page-v4](00-index.md)
> 要件定義書 3.6.1・3.10（SC-28 の廃止）、ワイヤーフレーム決定事項 72

## 依存

なし

## 背景

役割が重複しているため廃止する（2026-10-04 のメンタリング 8）。

| 伝えたいこと | 他にどこで伝わるか |
|---|---|
| 停止・非公開化・ストライクの理由 | **通知**（`account_suspended`・`moderation_action` など。要件 3.9.1「対応のたびに理由を通知する」） |
| いつまで投稿できないか | **投稿画面**（「◯/◯ まで投稿できません（下書きの保存はできます）」） |

**停止中はそもそもログインできない**ので、この画面は停止のときには見られなかった。実質「投稿禁止中」のためだけに存在していた。

## 実装内容

- `/account/status`（SC-28）と `AccountStatusScreen` を削除する
- マイページの帯（「いま、投稿とコメントができません…」）を削除する
- 通知からこの画面へ飛ばしている箇所があれば、通知の本文で完結するようにする（`resolveNotificationHref` を確認する）

**消さないもの**: 通知そのもの、投稿画面の案内、管理側のストライク・停止の仕組み。

## 成果物

- `src/app/account/status/`・`src/components/account/AccountStatusScreen.tsx` の削除
- `MyPageScreen` から帯を削除
- 通知の遷移先の確認
- テスト

## テスト要件

### 単体テスト
- `/account/status` が無くなっていること（ルートの削除）
- マイページに帯が出ないこと
- 通知の遷移先に `/account/status` が残っていないこと

### E2Eテスト
- 投稿禁止中のアカウントで、投稿画面に「◯/◯ まで投稿できません」が出ること（受け皿が残っていることの確認）
