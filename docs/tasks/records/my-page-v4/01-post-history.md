# Task 1: 投稿履歴に一覧タブを作り、マイページから投稿と下書きを移す

> インデックス: [my-page-v4](00-index.md)
> 要件定義書 3.6.5（投稿履歴）、ワイヤーフレーム決定事項 72

## 依存

なし

## 背景

「あしあと」は**地図だけ**の画面だった。名前を「投稿履歴」に改めるにあたり、**一覧**を持たせる（地図だけの画面を「履歴」と呼ぶと中身とずれる）。

あわせて、マイページにあった**自分の投稿一覧**と**下書き**をここへ移す。投稿に関するものを 1 か所にまとめ、マイページは「振り返りの入口」に徹する。

## 実装内容

### 1-1. タブ（一覧／地図）

- **一覧が既定**。URL に残す（`view=map` のような持ち方。検索結果の地図タブ〈post-timeline Task 7〉と揃える）
- 地図タブの中身は**いまのあしあとそのまま**（投稿・下書き・保存済みのピン、表示切り替え、最大 100 件）

### 1-2. 一覧タブの中身

マイページから移すもの。

| 移すもの | いまの場所 |
|---|---|
| 自分の投稿一覧（新着順・非公開を含む・アルバムで絞り込み） | `MyPostsList`（マイページ） |
| 下書き（「下書き N 件」と最新 3 件・「続きを書く」） | `DraftsSection`（マイページ） |

**部品はそのまま動かす**（作り直さない）。

### 1-3. 名前を揃える

画面名・見出し・マイページの導線を「投稿履歴」にする。URL（`/my-map` など）は変えない（外部からのリンクを壊さないため。要件 3.6.5 の「URL 以外の文言」）。

## 成果物

- 投稿履歴の画面（タブの追加）
- `MyPostsList`・`DraftsSection` の移動
- 用語の置き換え
- テスト

## テスト要件

### 単体テスト
- 一覧タブが既定で出ること。地図タブに切り替えられること
- 一覧に自分の投稿と下書きが出ること
- マイページに投稿一覧・下書きが**出ないこと**

### E2Eテスト
- 実機でマイページ →「投稿履歴」→ 一覧・地図の切り替え
