# Task 2: 「行きたい」スポット一覧画面(SC-08)の実装

> 出典: [wishlist.md](../../../user-stories/records/wishlist.md)
> インデックス: [wishlist](00-index.md)

## 依存

- [Task 1: 「行きたい」保存・取消 Route Handler](01-wishlist-toggle-handler.md)

## 実装内容

- `GET /api/wishlist`を実装し、ログインユーザーが保存した全スポットを返す（投稿の有無を問わない）
- SC-08画面を実装し、一覧を表示する
- 投稿が存在しないスポットには、プレースホルダ画像を表示する

## 成果物

- `app/api/wishlist/route.ts`（GET）
- 「行きたい」スポット一覧画面（SC-08）

## テスト要件

### 単体テスト
- 投稿がないスポットに対し、プレースホルダ画像のパスが返ることを検証する

### 結合テスト
- テスト用DBで、投稿あり・なしのスポットが混在する一覧が正しく表示されることを確認する

### E2Eテスト
- なし（[Task 4: 受入テスト（E2E）](04-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 「行きたい」スポット一覧画面で、保存したスポットが一覧表示されること
- 投稿がないスポットにはプレースホルダ画像が表示されること
