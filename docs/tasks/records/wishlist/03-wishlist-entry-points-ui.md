# Task 3: 投稿カード一覧・投稿詳細からの保存導線UI

> 出典: [wishlist.md](../../../user-stories/records/wishlist.md)
> インデックス: [wishlist](00-index.md)

## 依存

- [Task 1: 「行きたい」保存・取消 Route Handler](01-wishlist-toggle-handler.md)

## 実装内容

- 投稿カード一覧画面（SC-04、`map-search`カテゴリのピン操作機能の成果物）、および投稿詳細画面（SC-05、`browsing`カテゴリの投稿詳細閲覧機能の成果物）に、「行きたい」保存ボタンを追加する
- ボタンはTask1のAPIを呼び出し、保存状態（保存済み／未保存）を視覚的に反映する
- 両画面が未実装の間は、ボタンコンポーネント単体として実装し、各画面側の統合はそれぞれのストーリー側のタスクで行う

## 成果物

- 「行きたい」保存ボタンコンポーネント（SC-04・SC-05へ組み込み可能な形）

## テスト要件

### 単体テスト
- 保存済み・未保存それぞれの状態で、ボタンの表示（アイコン・ラベル）が切り替わることを検証する

### 結合テスト
- SC-04・SC-05のいずれかが実装済みの状態で、ボタン押下によりTask1のAPIが呼び出され、状態が反映されることを確認する

### E2Eテスト
- なし（[Task 4: 受入テスト（E2E）](04-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 投稿カード一覧・投稿詳細のいずれからも、スポットを「行きたい」として保存・保存解除できること
