# Task 2: 地図コンポーネントの再利用・ピン種別統合

> 出典: [my-map.md](../../../user-stories/records/my-map.md)
> インデックス: [my-map](00-index.md)

## 依存

- [Task 1: マイマップ用ピンデータ取得 Route Handler](01-my-map-pin-data-handler.md)
- pin-display-rules [Task2: 地図コンポーネントへのピン種別表示の組み込み](../../shared-ui/pin-display-rules/02-map-pin-integration-interface.md)

## 実装内容

- マイマップ画面（SC-12）を実装し、`map-search`カテゴリの地図表示（F-MP-01）で構築される共通地図コンポーネントを、取得条件（Task1のAPI）のみ差し替えて再利用する
- Task1が返す各スポットの種別（`posted`／`wishlist`）を、pin-display-rulesのピン描画インターフェースに渡し、色・形状で区別されたピンを表示する
- 画面上部に表示切り替えUI（自分の投稿のみ／「行きたい」のみ／両方）を実装し、選択に応じてTask1の`mode`パラメータを切り替える

## 成果物

- マイマップ画面（SC-12）
- 表示切り替えUIコンポーネント

## テスト要件

### 単体テスト
- 表示切り替えUIの選択に応じて、Task1への問い合わせパラメータが正しく切り替わることを検証する

### 結合テスト
- モックのピンデータ（投稿済み・「行きたい」混在）を用いて、種別ごとに異なる色・形状で描画されることを確認する

### E2Eテスト
- なし（[Task 4: 受入テスト（E2E）](04-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- マイマップで、自分の投稿のみ／「行きたい」のみ／両方の表示切り替えができること
- 投稿済みピンと「行きたい」ピンが色・形状の両方で区別されること
