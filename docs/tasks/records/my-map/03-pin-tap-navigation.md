# Task 3: ピン操作時の遷移制御

> 出典: [my-map.md](../../../user-stories/records/my-map.md)
> インデックス: [my-map](00-index.md)

## 依存

- [Task 2: 地図コンポーネントの再利用・ピン種別統合](02-map-component-reuse-integration.md)

## 実装内容

- 投稿済みピンのタップ時、自分の投稿詳細画面（SC-05、`browsing`カテゴリの投稿詳細閲覧機能の成果物）へ遷移する
- 「行きたい」ピンのタップ時、投稿カード一覧画面（SC-04、`map-search`カテゴリのピン操作機能の成果物）へ遷移する
- 対象の遷移先画面が未実装の間は、遷移先パス（スポットID・投稿IDを含むルーティング）の生成までを実装範囲とする

## 成果物

- ピンタップ時の遷移ロジック

## テスト要件

### 単体テスト
- ピン種別（投稿済み／「行きたい」）に応じて、生成される遷移先パスが正しく分岐することを検証する

### 結合テスト
- 遷移先画面が実装済みの状態で、実際に正しい画面へ遷移することを確認する

### E2Eテスト
- なし（[Task 4: 受入テスト（E2E）](04-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 投稿済みピンをタップすると自分の投稿詳細へ、「行きたい」ピンをタップすると投稿カード一覧へ遷移すること
