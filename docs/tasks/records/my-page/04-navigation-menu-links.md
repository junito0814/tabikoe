# Task 4: 遷移メニュー（アルバム／マイマップ／「行きたい」／ステータスバッジ）の導線実装

> 出典: [my-page.md](../../../user-stories/records/my-page.md)
> インデックス: [my-page](00-index.md)

## 依存

- [Task 1: マイページ画面(SC-06)の基本レイアウト実装](01-my-page-layout.md)

## 実装内容

- 遷移メニューブロックに、アルバム一覧・マイマップ・「行きたい」スポット一覧・ステータスバッジへの4つの導線を実装する
- 各導線の遷移先は以下のとおり
  - アルバム一覧 → album（[album](../album/00-index.md)、F-RC-02）
  - マイマップ → [my-map](../my-map/00-index.md)（F-RC-06）
  - 「行きたい」スポット一覧 → [wishlist](../wishlist/00-index.md)（F-RC-05）
  - ステータスバッジ → badges カテゴリ `status-badges`（F-BG、別カテゴリのため本タスクでは導線のみ実装し、遷移先画面自体は当該ストーリー側で実装する）

## 成果物

- マイページの遷移メニューコンポーネント（4導線）

## テスト要件

### 単体テスト
- 各メニュー項目のタップ・クリックで、想定した遷移先パスへのナビゲーションが発火することを検証する

### 結合テスト
- 遷移先の各画面（アルバム一覧・マイマップ・「行きたい」一覧）が実装済みの状態で、実際に遷移できることを確認する。ステータスバッジ画面が未実装の間は、導線の表示のみを確認する

### E2Eテスト
- なし（[Task 5: 受入テスト（E2E）](05-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- 遷移メニューから、アルバム・マイマップ・「行きたい」スポット一覧・ステータスバッジのそれぞれへ遷移できること
