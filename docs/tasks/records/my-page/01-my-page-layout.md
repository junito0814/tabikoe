# Task 1: マイページ画面(SC-06)の基本レイアウト実装

> 出典: [my-page.md](../../../user-stories/records/my-page.md)
> インデックス: [my-page](00-index.md)

## 依存

- profile-edit [Task2: ユーザー名・アイコン編集UI](../../account/profile-edit/02-display-name-edit-ui.md)（表示するプロフィール情報の取得元）

## 実装内容

- SC-06のレイアウトを、プロフィール／サマリー／遷移メニュー／投稿一覧の4ブロックがこの順で並ぶ構成として実装する
- プロフィールブロックには、アイコン画像・ユーザー名・プロフィール編集画面（SC-07）への導線を表示する
- サマリー・遷移メニュー・投稿一覧の各ブロックは、Task2〜4の成果物を組み込むためのプレースホルダとして実装する

## 成果物

- マイページ画面コンポーネント（4ブロックのレイアウト枠組み）

## テスト要件

### 単体テスト
- プロフィールブロックが、ログインユーザーのアイコン・ユーザー名を正しく表示することを検証する

### 結合テスト
- テスト用ユーザーでログインし、マイページにプロフィール情報が反映されることを確認する
- プロフィール編集画面への導線が正しく機能することを確認する

### E2Eテスト
- なし（[Task 5: 受入テスト（E2E）](05-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- マイページに、プロフィール・サマリー・遷移メニュー・自分の投稿一覧がこの順で表示されること
