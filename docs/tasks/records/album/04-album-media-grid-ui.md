# Task 4: アルバム画面UI実装（投稿・写真動画のグリッド表示）

> 出典: [album.md](../../../user-stories/records/album.md)
> インデックス: [album](00-index.md)

## 依存

- [Task 1: アルバム詳細取得 Route Handler（投稿・写真・動画）](01-album-detail-handler.md)
- media-layout [Task1: 添付点数に応じたグリッドレイアウトコンポーネント実装](../../shared-ui/media-layout/01-grid-layout-component.md)

## 実装内容

- アルバム画面（SC-09）に、Task1で取得した投稿一覧を表示する
- 各投稿の写真・動画表示には、共通の`MediaGrid`コンポーネント（media-layout）を再利用する
- 投稿編集画面での旅行タイトル変更により投稿がアルバム間を移動できる旨（3.6.2「投稿の移動」）は、投稿編集画面（post-edit）側の導線であり、本タスクでは移動結果がアルバム画面に正しく反映されることのみ確認する

## 成果物

- アルバム画面の投稿一覧UI（`MediaGrid`統合）

## テスト要件

### 単体テスト
- 対象外（`MediaGrid`自体の単体テストはmedia-layoutで実施済み）

### 結合テスト
- テスト用DBで、写真・動画混在の投稿を含む旅行のアルバム画面が、正しいレイアウトで表示されることを確認する

### E2Eテスト
- なし（[Task 5: 受入テスト（E2E）](05-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- アルバム画面に、当該旅行の投稿・写真・動画・メンバー一覧が表示されること
- 投稿編集画面で旅行タイトルを変更すると、移動先の旅行のオーナー・メンバーである場合に限り投稿が移動すること
