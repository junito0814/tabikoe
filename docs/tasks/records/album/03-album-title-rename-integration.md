# Task 3: アルバム名変更（旅行タイトル変更UIの統合）

> 出典: [album.md](../../../user-stories/records/album.md)
> インデックス: [album](00-index.md)

## 依存

- trip-title [Task3: 旅行タイトル編集（アルバム名変更）Route Handler](../../posts/trip-title/03-trip-title-rename-handler.md)
- [Task 2: アルバムメンバー一覧の表示](02-album-members-list.md)

## 実装内容

- アルバム画面（SC-09）に、旧オーナー判定に基づく名称変更UIを実装する
- 変更処理自体はtrip-title Task3の`PATCH /api/trips/{id}`をそのまま呼び出す（オーナー判定もそちら側で実施済み）
- 画面側では、Task2で取得したメンバー一覧の`role`を参照し、オーナー以外には変更UIを表示しない

## 成果物

- アルバム画面の名称変更UIコンポーネント

## テスト要件

### 単体テスト
- `role`が`owner`でないメンバーには変更ボタンが表示されないことを検証する

### 結合テスト
- テスト用DBでオーナーが名称を変更し、アルバム画面・マイページ双方の表示に反映されることを確認する

### E2Eテスト
- なし（[Task 5: 受入テスト（E2E）](05-acceptance-e2e.md)でまとめて検証する）

## 関連する受入条件

- オーナーがアルバム名（旅行タイトル）を変更すると、紐づく全投稿の表示名に反映されること
- オーナー以外のユーザーはアルバム名を変更できないこと
