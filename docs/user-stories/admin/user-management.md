# 利用者の管理・非公開の復元・操作の記録（user-management）

> 出典: [requirement.md](../../requirement.md) 3.10.9「利用者の管理」・3.10.10「非公開にしたものと復元」・3.10.12「操作の記録」（2026-09-27）
> 要求定義書: [request.md](../../request.md) 変更点 16、3-1-9
> 見た目: https://claude.ai/artifact/KoY91teZdaTPQahdk2LEhM の 4・5・6・8

## ユーザーストーリー

運営する人として、通報された人が他にどんな投稿をしているか調べ、必要なら止め、間違えたら戻したい。そして自分（や他の管理者）が何をしたかを後から説明できるようにしたい。

## 背景（2026-09-27）

- 停止は通報経由でできるのに、**解除する手段がどこにも無かった**（Supabase の管理画面で列を直すしかない）
- 要件 3.10.5 に「非公開化は復元できる」とありながら、**復元する画面も API も無かった**
- 利用者を探す画面が無く、通報対応で「この人の他の投稿は？」を見られなかった
- 誰がいつ何を消したかの記録が無かった

## 詳細

- 利用者一覧（SC-24）：表示名・メールで検索。列は 表示名／登録日／最終利用／投稿数／通報された回数／有効なストライク／状態
- 利用者詳細（SC-24）：ストライクの履歴（取り消し）、投稿・コメント・通報された履歴・この人への操作、今の制限。停止（理由必須・公開投稿の一括非公開＝既定オン）・解除（理由必須）・仮停止の確定
- 非公開のもの（SC-25）：3 タブ（自動で非公開・管理者が非公開・停止で非公開）。復元は理由必須
- 操作の記録（SC-27）：管理者の操作と自動処理を 1 つの表に。絞り込み可。消せない
- 置かないもの：管理者への昇格、退会の代行、管理者を停止できない守り

## 受入条件

- [ ] 表示名・メールで利用者を探せ、状態とストライクが一覧で分かること
- [ ] 停止は理由が空だとできず、既定でその人の公開投稿がまとめて非公開になること
- [ ] 停止を解除でき、一括非公開にした投稿を戻せること
- [ ] 管理者が非公開にした投稿・コメントを一覧から復元できること。削除したものは出ないこと
- [ ] すべての操作（自動を含む）が操作の記録に残り、消せないこと
- [ ] ストライクを取り消すと有効な数が減り、記録に残ること
