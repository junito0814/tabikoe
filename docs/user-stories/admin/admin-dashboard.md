# F-AD-02 管理者ダッシュボード

> 出典: [requirement.md](../../requirement.md) 3.10.2（v2.6で新設）

## ユーザーストーリー

管理者として、ログイン後に最初に着地する画面から、お知らせ管理・通報一覧のそれぞれへすぐに移動したい。なぜなら、管理業務の入口を一箇所にまとめ、迷わず作業を始めたいから。

## 詳細

- 管理者ログイン（F-AD-01）成功後に最初に着地する画面（SC-16）。
- 表示内容は「お知らせ管理」「通報一覧・対応」への遷移ボタンのみとする。件数サマリー等の集計表示は本リリースでは設けない。
- アクセス制御はF-AD-01と同様、`is_admin`によって制御する（`is_admin`がfalse、または未ログインの場合は404）。

## 受入条件

- [ ] 管理者ダッシュボード（SC-16）に、お知らせ管理（SC-17）・通報一覧（SC-18）への遷移ボタンが表示されること
- [ ] 各ボタンから対応する画面へ正しく遷移できること
- [ ] `is_admin`がfalse、または未ログインの状態でダッシュボードのURLへ直接アクセスすると404が返ること
