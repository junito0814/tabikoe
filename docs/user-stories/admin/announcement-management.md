# F-AD-03 お知らせ管理

> 出典: [requirement.md](../../requirement.md) 3.10.3

## ユーザーストーリー

管理者として、全ユーザー向けのお知らせを作成・編集・削除したい。なぜなら、利用規約の変更等の重要な情報を、個別のメール送信を行うことなく全利用者に一斉に伝えたいから。

## 詳細

- お知らせ管理画面（SC-17）から、タイトル（100文字まで）・本文（2,000文字まで）・公開日時を入力して作成する。
- 保存すると同時に`system_announcements`テーブルへ登録され、全ユーザーの通知一覧（SC-14）に表示される。個人ごとにレコードを複製しない。
- 管理者は、配信済みのお知らせを編集・削除できる。
- 遷移元は管理者ダッシュボード（SC-16、F-AD-02）。
- 本ストーリーが担うのは`system_announcements`への作成・編集・削除（書き込み側）のみ。通知一覧画面での個人向け通知とのマージ表示（読み取り側）は、通知機能のnotification-list（F-NT-02、[notification-list.md](../notifications/notification-list.md)）が担当する。
- `system_announcements`テーブルは要件定義書5.2で定義が示されているが、他のどのタスクからもまだマイグレーションが作成されていないため、本ストーリーで新規に定義する。

## 受入条件

- [ ] タイトル・本文・公開日時を入力してお知らせを保存すると、`system_announcements`に登録されること
- [ ] 保存したお知らせが、全ユーザーの通知一覧（SC-14）に表示されること（表示自体の検証はF-NT-02側で行う）
- [ ] 配信済みのお知らせを編集・削除できること
- [ ] 管理者ダッシュボード（SC-16）からお知らせ管理画面（SC-17）へ遷移できること
