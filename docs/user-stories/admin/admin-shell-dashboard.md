## ユーザーストーリー

運営する人として、管理画面を開いた瞬間に「いま対応が要るもの」と「使われているか」が分かるようにしたい。通報を放置していないか、利用者が増えているかを、毎回一覧を開いて数えたくないから。

## 背景（2026-09-27）

- ダッシュボードは「お知らせ管理」「通報一覧」への 2 つのボタンだけだった（要件 3.10.2 は「集計表示は設けない」だった）
- 通報が来ても通知が無く、管理者が一覧を開かない限り気づけない
- 管理画面はスマホ幅で中央寄せの作りで、パソコンで使うと狭い

## 詳細

### 枠（3.10.2）
- パソコン：左に共通のメニュー 7 項目（ダッシュボード／通報一覧・対応／利用者／非公開のもの／お知らせ管理／規約管理／操作の記録）。通報・非公開には未対応の件数を赤い丸で
- スマホ：本体と同じ下のメニューバーに 5 項目。「その他」に非公開・規約・記録・サイトへ戻る
- 既存の 3 画面（ダッシュボード・お知らせ・通報）をこの枠に入れる

### ダッシュボード（3.10.3）
- 上段：未対応の通報 N 件（最古の日数）／自動で非公開の投稿 N 件／仮停止の確認待ち N 人。無くても帯は消さない
- 中段：利用者（累計・今週）／投稿（累計・今週）／スポット（累計・タビコエだけの場所）／使った人（今日・今週）
- 下段：最近の投稿 5 件／最近のスポット 5 件／通報が集中している対象
- 「使った人」のために `users.last_active_at` を **1 日 1 回だけ**更新する

### 管理者への通知（3.9.1）
- 新しい通報・自動非公開・仮停止のとき、管理者全員にアプリ内通知

## 受入条件

- [ ] 管理画面のどのページでも左（スマホは下）のメニューが出て、通報の未対応件数が見えること
- [ ] ダッシュボードに、未対応の通報の件数と最古の日数が出ること
- [ ] 利用者・投稿・スポット・使った人の数字が出て、今週の増分が分かること
- [ ] 最近の投稿・スポットが 5 件ずつ出て、「見る」で利用者向けの画面が新しいタブで開くこと
- [ ] 新しい通報が入ると管理者の通知一覧に届くこと
- [ ] 1 人が 1 日に何度アクセスしても `last_active_at` の更新は 1 回だけであること
