# F-AD-04 通報一覧

> 出典: [requirement.md](../../requirement.md) 3.10.4

## ユーザーストーリー

管理者として、寄せられた通報を対応状態・理由・対象種別・日時で絞り込みながら確認したい。なぜなら、優先度の高い通報から効率よく対応したいから。

## 詳細

- 通報一覧画面（SC-18）で、対応状態（未確認／確認中／対応済み（非公開化）／対応済み（削除）／問題なし）・通報理由・対象種別（投稿／写真・動画／感想／コメント／ユーザー／スポット／アルバム）・通報日時により絞り込んで確認できる。
- 一覧から通報詳細（通報された投稿・写真・動画・コメント等の内容）へ遷移して確認できる。
- 遷移元は管理者ダッシュボード（SC-16、F-AD-02）。
- `reports`テーブルの定義は、通報機能本体（F-SF-01、[safety/reporting](../../tasks/safety/reporting/00-index.md)）が所有する。本ストーリーは一覧・絞り込みの読み取り実装のみを対象とし、テーブル定義は再定義しない。

## 受入条件

- [ ] 対応状態・通報理由・対象種別・通報日時で通報一覧を絞り込めること
- [ ] 一覧から通報対象（投稿・写真・動画・コメント等）の内容を確認する画面へ遷移できること
- [ ] 管理者ダッシュボード（SC-16）から通報一覧画面（SC-18）へ遷移できること
