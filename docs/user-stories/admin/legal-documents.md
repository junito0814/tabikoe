# 規約管理（legal-documents）

> 出典: [requirement.md](../../requirement.md) 3.10.11「規約管理」・3.9.1「規約の改定」・7.4（2026-09-27）
> 要求定義書: [request.md](../../request.md) 変更点 16、3-1-9
> 見た目: https://claude.ai/artifact/KoY91teZdaTPQahdk2LEhM の 7・10

## ユーザーストーリー

運営する人として、利用規約と個人情報保護方針を管理画面で直して版を上げ、全員に改めて同意してもらいたい。
利用者として、自分が何に同意したのかをいつでも読めるようにしたい。

## 背景（2026-09-27）

- 利用規約・個人情報保護方針の**本文がどこにも存在しなかった**。同意画面（SC-20）にチェック欄はあるが、読めるページが無い
- どの版に同意したかを記録していなかった（`users.consented_at` の日時だけ）
- ストライク制・最終利用日の記録など、方針に書くべきことが増えた

## 詳細

- データ：`legal_documents`（kind＝terms|privacy, version, summary（変更の要点）, body（Markdown）, status＝draft|published, published_at, published_by）と `user_consents`（user_id, kind, version, agreed_at）
- 公開ページ `/terms`・`/privacy`：公開中の最新版。過去の版も読める。同意画面（SC-20）と SC-28 からリンク
- 管理画面（SC-26）：お知らせと同じ形。種類を切替、左で編集（版・変更の要点・本文）、右に版の一覧（下書き／公開中／過去、公開日、同意済み N／全 M 人）。下書き → 公開で版が上がる
- 公開すると：全員向けの通知「規約の改定」（1 件）を作り、次にアプリを開いた人に再同意画面（SC-30）を出す。同意するまで他の画面に進めない（登録途中の人を止めている `pending-signup` と同じ作り）
- 登録時の同意も `user_consents` に版付きで記録する

## 受入条件

- [ ] `/terms` と `/privacy` で公開中の本文が読め、同意画面からリンクされていること
- [ ] 管理者が下書きを作り、公開すると版が上がり、版の一覧に「同意済み N／M 人」が出ること
- [ ] 公開後に利用者がアプリを開くと再同意画面が出て、同意するまで他の画面に進めないこと
- [ ] 同意すると `user_consents` にその版が記録され、以後は出ないこと
- [ ] 新規登録時にも、同意した版が記録されること
