# 共通メニューバー

> 出典: [requirement.md](../../requirement.md) 4.2

## ユーザーストーリー

ログイン済みの利用者として、どの画面からでも共通のメニューバーを使って主要な画面（全体マップ・新規投稿・通知・マイページ）に素早く移動したい。なぜなら、画面ごとに移動方法を探す手間なく、一貫した操作でアプリを使いたいから。

## 詳細

- 全画面共通のメニューバー（トップページ・ログイン画面・管理画面を除く）に、以下の4項目を配置する：全体マップ（SC-02）、新規投稿（SC-03）、通知（未読件数バッジ付き、SC-14）、マイページ（SC-06）。
- マイマップ（SC-12）へはメニューバーからではなく、マイページ（SC-06）の遷移メニューから遷移する。
- 管理画面（SC-15〜18）はis_adminユーザーのみ、URL直接アクセスまたはプロフィール画面からの導線で到達する（一般ユーザーのメニューバーには表示しない）。
- SC-19（スポット手動登録）は、SC-03のスポット名入力ステップから候補なし時のみ開く（メニューバーには表示しない）。

## 受入条件

- [ ] トップページ・ログイン画面・管理画面を除く全画面で、共通メニューバーが表示されること
- [ ] メニューバーから全体マップ・新規投稿・通知・マイページへ遷移できること
- [ ] 通知アイコンに未読件数バッジが表示されること
- [ ] 一般ユーザーのメニューバーに管理画面への導線が表示されないこと
- [ ] is_adminユーザーがプロフィール画面等の導線から管理画面へ到達できること
