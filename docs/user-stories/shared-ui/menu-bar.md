# 共通メニューバー

> 出典: [requirement.md](../../requirement.md) 4.2（v3.0で変更）

## ユーザーストーリー

ログイン済みの利用者として、どの画面からでも「さがす・しおり・通知・マイページ」に 1 タップで移動したい。なぜなら、旅行前は探す、旅行中はしおりを見る、という主な用途にすぐ届いてほしいから。

> v1 で実装済みの `menu-bar-config` と `MenuBar` を差し替える。

## 詳細

- 全画面共通のメニューバーを画面下部に置く（SC-00 の未ログイン表示・ログイン画面・アカウント新規作成画面・管理画面を除く）。項目は 4 つ：さがす（SC-00）、しおり（SC-22）、通知（未読件数バッジ付き、SC-14）、マイページ（SC-06）。
- 「地図」「投稿」は置かない。地図へは SC-00 の「近くのスポットを探す」と投稿カード・詳細の「地図で見る」、投稿へは SC-00 の「いまいる場所に投稿する」と各入口（[post-entry-points](../posts/post-entry-points.md)）から遷移する。
- パソコン幅では同じ 4 項目を左サイドバーに縦に並べる。
- マイマップ・行きたい・アルバム・バッジへはマイページの遷移メニューから。管理画面は一般ユーザーのメニューバーに表示しない。

## 受入条件

- [ ] メニューバーが「さがす・しおり・通知・マイページ」の 4 項目で、パソコン幅では左サイドバーになること（受入条件44）
- [ ] 未ログインの検索トップ・ログイン・新規作成・管理画面ではメニューバーが表示されないこと
- [ ] 通知アイコンに未読件数バッジが表示されること
- [ ] メニューバーに地図・投稿・管理画面への導線が無いこと
