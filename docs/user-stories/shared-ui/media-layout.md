# 写真・動画の表示レイアウト

> 出典: [requirement.md](../../requirement.md) 4.5.1

## ユーザーストーリー

投稿の閲覧者として、投稿に添付された写真・動画の枚数に応じて見やすいレイアウトで閲覧したい。なぜなら、枚数によらず一目で内容を把握できるようにしたいから。

## 詳細

- 表示レイアウトは添付点数に応じて変化する：1点＝全幅表示、2点＝左右2分割、3点＝左に1点（大）＋右を上下2分割、4点以上＝2×2グリッド。
- 5点目以降は、2×2グリッドの右下枠に「+N」の枚数バッジを重ねて表示する。
- 1点目を代表画像とし、グリッド内では左上（または最も大きい枠）に配置する。
- 動画はサムネイル画像（先頭フレーム）の中央に再生アイコンを重ねて表示し、写真と区別する。並び替え・代表画像の判定・枚数バッジの扱いは写真と同一のルールに従う（動画が1点目であれば代表サムネイルとなる）。
- タップすると、投稿詳細画面内でインライン再生する。

## 受入条件

- [ ] 添付点数が1／2／3／4点以上の各パターンで、規定のレイアウト（全幅／2分割／3分割／2×2グリッド）が適用されること
- [ ] 5点目以降で「+N」バッジが右下枠に表示されること
- [ ] 1点目が代表画像として左上（または最大枠）に表示されること
- [ ] 動画サムネイルに再生アイコンが重畳表示され、写真と視覚的に区別できること
- [ ] 動画タップで投稿詳細画面内にインライン再生されること
