# 上部の地図の操作とシートの 3 段階（map-sheet）

> 出典: [requirement.md](../../requirement.md) 4.5.6「上 1/3 地図＋下 2/3 シートの操作」・4.5.8「上部の地図の操作と拡大縮小ボタン」（2026-09-25 決定）
> 前身: [feedback-0919.md](feedback-0919.md) の「シートのドラッグ」（v3.2。2 段階）

## ユーザーストーリー

投稿を見ている人として、上の地図をその場で拡大・縮小して位置を確かめたい。全画面の地図に移ってから戻ってくるのは手間だから。地図をもっと広く見たいときは、下の内容を下げて地図を広げたい。

## 背景（2026-09-25、実機での確認）

- 上部の地図は「見るだけ」で、指では何もできない。位置を確かめるには全画面の地図に移るしかない。
- 地図全体がリンクになっていて、触るとすぐ全画面に移ってしまう。
- スマホでは地図の拡大縮小ボタン（＋ −）が画面を狭くしている。指 2 本で操作できれば要らない。

## 詳細

### 上部の地図（4.5.8）

- **2 本指で拡大・縮小・移動できる**。1 本指のドラッグでは動かさない（画面の縦スクロールを邪魔しないため）。
- 全画面の地図（SC-02）への入口は、右下の**ボタンだけ**にする。地図全体のタップは廃止する（2 本指の操作中にタップと判定されて意図せず移動するため）。
- 拡大・移動したあとは、そのボタンの隣に「戻す」を出す（そのスポットを中心とした初期表示に戻る）。
- 上部の地図に拡大縮小ボタン（＋ −）は出さない（領域が狭いため）。

### 拡大縮小ボタン（4.5.8）

- 全画面の地図（SC-02）では、**指で触れる端末（スマホ・タブレット）では出さない**。パソコンでは出す。
- 判定は画面の幅ではなく「指で触れるか」（`(pointer: coarse)`）で行う。幅で判断すると、小さな窓で開いたパソコンからボタンが消えてしまう。

### シートの 3 段階（4.5.6）

- 下から順に **地図 2/3・シート 1/3** ／ **地図 1/3・シート 2/3（既定）** ／ **全画面**。
- 地図を広くしたときは、シートに見出しの 1 行だけを出す（スポット別＝スポット名・★・件数、投稿詳細＝スポット名・★・訪問日、しおり＝しおり名・Day）。
- SC-03（投稿作成・編集）だけは **2 段階のまま**（入力中に地図が広がると打ちにくいため）。
- 取っ手は Enter／Space でも次の段階へ進む（いちばん上まで行ったら既定に戻る）。

## 受入条件

- [ ] 投稿詳細・スポット別一覧の上部の地図を 2 本指で拡大・縮小・移動できること。1 本指では画面が縦にスクロールすること
- [ ] 地図を触っても全画面に移らず、右下のボタンを押したときだけ移ること
- [ ] 上部の地図で拡大したあと「戻す」で初期表示に戻ること
- [ ] スマホでは全画面の地図に「＋ −」が出ず、パソコンでは出ること
- [ ] シートが 3 段階で吸い付き、地図を広くしたときに見出しの 1 行が見えること。SC-03 は 2 段階のままであること
