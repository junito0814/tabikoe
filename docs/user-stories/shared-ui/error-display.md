# エラー表示

> 出典: [requirement.md](../../requirement.md) 4.5.4（関連: 6.1〜6.5）

## ユーザーストーリー

利用者として、外部サービス（地図・検索・認証・DB等）に障害が発生した場合、状況を理解できるエラーメッセージを画面上で確認したい。なぜなら、原因不明のまま操作に詰まることを避けたいから。

## 詳細

外部サービス障害時の表示は6章の定義に従う。

- Google Maps JavaScript API障害時：地図エリアに「地図を読み込めませんでした」と表示する
- Google Places API障害時：「スポット検索が一時的に利用できません」と表示する。この場合もSC-19（手動登録）は利用可能とする
- OAuth認証障害時：「ログインに失敗しました。時間をおいて再度お試しください」と表示する
- Supabase（DB）障害時：「データを読み込めませんでした。時間をおいて再度お試しください」と表示し、再読み込みボタンを設ける

## 受入条件

- [ ] 地図読み込み失敗時、地図エリアに規定のエラーメッセージが表示されること
- [ ] スポット検索API障害時、規定のエラーメッセージが表示され、SC-19（手動登録）は引き続き利用できること
- [ ] OAuth認証失敗時、規定のエラーメッセージが表示されること
- [ ] DB読み込み失敗時、規定のエラーメッセージと再読み込みボタンが表示されること
