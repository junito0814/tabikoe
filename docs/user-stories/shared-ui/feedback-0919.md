# 画面遷移マップの見直しで出た追加要望（v3.2）

> 出典: [requirement.md](../../requirement.md) 「本改訂（v3.1 → v3.2）の変更点」、[request.md](../../request.md) 「v2 改訂（2026-09-19）」、[wireframes.md](../../wireframes.md) 決定事項 38〜45

## ユーザーストーリー

利用者として、まだ知られていない場所を登録したことが実績として残り、宿泊のような長い滞在も正しく記録でき、写真から気になった投稿へすぐ飛べ、旅の仲間をアプリの中で招待でき、移動手段に合わせて近くのスポットを探せ、コメントで会話ができる体験がほしい。なぜなら、全 67 画面の遷移マップを見直して「登録を頑張っても報われない」「宿泊が入力できない」「写真を見たあと投稿へ戻るのが手間」「招待にリンクの受け渡しが要る」「徒歩以外の距離感が分からない」「コメントに返事ができない」と感じたから。

> v3.1（メンタリング 7 回目）の反映（#421）の後に行う。データ構造の変更は spots.created_by・comments.parent_id・招待テーブルの invitee_user_id と滞在時間の CHECK 制約。

## 詳細

- **スポット登録バッジ**：「タビコエだけの場所」（spots.source = manual）を自分が最初に登録した件数で 1／3／5／10／20／30／50 件の 7 段階。spots.created_by を追加し、既存行は最も古い公開投稿の投稿者で埋める。判定は投稿の公開処理の中で、トーストで知らせる（通知一覧には残さない）。
- **滞在時間 7 択**：30分以内／1時間以内／2時間以内／3時間以内／半日／1日／宿泊。必須のまま。カテゴリ「宿泊施設」を選んだとき未選択なら「宿泊」を自動で入れる（変更可）。既存の「それ以上」は残し、絞り込みでは半日／1日／宿泊のどれを選んでも含める。絞り込みシートも 7 択。
- **写真タブのモーダル**：写真タブ（検索結果・スポット別）の写真をタップするとモーダルで開き、下部に情報バー（スポット名・★・滞在時間・費用・投稿者・訪問日）と「この投稿を見る →」。左右で前後へ。投稿詳細内のモーダルは写真の拡大だけ。投稿カード内の写真は投稿詳細へ直接のまま。
- **アプリ内招待**：しおり・アルバムの招待画面に「一緒だった人」の候補（同じアルバム・しおりに入ったことがある人。自分・既存メンバー・ブロック関係を除く）と、ユーザー名の部分一致検索（2 文字以上・最大 20 件）を置き、相手を選んで送る。招待テーブルに invitee_user_id・status・responded_at を追加。相手の通知一覧に「〈名前〉さんがしおり『…』に招待しました [参加する] [辞退]」が届き、参加するとメンバーに。オーナーは未回答の招待を取り消せる。招待リンクは併存。
- **移動手段**：探すモードの「徒歩圏 ▾」を「移動手段 ▾」（徒歩 1km・80m/分／自転車 3km・250m/分／車 10km・500m/分）にし、半径とカードの分数表示（「徒歩 6 分」「自転車で約 8 分」「車で約 12 分」）を連動させる。直線距離 ÷ 速度の目安で経路 API は呼ばない。**（2026-09-25 に変更。電車・バスを追加し、車・電車・バスは Routes API の実測、自転車は 180m/分に。[travel-time.md](../map-search/travel-time.md) を正とする）**地図の状態の復元に含める。
- **コメントへの返信**：comments.parent_id を追加。各コメントに「返信」、押すと入力欄に「@名前」が入る。返信は親の下に 1 段だけ字下げして時系列に平らに並べ、先頭に「@名前 への返信」。3 件を超えたら「返信をさらに N 件見る」。返信先の人に通知（comment_replied）。親を削除しても返信は残し「削除されたコメント」の枠を出す（論理削除）。
- **コメントのプレビュー**：スポット別の投稿カードに最新のコメント 1 件（投稿者名＋冒頭 1 行）と「コメント N 件をすべて見る」（返信を含む件数）。押すとカード直下のコメント欄が展開する。
- **シートのドラッグ**は v3.1 の Task 11（#421 配下）で共通部品として作り、本ストーリーでは使うだけ。

## 受入条件

- [ ] Google マップに無い位置で新しくスポットを作って投稿すると、スポット登録バッジが判定されトーストが出ること。Places 由来のスポットへの投稿では数えないこと（受入条件72）
- [ ] 滞在時間が 7 択で、カテゴリ「宿泊施設」を選ぶと未選択の滞在時間に「宿泊」が入り変更できること。既存の「それ以上」がそのまま表示され、絞り込みで「半日」を選ぶと含まれること（受入条件71）
- [ ] 写真タブの写真をタップするとモーダルが開き、情報バーと「この投稿を見る →」が出て、投稿詳細へ移れること。投稿詳細内のモーダルには情報バーが出ないこと（受入条件73）
- [ ] しおり・アルバムの招待画面で候補または検索から相手を選んで送ると、相手の通知一覧に届き「参加する」でメンバーになれること。辞退・取り消しができ、招待リンクも使えること（受入条件74）
- [ ] 探すモードで移動手段を切り替えると半径と分数表示が変わり、地図に戻ったとき移動手段も復元されること（受入条件75）
- [ ] コメントに返信でき、1 段字下げで「@名前 への返信」付きで並び、3 件超で折りたたまれ、返信先に通知が届き、親を削除しても枠が残ること（受入条件77）
- [ ] スポット別の投稿カードに最新コメント 1 件と「コメント N 件をすべて見る」が出て、押すとコメント欄が展開すること（受入条件78）
