# ピンをしずく型にし、カテゴリで見分けられるようにする（pin-categories）

> 出典: [requirement.md](../../requirement.md) 4.5.3「ピンの表示ルール」（2026-09-26 全面改訂）
> 要求定義書: [request.md](../../request.md) 「v2 改訂（2026-09-19）」変更点 14
> 前身: [pin-display-rules.md](pin-display-rules.md)（v3.0。色で状態を表していた版）

## ユーザーストーリー

地図を見ている人として、ピンが何の場所なのかを開く前に知りたい。ご飯の店を探しているときに、泊まる場所や買い物の場所まで同じ見た目で並んでいると、1 つずつ開いて確かめることになるから。

## 背景（2026-09-26）

- **投稿のピンと現在地がまったく同じ青**（`#2F7FD8`）だった。「青い丸の中が白」と「青い丸を白が囲む」の違いしかなく、見分けが付かない。
- ピンの色は「状態」を表していた（青＝みんなの投稿、赤＝保存済み）。カテゴリは地図では一切分からなかった。
- Google マップは「色と記号＝カテゴリ、バッジ＝保存の状態」と軸を分けている。色でカテゴリを表すなら、状態は色から降ろす必要がある。

## 決めたこと

### 形で現在地と分ける

スポットのピンは**しずく型**（下がとがった地図ピン。先端が実際の座標を指す）、現在地は**丸い点**のまま。
形が土台なので、色が見分けられない人にも区別できる。

### 色と記号でカテゴリを表す（7 つ）

| カテゴリ | 記号 | 明るいテーマ | 暗いテーマ |
|---|---|---|---|
| グルメ | フォークとナイフ | `#E2703A` | `#F08C5A` |
| 観光スポット | カメラ | `#C4478C` | `#DB6DA8` |
| 自然・景勝地 | 山 | `#3C8C5E` | `#5BAE7C` |
| 体験・アクティビティ | 旗 | `#7A57D1` | `#9B7FE6` |
| エンタメ・イベント | チケット | `#D8425F` | `#EE6B84` |
| ショッピング | 買い物袋 | `#0E93A0` | `#35B2BE` |
| 宿泊施設 | ベッド | `#9A6B33` | `#BE8C52` |
| カテゴリ無し | 点 | `#7B8794` | `#8B97A6` |

- 7 色とも**現在地の青とは違う色**にする。観光スポットは Google なら水色だが、現在地と近くなるのでピンクにした。
- **どのピンにも記号を入れる**（要件定義書 7.7「色だけに依存しない」）。色が見分けられなくても記号で分かるようにする。
- 見た目の確認用ページ: https://claude.ai/artifact/8aYEDqzbAkfmSdWPGeAdQ3

### 状態はバッジと縁に移す

| 状態 | 見せ方 |
|---|---|
| 保存済み | カテゴリの色のまま、右肩に赤いハートのバッジ |
| 自分の投稿がある | カテゴリの色のまま、右肩に緑のチェックのバッジ |
| 下書き | 灰色の破線のしずく |
| フォーカス | そのピンの色の淡い輪を外側に付ける |

バッジは 1 つだけ。保存済みと投稿済みの両方なら保存済み（ハート）を優先する。

### スポットのカテゴリの決め方

カテゴリは**投稿の属性**なので、1 つのスポットに違うカテゴリの投稿が混ざる。

- **そのスポットの公開投稿でいちばん多いカテゴリ**
- **同数なら新しい方**（最後に投稿された方）
- 公開投稿が無ければ「カテゴリ無し」の灰色

### 変えないもの

- 現在地の青い点
- しおりの番号ピン（Day の色＋番号）。しおりの地図ではカテゴリ色を使わない
- クラスタ（濃色の丸＋件数）

## 受入条件

- [ ] 地図のピンがしずく型になり、現在地の青い点と一目で区別できること
- [ ] ピンの色と記号がそのスポットのカテゴリを表していること
- [ ] 保存済みのスポットに赤いハートのバッジが付き、色はカテゴリのままであること
- [ ] 下書きが灰色の破線のしずくのままであること
- [ ] しおりの地図では今までどおり番号ピンが出ること
- [ ] 明るいテーマ・暗いテーマのどちらでもピンが地図に沈まないこと
- [ ] ピンの先端が実際の座標を指していること（ピンが座標の上にずれて立つこと）
