# 配色とダークモード

> 出典: [requirement.md](../../requirement.md) 4.5.5, 7.7（v3.0で新設）。色の値は [wireframes.md](../../wireframes.md)「配色」を正とする

## ユーザーストーリー

利用者として、昼は空のような明るい配色、夜は OS のダーク設定に合わせた見やすい配色でアプリを使いたい。なぜなら、旅先では屋外でも夜でも地図と投稿を見るから。

## 詳細

- 基本方針：「旅＝空」のイメージで空の青をメインにする。
- ライト：検索トップ（SC-00）だけ背景上部に空のグラデーション（`#BFDDF7` → `#E4F1FC` → `#F3F8FD`）、他の画面は白地。文字は紺（`#1E2A38`）、薄い文字 `#7B8794`、罫線 `#D9E4EF`、淡い面 `#F3F8FD`。アクセント（主要ボタン・リンク・バッジ・選択状態・みんなの投稿のピン）は空の青 `#2F7FD8`（押下 `#1F65B8`）、保存済みのピンは赤 `#D9414A`、完了・チェックは緑 `#3D7A5C`、星は黄 `#F2B233`。
- ダーク：OS の設定（`prefers-color-scheme: dark`）に追従して自動で切り替える。アプリ内の切替は設けない。下地 `#0B1220`、面 `#161E2B`、文字 `#E6EDF5`、薄い文字 `#8B97A6`、罫線 `#263142`、淡い面 `#1C2634`、アクセント `#5AA2F0`（押下 `#3F8BE0`）、保存済み `#F06B72`、完了 `#4CAF7D`。SC-00 のグラデーションは夜空（`#0E1E3D` → `#0B1220`）。地図は Google マップのダークスタイル。
- 実装：色は `src/app/globals.css` の CSS 変数（`--color-*`）に集約し、コンポーネントに 16 進を直書きしない（現状の直書き 400 箇所超を置き換える）。ダークは `@media (prefers-color-scheme: dark)` での変数の再定義で実現する。
- 主要ボタンは 1 画面 1 つ（SC-00＝いまいる場所に投稿する、SC-04＝地図で見る／＋、SC-03＝投稿する、SC-23＝投稿する）をアクセント色で塗り、それ以外は白地（ダークでは面色）に枠線。
- 両モードで文字と背景・ボタンのコントラスト比を 4.5:1 以上にする。
- 共通ルール：戻るは左・削除は右、星評価は黄色＋「星4」の文字、並び替えは 1 ボタンのドロップダウン、「今何を見ているか」を画面上部に常時表示する。

## 受入条件

- [ ] OS をダークモードにすると全画面がダーク配色に切り替わり、地図もダークスタイルになること。両モードで文字とボタンが読めること（受入条件68）
- [ ] 検索トップだけにグラデーション背景があり、他の画面が白地（ダークでは紺寄りの黒）であること
- [ ] コンポーネントに 16 進の色が直書きされておらず、CSS 変数を参照していること（lint または grep で検証）
- [ ] 主要ボタン・リンク・バッジ・みんなの投稿のピンがアクセント色、保存済みのピンが赤で描画されること
- [ ] 両モードで本文・ボタンのコントラスト比が 4.5:1 以上であること
