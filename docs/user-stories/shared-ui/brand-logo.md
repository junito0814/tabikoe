# ロゴとファビコン（brand-logo）

> 出典: [requirement.md](../../requirement.md) 4.5.9「ロゴとファビコン」（2026-09-26 決定）
> 要求定義書: [request.md](../../request.md) 「v2 改訂（2026-09-19）」変更点 12、3-1-10「ロゴは 1 つの形で通す」

## ユーザーストーリー

アプリを使う人として、タブやホーム画面に並んだたくさんのアイコンの中から、タビコエをひと目で見つけたい。今は初期状態のままの黒いアイコンなので、他のタブと見分けが付かないから。

## 背景（2026-09-26）

- ブラウザのタブに出るファビコンが **Next.js の初期状態のまま**で、アプリと関係のない形だった。
- ログイン画面のロゴは間に合わせで作ったもので、何を表しているのかが決まっていなかった。
- スマホのホーム画面に追加したときのアイコン（180 ピクセル）が無く、文字だけの味気ない表示になっていた。

## 形の決め方

- 伝えたいのは **コエ（声）とタビ（旅）の 2 つ**。吹き出しで「声」、下に伸びる尾と広がる輪で「そこへ行く・伝わっていく」を表す。
- **16 ピクセル角で形が残るか**を唯一の基準にした。ファビコンはタブの端にその大きさで出るため、そこで読めない要素は入れない。
- そのため次の案は外した。
  - 文字（タ・t・v）を組む案 … 16 ピクセルでは読めず、黒い汚れに見える
  - 吹き出しの中に点を 3 つ置く案 … メッセージアプリの「入力中」の印そのもので、他のアプリと見分けが付かない

## 詳細（4.5.9）

- 地は**角丸 20 の正方形・`#2F7FD8`**（空の青。配色のアクセントと同じ）。
- 中心に**白い丸い吹き出し**（円＝中心 (36, 32.8)・半径 11.5）と、**下中央に伸びる尾**（付け根 (32, 42)–(40, 42)、先端 (36, 51)）。尾は地図のピンにも読める。
- そのまわりに**広がる 2 本の輪**（内側＝半径 22・白 60%・太さ 4.2／外側＝半径 30・白 28%・太さ 3.6）。声が伝わっていく波紋を表す。
- 吹き出しは**どの向きでも輪に触れない**（中心から吹き出しの縁まで 11.5〜15、内側の輪の内縁 19.9）。触れると 16 ピクセルでつながって 1 つの塊に見える。
- **ロゴ・ファビコン・ホーム画面のアイコン・ログイン画面のロゴはすべて同じ形**を使い、大きさによって形を変えない。
- ダークモードでも地の青と輪の白の薄さは変えない（暗い背景でも明るい四角として見えるため）。

## 受入条件

- [ ] ブラウザのタブにタビコエのアイコンが出ること（Next.js の初期状態の黒いアイコンが残っていないこと）
- [ ] スマホのホーム画面に追加したときに 180 ピクセルのアイコンが出ること
- [ ] ログイン画面（SC-01）と未ログインのホーム（SC-00）のロゴが、ファビコンと同じ形であること
- [ ] 16 ピクセルに縮めても吹き出しと輪が分かれて見え、1 つの塊にならないこと
- [ ] ライト・ダークのどちらでもロゴが背景に溶けずに見えること
