# ピンの表示ルール

> 出典: [requirement.md](../../requirement.md) 4.5.3（v3.0で変更。関連: 3.4.3, 3.6.5, 3.11.6）

## ユーザーストーリー

地図を見る利用者として、ピンが「みんなの投稿」「保存済み」「下書き」「しおりの何番目」のどれかを色と形で一目で見分けたい。なぜなら、タブを切り替えずに 1 つの地図で判断したいから。

> v1 で実装済みの `pin-marker-icon.ts`／`PinIcon` を拡張する。ピンの取得・描画は [map-display](../map-search/map-display.md)・[my-map](../records/my-map.md)・[itinerary-map-and-post](../itinerary/itinerary-map-and-post.md) が本ルールを組み込む。

## 詳細

| 種別 | 色・形 | 対象 | 表示箇所 |
|---|---|---|---|
| みんなの投稿 | 青（アクセント色）の丸 | 公開投稿があるスポット | SC-02、SC-03 上部 |
| 保存済み | 赤のひし形 | 自分の行きたいスポット、自分がオーナーまたはメンバーのしおりのスポット | SC-02、SC-08（地図）、SC-12 |
| 投稿済み | 青の丸＋チェック | 自分の投稿があるスポット | SC-12 |
| 下書き | 灰色の破線の丸 | 自分の下書き（本人のみ） | SC-02、SC-12 |
| フォーカス | 青の丸＋淡い輪 | 「地図で見る」で開いた対象スポット、探すモードでめくったカードのスポット | SC-02 |
| 番号ピン | Day ごとの色＋訪問順の番号。済みは灰色 | しおりのスポット | SC-02（しおり表示） |
| クラスタ | 濃色の丸＋件数 | 同一エリアに集中したピン | SC-02、SC-12 |
| 現在地 | Google マップ標準の青い点と精度の円 | 端末の現在地 | 全ての地図 |

- 優先順位：SC-02 では 保存済み ＞ みんなの投稿、SC-12 では 投稿済み ＞ 保存済み。
- 凡例（種別の色と名前）を地図上に常時表示する。色だけに依存しないよう形状も変える。
- 色の値は [theme](theme.md) の CSS 変数から取り、ライト／ダークで切り替わる（ダークの保存済みは `#F06B72`）。

## 受入条件

- [ ] 8 種別のピンが表の色・形で描画され、色だけでなく形状でも判別できること
- [ ] SC-02 で保存済みがみんなの投稿より優先され、SC-12 で投稿済みが保存済みより優先されること
- [ ] 凡例が地図上に常時表示されること（受入条件47）
- [ ] ダークモードでピンの色が切り替わり、地図上で読めること（受入条件68）
