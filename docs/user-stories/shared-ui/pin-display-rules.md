# ピンの表示ルール

> 出典: [requirement.md](../../requirement.md) 4.5.3（関連: 3.4.1, 3.6.5）

## ユーザーストーリー

マップ利用者として、地図上のピンが「通常投稿」「行きたい」「投稿済み」のどれを示しているかを色や形状で判別したい。なぜなら、一目でスポットの状態を把握して行動を判断したいから。

## 詳細

- ピン種別と表示箇所：
  - 通常：公開投稿があるスポット → SC-02（「全体」タブ）
  - 「行きたい」：自分が「行きたい」保存したスポット → SC-02（「行きたい」タブ）、SC-12
  - 投稿済み：自分の投稿があるスポット → SC-12
- ピンの区別は色および形状・アイコンの両方で行い、色のみに依存しない（7.7 アクセシビリティ準拠）。

> 本ストーリーはピンの視覚的区別ルール（アイコン・色定義）を対象とする。ピンの取得・地図表示ロジック自体は、地図・検索機能（F-MP-01）およびマイマップ機能（F-RC-06）の実装時に本コンポーネントを組み込む前提とする。

## 受入条件

- [ ] SC-02「全体」タブで、公開投稿があるスポットが通常ピンとして表示されること
- [ ] SC-02「行きたい」タブで、「行きたい」保存したスポットのみがピン表示されること
- [ ] SC-12（マイマップ）で、投稿済みピンと「行きたい」ピンが色・形状の両方で区別されること
- [ ] ピンの区別が色のみに依存していない（形状・アイコンでも判別できる）こと
