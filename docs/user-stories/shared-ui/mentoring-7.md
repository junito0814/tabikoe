# メンタリング 7 回目の反映（v3.1）

> 出典: [requirement.md](../../requirement.md) 「本改訂（v3.0 → v3.1）の変更点」、[request.md](../../request.md) 「v2 改訂（2026-09-18）」、[wireframes.md](../../wireframes.md) 決定事項 25〜37

## ユーザーストーリー

利用者として、どの画面でも同じ言葉で同じものが呼ばれ、行き先を調べたときに「どんな場所があるか」がスポット単位で分かり、詳細を見ながら地図で位置を確かめ、地図に戻っても見ていた場所がずれない体験がほしい。なぜなら、実際に触ってみて「言葉が揺れる」「同じスポットの投稿が並んで見づらい」「地図と詳細を行き来すると迷子になる」と感じたから。

> Phase 10〜14 で実装した v3.0 の画面を、2026-09-18 のメンタリングの指摘に沿って直す。データ構造の変更は「日常」アルバムだけ。

## 詳細

- **用語の統一**：「旅行タイトル」→「アルバム」、「マイマップ」→「あしあと」、「近くの声」→「近くのスポット」、「いまいる場所に投稿する」→「ここを投稿」、しおりの「未定」→「ALL」。検索トップの案内文を削除。行きたいの「解除」はゴミ箱マーク。下書きは 3 件＋「すべて見る」。
- **「日常」アルバム**：アルバム欄が空の投稿は 1 人 1 つの「日常」アルバムへ（自動作成、名前変更・削除・招待・しおり不可、アルバム一覧の先頭に固定）。仮タイトル「今日の投稿（M/D）」と付け直し促しは廃止。
- **検索結果はスポット単位**：スポットカード（スポット名・代表写真・★の平均・投稿件数・徒歩 N 分・まだあった・最新の感想 1 行・「＋」）。並び替えは 新着順／評価順／投稿数順。
- **上 1/3 に地図**：スポット別の投稿一覧・投稿詳細・しおり詳細（「地図で見る」を押したとき）は、上 1/3 に見るだけの地図、下 2/3 にシート（1：2）。「地図で見る」ボタンは廃止し、地図のタップで SC-02 へ。
- **写真タブ**：検索結果は 1 スポットにつき新しい投稿から 5 枚まで、スポット別は全部。写真（カード内の写真も）のタップは投稿詳細へ直接。モーダルは投稿詳細内のみ。
- **地図**：吹き出しの「一覧」ボタンを廃止し本体タップで一覧へ。左上の戻るは戻り先の画面名。地図に戻ったときは直前の地図の状態（中心・ズーム・モード・徒歩圏）を復元する。
- **しおり詳細**：ALL タブ（左端）、期間は年つき、期間・タイトルはタップで編集（カレンダー・鉛筆）、値段の表示を削除、並べ替えはドラッグ、「地図で見る」は上 1/3 に地図を出して下に一覧を残す。
- **しおり一覧・アルバム**：終わったしおりは薄くせず「済」の印、先頭に行きたいの入口。アルバム画面の「名前を変更」は廃止（名前はしおり詳細のタイトルから。しおりが無いアルバムはアルバム画面のタイトルをタップ）。

## 受入条件

- [ ] 「旅行タイトル」「マイマップ」「近くの声」「いまいる場所に投稿する」「未定」の文言が画面のどこにも出ないこと
- [ ] アルバム欄を空で投稿すると「日常」アルバムに入り、「日常」は名前変更・削除・招待・しおり作成ができないこと
- [ ] 検索結果がスポット単位のカードで、タップするとスポット別の投稿一覧（上 1/3 地図）が開くこと（受入条件45）
- [ ] 検索結果の写真タブが 1 スポット 5 枚までで、写真のタップで投稿詳細が開くこと
- [ ] 投稿詳細の上 1/3 に地図があり、タップすると SC-02 がそのスポット中心で開くこと。左上の戻るに戻り先の画面名が出ること
- [ ] 地図 → 詳細 → 戻る、で直前の地図の中心・ズームが復元されること（受入条件46）
- [ ] しおり詳細で ALL タブが左端にあり、期間に年が出て、期間・タイトルの表示をタップして編集でき、値段が表示されず、時刻の無い行をドラッグで並べ替えられること（受入条件58・62）
- [ ] しおり一覧で終わったしおりに「済」が付き薄くならず、先頭に行きたいの入口があること。行きたいの各行にゴミ箱マークがあること
