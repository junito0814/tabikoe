# 写真・動画ビューア（モーダル表示）

> 出典: [requirement.md](../../requirement.md) 4.5.5（v2.10で追加）、要求定義書「写真をタップすると、その写真を起点にフルスクリーン表示し、左右スワイプで閲覧できる」

## ユーザーストーリー

投稿の閲覧者として、どの画面でも写真・動画をタップすればその場で大きく見たい。複数枚ある投稿は、モーダルの中で←→を押して次の写真・動画に進みたい。なぜなら、投稿詳細へ遷移したり戻ったりせずに、写真・動画だけをさっと見比べたいから。

## 詳細

- 対象画面は、写真・動画が表示されるすべての画面：投稿詳細（SC-05）、スポット写真一覧（SC-13）、投稿カードのサムネイル（SC-04・検索結果・SC-06 マイページ・SC-09 アルバム）。
- タップすると全画面のモーダルでその写真・動画を表示する。投稿カードのサムネイルからは、その投稿の全メディアを1点目から表示する（カードは代表画像しか持たないため、その時点で取得する）。
- 複数点ある場合は、画面上の←→ボタン、キーボードの←→キー、スマートフォンの左右スワイプで前後に移動できる。「n / N」で現在位置を示す。端ではそれ以上進まない（ループしない）。
  - 移動の範囲は、投稿詳細・投稿カードではその投稿の全点、スポット写真一覧では読み込み済みの一覧全体（他の投稿のものを含む）。
- 動画はモーダル内で再生する（ブラウザ標準の再生コントロール・自動再生）。4.5.1 のインライン再生は廃止。
- 投稿詳細の「+N」枠をタップした場合は4点目から開き、→で5点目以降へ進める。
- 閉じ方：×ボタン、Escキー、背景のタップ。表示中は背面のページをスクロールさせない。
- スポット写真一覧から開いた場合は、モーダル内に「この投稿を見る」（SC-05への導線）を置く。3.4.5「タップで投稿詳細へ遷移」はこの導線に置き換える。
- 「行きたい」スポット一覧（SC-08）のサムネイルはスポットの代表画像であり投稿に紐づかないため、本ストーリーの対象外とする。

## 受入条件

- [ ] 投稿詳細・スポット写真一覧・投稿カードのいずれからも、写真・動画をタップするとモーダルで表示されること（8章 受入条件44）
- [ ] 複数点ある場合に←→ボタン・矢印キー・左右スワイプで前後に移動でき、端で止まること
- [ ] 動画がモーダル内で再生されること
- [ ] ×ボタン・Esc・背景タップで閉じ、元の画面の位置に戻ること
- [ ] スポット写真一覧のモーダルから元の投稿の詳細へ遷移できること
