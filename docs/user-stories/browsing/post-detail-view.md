# F-VW-01 投稿詳細閲覧

> 出典: [requirement.md](../../requirement.md) 3.5.1、3.5.4

## ユーザーストーリー

ログイン済みの利用者として、投稿の詳細内容とコメントを見たい。なぜなら、投稿者の体験を詳しく知り、自分の「行きたい」判断や次の旅の参考にしたいから。

## 詳細

- 投稿詳細画面（SC-05）には、投稿の全項目（スポット名・カテゴリ・日付・滞在時間・費用・星評価・写真・動画・感想・投稿者・投稿日時）とコメント欄を表示する。旅行タイトルは表示しない（3.3.4の表示範囲に準拠）。
- 投稿詳細画面から、当該スポットを「行きたい」に保存できる。保存自体の処理は「行きたい」保存機能（F-RC-05、`records`カテゴリで別途作成）に委ね、本ストーリーでは保存ボタンの設置と導線のみを扱う。
- コメント欄の表示・投稿・削除ロジック自体はコメント機能（F-VW-03、[comments.md](comments.md)）に委ね、本ストーリーでは投稿詳細画面へのコメント欄の組み込みのみを扱う。
- 非公開設定（3.3.6）の投稿は、投稿者本人およびアルバムメンバー以外は取得できない。地図・検索・投稿一覧・スポット写真一覧からは除外されるが、直接URLでアクセスされた場合も含めRoute Handlers・RLSの両方で保護する（7.2準拠）。
- 本サービスは全機能・全画面についてログインを必須とする（3.5.4）。未ログイン状態で投稿詳細画面（あるいはログイン必須の他画面）に直接アクセスした場合は、ログイン画面（SC-01）へ誘導し、ログイン完了後に元の遷移先へ戻す。トークン検証自体は[session-management](../../tasks/account/session-management/00-index.md)のMiddlewareが担うが、「ログイン画面へのリダイレクト」と「ログイン後に元の遷移先へ戻す」という画面遷移の仕組みは未実装のため、本ストーリーのタスクとして扱う（他のログイン必須画面からも再利用できる共通処理として実装する）。

## 受入条件

- [ ] 投稿詳細画面に、投稿の全項目（スポット名・カテゴリ・日付・滞在時間・費用・星評価・写真・動画・感想・投稿者・投稿日時）とコメント欄が表示されること
- [ ] 投稿詳細画面に旅行タイトルが表示されないこと
- [ ] 投稿詳細画面から、当該スポットを「行きたい」に保存できること
- [ ] 非公開設定の投稿が、投稿者本人・アルバムメンバー以外の他ユーザーの地図・検索結果・投稿一覧・スポット写真一覧に表示されないこと。一方でアルバムメンバーには表示されること（受入条件9）
- [ ] 未ログイン状態で投稿詳細画面に直接アクセスすると、ログイン画面へ誘導され、ログイン完了後に元の投稿詳細画面へ戻ること（受入条件3）
