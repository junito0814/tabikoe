# F-VW-01 投稿詳細閲覧

> 出典: [requirement.md](../../requirement.md) 3.5.1、3.5.4（v3.0で変更）

## ユーザーストーリー

ログイン済みの利用者として、投稿の詳細内容とコメントを見て、その場所を地図で確かめたり、しおりに入れたり、自分も投稿したりしたい。なぜなら、投稿者の体験を詳しく知ったうえで、次の行動にすぐ移りたいから。

> v1 で実装済みの `/posts/[id]`（全項目表示・コメント欄・いいね・ログイン誘導）を土台に、見出しと導線を変える。

## 詳細

- 投稿詳細画面（SC-05）には、投稿の全項目（スポット名・都道府県・カテゴリ・訪問日・滞在時間・費用・星評価・写真・動画・感想・投稿者・投稿日時）とコメント欄を表示する。旅行タイトルは表示しない。非公開投稿にはいいね・コメント欄を出さない。
- 見出しはスポット名。タップするとそのスポットの投稿一覧（SC-04）へ。手動登録スポットには「タビコエだけの場所」ラベル。
- 導線：「地図で見る」（SC-02、そのスポットを中心）、「＋」（保存先の 2 択シート。[wishlist](../records/wishlist.md)）、「自分も投稿する」（そのスポットが確定した SC-03。[post-entry-points](../posts/post-entry-points.md)）。
- 「まだあった」報告（[spot-status-report](spot-status-report.md)）の 2 ボタンと最新の報告を表示する。
- 本人の操作：右上の「⋯」に編集・削除（削除は右端）。他人の投稿には「通報」。
- 写真・動画のタップはモーダル（[media-layout](../shared-ui/media-layout.md)）。
- 非公開投稿の保護（Route Handlers・RLS）とログイン誘導は v1 実装のまま。

## 受入条件

- [ ] 投稿詳細画面に全項目とコメント欄が表示され、旅行タイトルが表示されないこと（受入条件15）
- [ ] 見出しがスポット名で、タップするとそのスポットの投稿一覧へ遷移すること。手動登録スポットに「タビコエだけの場所」が表示されること（受入条件54）
- [ ] 「地図で見る」「＋」「自分も投稿する」のそれぞれから、地図・保存先シート・スポット確定済みの SC-03 へ遷移すること（受入条件56）
- [ ] 非公開投稿にいいね・コメント欄が表示されないこと。アルバムメンバー以外には取得できないこと（受入条件9）
- [ ] 未ログイン状態で直接アクセスすると、ログイン画面へ誘導され、ログイン完了後に元の画面へ戻ること（受入条件3）
