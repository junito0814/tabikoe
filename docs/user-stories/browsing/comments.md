# F-VW-03 コメント

> 出典: [requirement.md](../../requirement.md) 3.5.3

## ユーザーストーリー

ログイン済みの利用者として、投稿にコメントを書き込みたい。なぜなら、投稿者に感想や質問を直接伝え、交流したいから。

## 詳細

- 投稿に対してコメントを書き込む。入力は全角4,000文字まで。
- コメント一覧は1回につき20件を表示し、「もっと見る」で追加読み込みする。
- コメントの編集はできない。
- 削除はコメント投稿者本人のみ可能。
- 投稿頻度は1ユーザーにつき1分間5件までに制限する（`rate_limits`テーブルで判定）。
- コメントが投稿されると、投稿者（自分自身のコメントを除く）にアプリ内通知を送る（3.9.1）。通知の生成自体は通知機能（F-NT-01、`notifications`カテゴリで別途作成）の共通処理を利用する。
- 自由記述欄のため、HTMLタグ・スクリプトとして解釈されないようエスケープ処理を行う（7.2準拠）。

## 受入条件

- [ ] 投稿にコメントを書き込めること（全角4,000文字まで）
- [ ] コメント一覧が1回につき20件読み込まれ、「もっと見る」で追加読み込みできること
- [ ] コメントを編集する機能がないこと
- [ ] コメント投稿者本人のみがコメントを削除できること
- [ ] 1ユーザーにつき1分間5件を超えるコメント投稿が拒否されること
- [ ] コメントが投稿されると、投稿者（自分自身のコメントを除く）に通知が送られること（受入条件29）
- [ ] コメント本文がHTMLタグ・スクリプトとして解釈されず、エスケープされた状態で表示されること
