# F-VW-02 いいね

> 出典: [requirement.md](../../requirement.md) 3.5.2

## ユーザーストーリー

ログイン済みの利用者として、気に入った投稿に「いいね」を付けたい。なぜなら、投稿者に好意的な反応を手軽に伝えたいから。

## 詳細

- 投稿に対していいねを付与・取り消しする。
- 1ユーザーにつき1投稿1件までに制限する。
- 対象は公開設定が「公開」の投稿のみ。非公開投稿にはいいねが付かない。
- いいねが付与されると、投稿者（自分自身によるいいねを除く）にアプリ内通知を送る。1件ずつ都度通知する（3.9.1）。通知の生成自体は通知機能（F-NT-01、`notifications`カテゴリで別途作成）の共通処理を利用する。

## 受入条件

- [ ] 投稿にいいねを付与・取り消しできること
- [ ] いいねが1ユーザー1投稿1件に制限されること（受入条件21）
- [ ] 公開設定が「公開」の投稿のみがいいねの対象であること
- [ ] いいねが付与されると、投稿者（自分自身によるいいねを除く）に通知が送られること（受入条件29）
