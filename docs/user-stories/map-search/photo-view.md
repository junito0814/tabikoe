# F-MP-05 写真の切替

> 出典: [requirement.md](../../requirement.md) 3.4.5（v3.0で変更。v1 の「スポット写真一覧（SC-13）」を SC-04 の切替に統合）

## ユーザーストーリー

ログイン済みの利用者として、行き先やスポットの投稿を写真だけでざっと眺めたい。なぜなら、文章を読む前に雰囲気を写真でつかみたいから。

> v1 で実装済みの `SpotPhotoGalleryScreen`（`/spots/[id]/photos`、40 点ページング、モーダル）を部品として流用し、検索結果にも適用する。独立画面 SC-13 は廃止する。

## 詳細

- 投稿一覧（SC-04）の「投稿／写真」切替で、同じ検索条件・絞り込み条件の公開投稿の写真・動画を、投稿をまたいで 1 つのグリッドにまとめて表示する。検索結果でもスポット別でも使える。URL は `?view=photos`。
- 表示形式は正方形サムネイルのグリッド（列数は画面幅に応じて可変）。動画は再生アイコンを重ねる。
- 並び順は投稿一覧と同じ並び替え（新着順／評価順／いいね順）。写真は元の投稿の順で並び、同じ投稿の写真は添付順にまとまる。
- タップでその写真・動画を起点にモーダル表示し、左右で前後へ送れる。「この投稿を見る」で投稿詳細（SC-05）へ。
- 1回につき40点を読み込み、スクロールに応じて追加読み込みする。非公開投稿・下書きは含めない。

## 受入条件

- [ ] 投稿一覧の「写真」切替で、同じ条件の全公開投稿の写真・動画がグリッドで一覧表示され、並び替えが投稿一覧と連動すること（受入条件11）
- [ ] 検索結果（都道府県・周辺）でもスポット別でも切替が使えること
- [ ] 写真をタップするとモーダルで前後に送れ、「この投稿を見る」で投稿詳細へ遷移すること
- [ ] 1回40点のページングでスクロールに応じて追加読み込みされること
- [ ] 非公開投稿・下書きの写真が含まれないこと
