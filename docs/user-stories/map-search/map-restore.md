# F-MP-03 地図の復元と吹き出しの導線（map-restore）

> 出典: [requirement.md](../../requirement.md) 3.4.3「地図の状態の復元」・3.4.4「ピン操作」・3.4.6「戻ったときの復元」・8章 46
> 2026-09-25、ステージングの実機（渋谷・新宿）での確認で判明

## ユーザーストーリー

地図で近くのスポットを見比べている人として、投稿を 1 つ開いて戻ってきたときに、さっきまで見ていた画面のままでいてほしい。毎回はじめからやり直しでは、次のスポットと見比べられないから。

## 背景（実機で判明した 2 つの問題）

1. **戻ると初期値に戻る**。探すモードで移動手段を車にして地図を動かし、カードから投稿詳細へ進んで戻ると、移動手段も位置も初期値に戻る。原因は復元の判定で、「今回の現在地と、保存した地図の中心が 500m 以内なら復元する」としていたため。カードを横にスライドすると地図がそのスポットへ動き、保存される中心が現在地から離れる。車（半径 10km）ではほぼ必ず条件から外れる。
2. **吹き出しから一覧へ行けると分からない**。吹き出しは本体（スポット名）をタップすると投稿一覧へ行くが、見た目では分からない。唯一の文字のあるボタンが「投稿する」なので、見るつもりで押すと投稿画面が開く。

## 詳細

### 復元（3.4.3・3.4.6）

- 判定は**同じ入口から戻ってきたかどうか**だけにする。地図の中心が動いていても復元する。
- 「別の街から開き直したら初期位置」を保つため、**探すモードを開いたときの現在地**を別に保存し、今回の現在地と比べる（500m）。現在地が取れないときは復元する（取り直しを待たない）。
- 復元するもの: 中心・ズーム・モード・移動手段・**選んでいたカード**（そのカードを中央に置き、対応するピンを強調する）。

### 吹き出し（3.4.4）

- 「投稿する」を **「投稿を見る」** に変える（そのスポットの投稿一覧へ。本体タップと同じ行き先）。
- 吹き出しからの投稿は廃止する。投稿は右下の「ここに投稿」と長押しから行う。

## 追加（2026-09-25、カードのタップの見直し）

- カードのタップを 2 段階にする。選ばれていないカードのタップは「中央へ寄せて地図を動かし、吹き出しを開く」だけで画面は移らない。選ばれている（中央の）カードのタップで、そのスポットの投稿一覧（SC-04）へ行く。
- 現在地（マーカー・「ここに投稿」・近くのスポットの取得元）は、地図の表示位置とは別に持つ。地図を動かしても、カードの選択で地図がスポットへ動いても変わらない。投稿一覧などから戻ってきたときは位置情報を取り直し、取れるまでは開いたときの現在地を仮に使う。
- 戻ったときは、選んでいたカードの吹き出しも開き直す。
- 検索トップ（SC-00）を開いた時点で、覚えている地図の状態を消す（そのあと探すモードを開くと現在地・徒歩の初期値）。

## 受入条件

- [ ] 探すモードで移動手段を車にし、カードを 3 枚ほどスライドしてから投稿詳細へ進み、戻ったとき、移動手段・地図の位置・選んでいたカードがそのままであること
- [ ] 別の場所（500m 以上離れた地点）で探すモードを開き直したときは、初期位置で開くこと
- [ ] 現在地が取れないときも復元されること
- [ ] 地図のピンをタップすると吹き出しに「投稿を見る」が出て、押すとそのスポットの投稿一覧へ行くこと。「投稿する」は無いこと
- [ ] 選ばれていないカードをタップすると、画面は移らずに地図が動いて吹き出しが出ること
- [ ] 選ばれているカードをタップすると、そのスポットの投稿一覧へ行くこと
- [ ] 投稿一覧から戻ると、地図・移動手段・選んでいたカード・吹き出しが元どおりになること
- [ ] ホームを開いてから探すモードを開き直すと、現在地・徒歩の初期値になること
- [ ] 要件定義書 8 章 46
