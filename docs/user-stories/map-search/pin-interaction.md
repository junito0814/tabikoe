# F-MP-03 ピン操作

> 出典: [requirement.md](../../requirement.md) 3.4.3

## ユーザーストーリー

ログイン済みの利用者として、地図上のピンをタップして、そのスポットに投稿された内容を確認したい。なぜなら、気になるスポットの詳しい情報をすぐに見たいから。

## 詳細

- ピンをタップすると、当該スポットに投稿された投稿の一覧（SC-04）を表示する。
- 一覧は新着順（デフォルト）／評価順／いいね順から並び替えられる。
- 一覧内の投稿カードをタップすると投稿詳細画面へ遷移する。
- 投稿がない場合は「まだ投稿がありません」と表示する。

## 受入条件

- [ ] ピンをタップすると、そのスポットの投稿一覧が表示されること
- [ ] 投稿一覧を新着順／評価順／いいね順で並び替えられること
- [ ] 投稿がないスポットでは「まだ投稿がありません」と表示されること
- [ ] 投稿一覧内の投稿カードをタップすると投稿詳細画面へ遷移すること
