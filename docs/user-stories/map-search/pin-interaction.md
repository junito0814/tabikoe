# F-MP-03 ピン操作と地図からの投稿

> 出典: [requirement.md](../../requirement.md) 3.4.4（v3.0で変更）

## ユーザーストーリー

ログイン済みの利用者として、地図上のピンから投稿を見たり、いまいる場所や長押しした地点からすぐ投稿を始めたい。なぜなら、地図を見ているその流れで、見る・残すの両方を済ませたいから。

## 詳細

- 既存ピンのタップ：吹き出し（スポット名・星評価・投稿件数・最新の「まだあった」・「一覧」「投稿する」）を出す。「一覧」でスポット別の投稿一覧（SC-04）、「投稿する」でそのスポットが確定した SC-03。
- 「ここに投稿」（右下）：現在地にピンが刺さった SC-03 を開く。半径50m以内に既存スポットがあればそれを選択済みにする。
- 長押し：地図を長押し（touchstart から 500ms 動かさない。マウスは右クリック）すると、その点にピンを立てて吹き出し「この地点 [ここに投稿]」を出す。押すとその点を中心に SC-03 を開く。ダブルタップは地図のズームに使い、投稿には使わない。
- 下書きピン：タップで吹き出し「下書き: 〈スポット名または名前のない場所〉 [続きを書く]」。押すと SC-03 を保存時の状態で開く。
- 番号ピン（しおり表示）：タップでそのスポットの行をしおり詳細で強調する（[itinerary-map-and-post](../itinerary/itinerary-map-and-post.md)）。
- 投稿専用モードは設けない。どの表示状態でも上記の入口から SC-03 に直行する。

## 受入条件

- [ ] ピンをタップすると吹き出しが出て、「一覧」からスポット別の投稿一覧が表示されること（受入条件10）
- [ ] 地図で「ここに投稿」を押す、または長押しすると、その位置にピンが刺さった SC-03 が直接開くこと（受入条件48）
- [ ] 長押し中に指を動かした場合や 500ms 未満ではピンが立たず、ダブルタップではズームだけが起きること
- [ ] 下書きピンの「続きを書く」で SC-03 が保存時の状態で開くこと
- [ ] 投稿がないスポットの一覧で「まだ投稿がありません」と表示されること
