# スポット一覧から開いた地図にも現在地を出す（map-current-location）

> 出典: [requirement.md](../../requirement.md) 4.5.10「地図の現在地」（2026-09-26 決定）
> 要求定義書: [request.md](../../request.md) 「v2 改訂（2026-09-19）」変更点 13

## ユーザーストーリー

行き先を調べている人として、スポットの地図を見たときに自分の現在地も見たい。そのスポットが自分からどれくらい離れているのかを知りたいから。

## 背景（2026-09-26）

- 全画面の地図（SC-02）が現在地を取りに行くのは、**探すモードのとき**か、**URL に中心が無くて地図をどこに開けばいいか分からないとき**だけだった。
- スポット一覧の上の地図から「地図を全画面に」で開くと `?spot=…&lat=…&lng=…` と中心が付いてくるので、どちらにも当てはまらず位置情報を一度も取りに行かない。
- 右下の「現在地」ボタンを押せば出るが、押すまで出ないうえ、押すと地図がそこへ飛んでしまい、見ていたスポットが画面から外れる。

## 詳細（4.5.10）

- 全画面の地図（SC-02）を開いたら、**モードを問わず**現在地を取りに行く。
- **地図は動かさない**。点を出すだけ。地図の中心の決め方は今までどおり。
- 取れなかったら何も出さない（エラーも出さない）。「現在地」ボタンを押したときだけ、今までどおり失敗を伝える。
- 出すのは **SC-02（全画面の地図）だけ**。次の画面には出さない（2026-09-26 決定）。
  - **あしあと（SC-12）** … 自分の記録を見る画面で、今どこにいるかは要らない
  - **投稿作成・編集（SC-03）** … 中央固定ピンがその位置を指している
  - **上部の地図**（投稿詳細・スポット別一覧・しおり）… 狭いので、全画面にしてから見る
  - **スポット手動登録モーダル**

## 受入条件

- [ ] スポット別一覧の上の地図から全画面にすると、青い点（現在地）が出ること
- [ ] そのとき地図の中心が動かず、開いたスポットが画面の中央のままであること
- [ ] 位置情報を断った場合も地図が普通に使えること（エラーが出ないこと）
- [ ] 探すモードの動き（現在地を中心に開く）が今までどおりであること
- [ ] あしあと（SC-12）には現在地が出ないこと（今までどおり）
