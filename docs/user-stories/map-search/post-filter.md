# F-MP-04 投稿検索・絞り込み

> 出典: [requirement.md](../../requirement.md) 3.4.4

## ユーザーストーリー

ログイン済みの利用者として、条件を指定して投稿を絞り込みたい。なぜなら、自分の好みや予算・時間に合ったスポットだけを効率よく探したいから。

## 詳細

- キーワード検索はスポット名を対象とする。
- 絞り込み条件：
  - カテゴリ（5カテゴリから複数選択可）
  - 距離（500m以内／1km以内／3km以内／5km以内。地図の中心座標を基準とする）
  - 費用（数値で保存された費用〔1人あたり〕に対するレンジ判定：〜1,000円／〜3,000円／〜5,000円／5,000円〜。費用未入力の投稿は結果から除外する）
  - 滞在時間（30分以内／1時間以内／2時間以内／3時間以内／それ以上）
- ページングは1回につき20件を読み込み、スクロールに応じて追加読み込みする（無限スクロール）。
- 対象範囲は公開設定が「公開」の投稿のみとする。

## 受入条件

- [ ] キーワード（スポット名）・カテゴリ・距離・費用・滞在時間による絞り込みが動作すること
- [ ] 費用未入力の投稿が費用による絞り込み結果から除外されること
- [ ] 非公開設定の投稿が絞り込み結果に含まれないこと
- [ ] 1回につき20件のページングで、スクロールに応じて追加読み込みされること
