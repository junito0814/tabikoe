# F-MP-01 地図表示

> 出典: [requirement.md](../../requirement.md) 3.4.3（v3.0で変更）

## ユーザーストーリー

ログイン済みの利用者として、1 つの地図で「みんなの投稿」と「自分が保存した場所」を色で見分けながら位置関係を確かめたい。なぜなら、タブを切り替えなくても、行きたい場所と周りの投稿を同時に見たいから。

> v1 で実装済みの `GoogleMap`／`MapScreen`／クラスタリング／`/api/spots` はそのまま使う。本ストーリーで変えるのは「タブと検索バーの撤去」「ピン種別の同時表示と色」「表示情報の削減」「戻るの出し分け」。

## 詳細

- 置く要素：地図、ピン、凡例、現在地ボタン、「ここに投稿」（右下に常時表示）、戻る（「ホーム」「一覧に戻る」「しおりに戻る」のいずれか、左上）。検索バー・絞り込み・タブ・説明文は置かない。
- ピンの種別（[pin-display-rules](../shared-ui/pin-display-rules.md)）を 1 つの地図に同時に出す：青＝みんなの投稿（公開投稿があるスポット）、赤＝保存済み（自分の行きたいスポットと、自分が参加するしおりのスポット。両方に該当するスポットは赤）、灰の破線＝自分の下書き、番号ピン＝しおり表示時。色に加えて形状でも区別し、凡例を常時表示する。
- 同一エリアにピンが集中する場合はクラスタリングする。表示範囲内のピンを最大 100 件まで読み込む（`/api/spots` に保存済み・下書きの取得を追加）。
- 初期表示位置：「地図で見る」から＝そのスポットを中心に吹き出しで強調。探すモード＝現在地。しおりから＝その Day のスポットが収まる範囲。
- 現在地は Google マップ標準の青い点と精度の円のまま。
- 「一覧に戻る」は投稿一覧から来た場合のみ表示し、直前の SC-04 にスクロール位置と絞り込み条件を保って戻る。地図の表示位置は保持しない。
- 表示情報の削減（Google Maps `styles`）：POI ラベル非表示、駅名と地名は残す、道路名はズーム 16 以上のみ、彩度を下げる、3D・建物の立体表示・ストリートビューを無効にする。
- ダークモード時は Google マップのダークスタイルを適用する（[theme](../shared-ui/theme.md)）。
- 利用にはログインを必須とする。

## 受入条件

- [ ] 地図にタブが無く、青（みんなの投稿）・赤（保存済み）・灰の破線（下書き）のピンが同時に表示され、凡例が常時表示されること（受入条件47）
- [ ] 行きたい・しおりの両方に該当するスポットが赤 1 つで表示され、みんなの投稿にも該当する場合は赤が優先されること
- [ ] 同一スポットへの複数投稿が1ピンに集約され、表示範囲内のピンが最大100件まで読み込まれること（受入条件10）
- [ ] 「地図で見る」で地図がそのスポットを中心に開き、「一覧に戻る」で直前の一覧にスクロール位置と絞り込み条件を保ったまま戻ること（受入条件46）
- [ ] 地図上に Google マップの店舗ラベルが表示されず、駅名と地名は表示されること（受入条件69）
- [ ] OS をダークにすると地図がダークスタイルになること（受入条件68）
- [ ] 地図の初期表示が、投稿100件程度の条件下で3秒以内に完了すること（受入条件22）
