# F-MP-06 探すモード（近くの声）

> 出典: [requirement.md](../../requirement.md) 3.4.6（v3.0で新設）

## ユーザーストーリー

いま旅先にいる利用者として、現在地の周りにどんな投稿があるかを地図とカードで一度に見たい。なぜなら、開演までの空き時間や散歩の途中で、徒歩圏の穴場をすぐ見つけたいから。

## 詳細

- 入口は検索トップの「近くのスポットを探す」。URL は `/map?mode=explore`。位置情報が拒否された場合は開かず、検索トップで入力欄にフォーカスする。
- 現在地を中心に地図（[map-display](map-display.md)）を開き、下 1/3 に「近くの声」を横並びのカードで出す。カードは見出し＝スポット名、感想の冒頭、代表写真、徒歩 N 分。
- 対象と順序：現在地から「徒歩圏」で選んだ半径（500m／1km／3km。既定 1km）内の公開投稿を、距離が近い順に最大 20 件（`/api/posts/nearby`）。
- カードを横にめくると地図の対応するピンを強調する。カードのタップで投稿詳細（SC-05）。
- 右下の「ここに投稿」・長押し・既存ピンから SC-03 へ（[pin-interaction](pin-interaction.md)）。左上の戻るで検索トップへ。

## 受入条件

- [ ] 「近くのスポットを探す」で地図が探すモードで開き、徒歩圏（既定 1km）内の投稿が近い順に下部へ横並びで表示され、徒歩圏の切替が動作すること（受入条件50）
- [ ] カードを横にめくると地図のピンが連動して強調されること
- [ ] カードのタップで投稿詳細へ、右下の「ここに投稿」で現在地の SC-03 へ遷移すること
- [ ] 位置情報を拒否した場合、探すモードは開かず検索トップの入力欄にフォーカスすること
