# F-MP-04 投稿一覧（タイムライン・絞り込み・並び替え）

> 出典: [requirement.md](../../requirement.md) 3.4.2（v3.0で再定義。v1 の「投稿検索・絞り込み」を置き換える）

## ユーザーストーリー

ログイン済みの利用者として、行き先の投稿を新しい順に流し読みし、予算や期間で絞り、気になった投稿から地図やしおりへ進みたい。なぜなら、費用と日付つきの生の声を眺めるだけで旅先の候補を決めたいから。

> v1 で実装済みの `/search`（`search-posts.ts`、カード部品、カード上のコメント展開、絞り込み）を土台に、行き先検索・縦一列・見出し・切替・並び替え UI を作り替える。

## 詳細

- 表示形式：投稿日時の新しい順に縦一列のタイムライン（グリッドにしない）。1 画面に 1〜2 件が見える大きさ。
- 検索の判定：都道府県＝スポットの `prefecture` が一致／駅・市区町村（座標あり）＝その地点から半径 5km 以内のスポット／スポット名・ピン＝そのスポットの投稿（スポット別一覧）。
- 投稿カードの必須表示：スポット名（見出し）、感想の冒頭 2 行、星評価（黄色＋「星4」）、予算（未入力は「費用未記入」）、訪問日、写真・動画（[media-layout](../shared-ui/media-layout.md)）、投稿者、「地図で見る」、「＋」（[wishlist](../records/wishlist.md) の保存先シート）、いいね数、コメント件数。
- 付加表示：現在地が取れているときは「徒歩 N 分」（直線距離 ÷ 80m／分、切り上げ）。最新の「まだあった」報告（[spot-status-report](../browsing/spot-status-report.md)）。手動登録スポットには「タビコエだけの場所」ラベル。
- 「投稿／写真」の切替（[photo-view](photo-view.md)）。
- 絞り込み（下からのシート）：予算（〜1,000円／〜3,000円／〜5,000円／5,000円〜。費用未入力は除外）、期間（訪問日。今月／先月／日付指定）、カテゴリ（7 つから複数選択）、滞在時間、距離（500m／1km／3km／5km。駅・スポット名・現在地が基準点のときのみ表示）。適用中の条件数を「絞り込み」ボタンに表示する。
- 並び替え：「新着順 ▾」の 1 つのボタンを押してドロップダウンで新着順／評価順／いいね順を選ぶ。選択肢を横に並べない。
- ページング：20 件ずつの無限スクロール。対象は公開投稿のみ（下書き・非公開は含めない）。
- カード上のコメント展開は v1 実装をそのまま使う。
- スポット別一覧の見出し：スポット名、「地図で見る」「＋」「投稿する」。投稿がない場合は「まだ投稿がありません」。
- 追加モード（[add-spots](../itinerary/add-spots.md)）：画面上部に「〈旅行タイトル〉 Day n に追加中 [完了]」を出し、「＋」でそのしおりに直接入る。
- 戻る：左上の戻るで検索トップへ。地図から「一覧に戻る」で戻った場合はスクロール位置と絞り込み条件を保つ（検索条件・スクロール位置を URL と履歴 state に持つ）。

## 受入条件

- [ ] 投稿一覧が縦一列のタイムラインで、各カードにスポット名（見出し）・星評価・予算・訪問日・写真・「地図で見る」・「＋」が表示され、20 件ずつ追加読み込みされること（受入条件45）
- [ ] 都道府県・駅（周辺 5km）・スポット名の 3 通りの検索で正しい投稿が返ること
- [ ] 予算・期間・カテゴリ（7 つ）・滞在時間・距離による絞り込みが動作し、費用未入力の投稿が予算の絞り込みから除外されること（受入条件12）
- [ ] 並び替えが 1 つのボタンのドロップダウンで、新着順／評価順／いいね順を切り替えられること
- [ ] 現在地が取れているときだけ「徒歩 N 分」が表示されること
- [ ] 非公開投稿・下書きが一覧に含まれないこと（受入条件9）
- [ ] 「一覧に戻る」で戻ったときにスクロール位置と絞り込み条件が保たれること（受入条件46）
