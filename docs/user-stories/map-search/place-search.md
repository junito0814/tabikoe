# F-MP-02 地名検索

> 出典: [requirement.md](../../requirement.md) 3.4.2

## ユーザーストーリー

ログイン済みの利用者として、地図上部の検索バーに地名を入力して、見たいエリアへすぐに地図を移動したい。なぜなら、現在地から離れたエリアのスポットも探したいから。

## 詳細

- 地図上部の検索バーに地名を入力すると、地図の表示位置を移動する。
- 実現方式は、Google Maps Geocoding APIのジオコーディング機能をRoute Handlers（`/api/geocode`）経由で利用する。APIキーはサーバー側のみで保持する。
- 本機能は地図の移動のみを行う。投稿の検索・絞り込みは [map-search/post-filter](post-filter.md) の対象であり、本機能には含まない。

## 受入条件

- [ ] 地名検索バーに地名を入力すると、地図が該当エリアへ移動すること
- [ ] 地名検索は地図の移動のみを行い、投稿の検索・絞り込み結果には影響しないこと
- [ ] Geocoding APIキーがフロントエンドのビルド成果物・ブラウザの開発者ツールから確認できないこと
