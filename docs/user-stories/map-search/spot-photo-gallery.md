# F-MP-05 スポット写真一覧

> 出典: [requirement.md](../../requirement.md) 3.4.5

## ユーザーストーリー

ログイン済みの利用者として、1つのスポットに投稿された全ての写真・動画を、投稿をまたいで一覧で見たい。なぜなら、そのスポットの雰囲気を写真・動画でまとめて確認したいから。

## 詳細

- 投稿一覧画面（SC-04）の上部に「写真」タグを設置し、タップするとスポット写真一覧画面（SC-13）に遷移する。
- 表示形式は正方形サムネイルのグリッド表示（列数は画面幅に応じて可変）。動画はサムネイルに再生アイコンを重畳して表示する（4.5.1準拠）。
- 対象は公開設定が「公開」の投稿の写真・動画のみとする。
- 並び順は投稿日時が新しい順（新着順）とする。
- 写真・動画をタップすると、それを含む元の投稿の詳細画面（SC-05）へ遷移する。
- 1回につき40点を読み込み、スクロールに応じて追加読み込みする。

## 受入条件

- [ ] 投稿一覧画面から「写真」タグを押すと、そのスポットの全公開投稿の写真・動画がグリッドで一覧表示されること
- [ ] 動画は再生アイコンを重畳したサムネイルで表示されること
- [ ] 表示が新着順であり、1回40点のページングでスクロールに応じて追加読み込みされること
- [ ] 写真・動画をタップすると元の投稿詳細画面へ遷移すること
- [ ] 非公開設定の投稿の写真・動画は一覧に含まれないこと
