# F-AC-04 プロフィール編集

> 出典: [requirement.md](../../requirement.md) 3.2.4

## ユーザーストーリー

ログイン済みの利用者として、ユーザー名とアイコン画像を変更したい。なぜなら、自分のプロフィールを自分らしくカスタマイズしたいから。

## 詳細

- 入力項目：ユーザー名（200文字まで）、アイコン画像。
- 画像の取り扱いは5.4「画像・動画の取り扱い」の規則に準拠する。

## 受入条件

- [ ] ユーザー名を200文字以内で変更できること
- [ ] アイコン画像をアップロードして変更できること
- [ ] アップロードした画像がEXIF位置情報除去・縮小画像生成など5.4の規則に従って処理されること
