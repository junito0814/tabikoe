# F-AC-02 セッション管理

> 出典: [requirement.md](../../requirement.md) 3.2.2

## ユーザーストーリー

ログイン済みの利用者として、操作の途中でセッションが切れて中断されたくない。なぜなら、投稿や閲覧の作業をスムーズに続けたいから。

## 詳細

- アクセストークンの有効期限は1時間。期限切れ時はリフレッシュトークンを用いて自動的に再発行し、ユーザーの操作を中断しない。
- リフレッシュトークンの有効期限は30日。最終利用から30日経過した場合は再ログインを求める。
- トークンはHttpOnly属性を付与したCookieで保持し、フロントエンドのJavaScriptから読み取れないようにする。発行・検証はRoute Handlers（Middleware）で行う。

## 受入条件

- [ ] アクセストークンの有効期限切れ時、画面操作を中断せず自動的に再取得されること
- [ ] 最終利用から30日経過したセッションでは、再ログインが求められること
- [ ] トークンがHttpOnly Cookieで保持され、ブラウザのJavaScriptから参照できないこと
