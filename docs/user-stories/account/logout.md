# F-AC-03 ログアウト

> 出典: [requirement.md](../../requirement.md) 3.2.3

## ユーザーストーリー

ログイン済みの利用者として、プロフィール編集画面からログアウトしたい。なぜなら、共用端末の利用後などに自分のセッションを確実に終了させたいから。

## 詳細

- セッション（アクセストークン・リフレッシュトークン）を破棄し、未ログイン状態に戻す。
- 事前条件：ログイン済みであること。
- 操作起点：プロフィール編集画面（SC-07）。

## 受入条件

- [ ] プロフィール編集画面からログアウト操作ができること
- [ ] ログアウト後、アクセストークン・リフレッシュトークンが破棄され未ログイン状態になること
- [ ] ログアウト後にログイン必須画面へアクセスすると、ログイン画面へ誘導されること
