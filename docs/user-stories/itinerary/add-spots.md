# F-IT-04 スポットの追加と追加モード

> 出典: [requirement.md](../../requirement.md) 3.11.4（v3.0で新設）

## ユーザーストーリー

旅行を計画する利用者として、しおりを開いたまま投稿一覧から次々にスポットを足したい。なぜなら、1 件ごとに保存先を選び直すのは面倒だから。

## 詳細

- 通常の追加：投稿カード・投稿詳細・地図の「＋」→ 保存先シートでしおり（と Day）を選ぶ（[wishlist](../records/wishlist.md)）。行きたいスポット（SC-08）の「＋」からも同様。
- 追加モード：しおり詳細の「＋ スポットを追加」を押すと、投稿一覧（SC-04）を追加モードで開く。行き先はしおりに入っているスポットの都道府県（複数なら最も多いもの）を自動で入れ、しおりが空なら検索トップ（SC-00）を追加モードで開く。追加先は開いていた Day（未定タブなら未定）。URL は `?itinerary=<id>&day=<n>`。
- 追加モードの表示：画面上部に「〈旅行タイトル〉 Day n に追加中 [完了]」を固定表示する。カードの「＋」を押すだけでそのしおりに入り（保存先シートは出さない）、入っているスポットの「＋」はチェック表示にする。「完了」でしおり詳細に戻る。
- 同じスポットは 1 つのしおりに 1 回だけ入る（`(itinerary_id, spot_id)` UNIQUE）。複数のしおりには入れられる。
- 追加できるのはしおりのオーナーとメンバー。

## 受入条件

- [ ] しおり詳細の「＋ スポットを追加」で投稿一覧が追加モードで開き、カードの「＋」だけで開いていた Day に追加され、「完了」でしおりに戻ること（受入条件61）
- [ ] 追加モードの行き先がしおりのスポットの都道府県で自動的に埋まり、しおりが空なら検索トップが開くこと
- [ ] 既に入っているスポットの「＋」がチェック表示になり、押すと外れること
- [ ] 同じスポットを同じしおりに 2 回入れられないこと
