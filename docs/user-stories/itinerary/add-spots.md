# F-IT-04 スポットの追加と追加モード

> 出典: [requirement.md](../../requirement.md) 3.11.4（v3.0で新設。2026-11-07 に「しおりから追加する」を変更）・3.3.5

## ユーザーストーリー

旅行を計画する利用者として、しおりを開いたまま投稿一覧から次々にスポットを足したい。なぜなら、1 件ごとに保存先を選び直すのは面倒だから。

旅行を計画する利用者として、タビコエにまだ投稿が無い場所も、名前や住所で探してしおりに入れたい。なぜなら、行きたい店や宿は SNS や友だちから知ることが多く、タビコエに載っているとは限らないから。（2026-11-07 追加）

## 詳細

- 通常の追加：投稿カード・投稿詳細・地図の「＋」→ 保存先シートでしおり（と Day）を選ぶ（[wishlist](../records/wishlist.md)）。行きたいスポット（SC-08）の「＋」からも同様。
- ~~追加モード：しおり詳細の「＋ スポットを追加」を押すと、投稿一覧（SC-04）を追加モードで開く。~~ → **2026-11-07 に変更**。しおり詳細の「＋ スポットを追加」を押すと、シート「スポットを追加」を出す。中身は「場所の名前または住所で探す」欄と「投稿から探す」。理由: 今の追加モードはタビコエに登録済みの場所しか入れられなかったため。また空のしおりでは先に行き先を選ぶ画面が出て、1 件目を名前で入れられなかったため。
- 名前・住所で探す：候補は「タビコエの中から」（最大 5 件）と「Google マップから」（残り）に分け、合わせて最大 10 件。タビコエの場所はその場で入る。Google の候補（住所を含む）は「場所の確認」（地図・名前・住所・都道府県。投稿画面と同じ部品）のあとに入る。タビコエの候補の名前を押すと、その場所のスポット別一覧を追加モードで開き、「‹ 戻る」でシートに戻る（入力は残す）。
- Day の選び方：「＋」の左に「Day n ▾」の札を置く（しおりの行の Day と同じ部品）。最初の値はシートを開いたタブの Day（ALL なら日付なし）で、変えると、それ以降の札もその Day から始まる。入っている場所は「Day n ▾」と青い ✓ を出し、✓ を押すと外れる。期間の無いしおりでは札を出さない。
- 続けて入れる：入れたあともシートは開いたままにし、「〈場所〉 を Day n に追加しました」と出す。
- 投稿から探す（追加モード）：投稿一覧（SC-04）を追加モードで開く。行き先はしおりに入っているスポットの都道府県（複数なら最も多いもの）を自動で入れ、しおりが空なら検索トップ（SC-00）を追加モードで開く。URL は `?itinerary=<id>&day=<n>`（day は札の最初の値）。
- 追加モードの表示：画面上部に ~~「〈旅行タイトル〉 Day n に追加中 [完了]」~~ → **2026-11-07 に変更**「〈アルバム名〉 に追加中 [完了]」を固定表示する（Day はカードの札で選ぶため、帯から外した）。カードの「＋」を押すだけでそのしおりに入り（保存先シートは出さない）、入っているスポットは青い ✓ にする。「完了」でしおり詳細に戻る。
- 投稿 0 件の場所：しおりの中では普通の行として出す。「⋯」は今のまま「投稿を見る」で、開いた先に営業時間と地図が出る。他の人の候補と地図には出さない（3.3.5）。
- 見つからないとき：「タビコエにも Google マップにも見つかりませんでした。住所で探すと、その場所に名前を付けて入れられます。」と出す。Google が使えないときは、タビコエの候補だけを出し「スポット検索が一時的に利用できません」と出す。
- 同じスポットは 1 つのしおりに 1 回だけ入る（`(itinerary_id, spot_id)` UNIQUE）。複数のしおりには入れられる。
- 追加できるのはしおりのオーナーとメンバー。
- Google の候補を選んだあと、50m 以内の別の店に置き換わらないこと（#1062）が前提。先に直す。

## 受入条件

- [ ] ~~しおり詳細の「＋ スポットを追加」で投稿一覧が追加モードで開き、カードの「＋」だけで開いていた Day に追加され、「完了」でしおりに戻ること（受入条件61）~~ → **2026-11-07 に変更**：シートの「投稿から探す」で投稿一覧が追加モードで開き、カードの「＋」だけで札の Day に追加され、「完了」でしおりに戻ること（受入条件61）
- [ ] 追加モードの行き先がしおりのスポットの都道府県で自動的に埋まり、しおりが空なら検索トップが開くこと
- [ ] 既に入っているスポットが青い ✓ になり、押すと外れること
- [ ] 同じスポットを同じしおりに 2 回入れられないこと
- [ ] しおりの「＋ スポットを追加」でシートが開き、タビコエに無い場所を名前で探して Google の候補から「場所の確認」を経て、選んだ Day に入ること（受入条件106）
- [ ] 場所の確認で地図を動かし名前を直して追加すると、その位置と名前で登録されること。「候補に戻る」で入力が残っていること（受入条件107）
- [ ] 住所で探し、名前を付けて追加できること。住所が保存されていないこと（受入条件108）
- [ ] 候補・カード・場所の確認の札で Day を選べ、変えるとそれ以降の札もその Day から始まること。入っている場所に Day と青い ✓ が出ること（受入条件109）
- [ ] 投稿 0 件のスポットが、他の人の候補と地図に出ないこと（受入条件110）
- [ ] 投稿画面の「場所の確認」がしおりと同じ部品であること（受入条件111）
