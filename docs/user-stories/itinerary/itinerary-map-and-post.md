# F-IT-06 しおりの地図表示と投稿

> 出典: [requirement.md](../../requirement.md) 3.11.6（v3.0で新設）

## ユーザーストーリー

旅行中の利用者として、今日行くスポットを地図で順番に確かめ、着いた場所からそのまま投稿したい。なぜなら、しおりを見ながら回り、記録まで一続きで済ませたいから。

## 詳細

- 「地図で見る」：開いている Day のスポットだけに訪問順の番号ピンを出し、全体が収まる範囲で地図（SC-02）を開く（`/map?itinerary=<id>&day=<n>`）。地図上に Day タブを重ねて切り替えられ、「すべて」で全日を色分けする。「しおりに戻る」で戻る。済みのスポットの番号ピンは灰色。番号ピンのタップでしおり詳細の該当行を強調する。
- 「投稿一覧」：各スポットからスポット別の投稿一覧（SC-04）へ。
- 「投稿する」：各スポットから、スポット・旅行タイトル（しおりの旅行）・訪問日（その Day の日付。未定・期間未設定なら今日）が入力済みの SC-03 を開く（[post-entry-points](../posts/post-entry-points.md)）。投稿済みのスポットには「投稿済み」を表示する。
- 投稿はその旅行のアルバムにまとまり、しおりのスポットが自動でチェックされる（[itinerary-check](itinerary-check.md)）。

## 受入条件

- [ ] しおりの「地図で見る」で開いている Day のスポットに訪問順の番号ピンが表示され、Day の切替と「すべて」が動作すること（受入条件62）
- [ ] 済みのスポットの番号ピンが灰色で表示されること
- [ ] しおりのスポットの「投稿する」で、スポット・旅行タイトル・訪問日（その Day の日付）が入力済みの SC-03 が開き、投稿がそのアルバムにまとまること（受入条件63）
- [ ] 投稿済みのスポットに「投稿済み」が表示されること
