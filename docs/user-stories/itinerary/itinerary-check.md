# F-IT-05 チェック（行った場所）

> 出典: [requirement.md](../../requirement.md) 3.11.5, 5.3（v3.0で新設）

## ユーザーストーリー

旅行中の利用者として、行った場所にチェックを付けて「次はどこ」をすぐ分かるようにしたい。また、しおりのメンバーが投稿したら自動でチェックされてほしい。なぜなら、旅行中は手を動かす余裕が少なく、同行者の投稿も進捗に反映してほしいから。

## 詳細

- 手動：各スポットのチェックボックス（時刻の下）をタップでチェック／解除する。確認は出さない。
- 表示：済みはスポット名に取り消し線＋文字を薄くする。位置は動かさない。地図の番号ピンは灰色にする。
- 自動チェック：しおりのメンバー（オーナーを含む）の誰かが、その旅行（同じ旅行 ID）でそのスポットに投稿したら自動でチェックする。しおりのメンバーでない人（アルバムのメンバーであっても）の投稿では変わらない。下書きでは変わらない。実装は投稿の公開処理（Route Handlers）の中で、投稿者がメンバーである同じ `trip_id` のしおりに同じ `spot_id` の行があれば `checked_at`・`checked_by` を埋める。
- 状態の共有：チェックはしおり単位で 1 つ（`itinerary_spots.checked_at`）。メンバー全員に同じ状態が見える。
- 投稿との関係：手でチェックしても投稿は作らない。投稿を削除してもチェックは外さない。チェックは通知しない。

## 受入条件

- [ ] しおりのスポットをチェックすると取り消し線で表示され、しおりのメンバーがその旅行でそのスポットに投稿すると自動でチェックされ、メンバー以外の投稿では変わらないこと（受入条件60）
- [ ] 下書きの保存では自動チェックされず、公開した時点でチェックされること
- [ ] チェックしてもスポットの位置（並び順）が変わらないこと
- [ ] チェック状態がメンバー全員に同じく表示されること
