# F-SF-02 ブロック

> 出典: [requirement.md](../../requirement.md) 3.8.2

## ユーザーストーリー

ログイン済みの利用者として、他のユーザーをブロックしたい。なぜなら、関わりたくない相手の投稿・コメント・プロフィールを見えないようにし、快適にサービスを利用したいから。

## 詳細

- ブロックすると、ブロックしたユーザー・ブロックされたユーザーの双方から見て、相手の投稿・コメント・プロフィール・アルバムが表示されなくなる（相互非表示）。
- ブロックはいつでも解除できる。
- 共同アルバムのメンバー同士がブロック関係にある場合、アルバムの成立を優先し、アルバム内では相手の投稿を表示する（相互非表示の例外）。
- ブロックは他の多くの機能（地図・検索、投稿一覧・詳細、マイページ等）の表示結果に影響する横断的な機能のため、本ストーリーでは block／unblock の実行と、「ブロック関係にあるユーザーのコンテンツを除外する」ための共通フィルタ（クエリヘルパー）を提供する。各機能側での組み込みは、それぞれの機能のストーリー（地図・検索、閲覧・交流、記録・振り返り等）の実装時に本フィルタを利用する前提とする。
- 退会時のブロック情報の削除（自分が設定した／された双方）は F-AC-05（退会）の範囲で扱う。
- 要件定義書にブロック管理専用の画面IDは定義されていないため、ブロック操作の導線・ブロック中ユーザー一覧は本ストーリーの実装時にプロフィール編集画面（SC-07）上に追加する（設計判断。3.10.1のような明示的な画面追加ではないため、実装時にUI配置を確認する）。

## 受入条件

- [ ] ユーザーをブロックすると、そのユーザーの投稿・コメント・プロフィール・アルバムが相互に表示されなくなること
- [ ] ブロックをいつでも解除できること
- [ ] 共同アルバムのメンバー同士がブロック関係にある場合でも、アルバム内では相手の投稿が表示されること
- [ ] 退会時、自分が設定した／されたブロック情報が削除されること（F-AC-05と整合。本ストーリーでは新規タスクを設けない）
