## ユーザーストーリー

運営する人として、繰り返し違反する利用者には段階的に重い措置を自動で掛けたい。ただし、示し合わせた通報で無実の人が止められることは避けたい。
利用者として、自分の投稿が非公開にされたら理由を知りたいし、自分がいまどういう状態かを自分で確かめたい。

## 背景（2026-09-27）

- 通報の件数で自動停止する案を、X・Meta・Reddit・Google マップ・Mastodon の運用を調べたうえで取り下げた。**どこも通報数では止めていない**。数えるのは人が確定した違反で、自動で動かすのは投稿の非表示まで
- 被通報者に何も通知していなかった。非公開にされた本人が理由を知る手段が無かった
- スポット情報の誤りは「非公開化」しか対応が無く、誤字 1 つでスポットごと消すしかなかった

## 詳細

### ストライク（3.10.7）
- 管理者が「非公開化」「削除」を確定するたびに投稿者に 1 つ。「問題なし」では付かない。**通報の件数では付かない**
- 段階：1 警告／2 で 3 日／3 で 7 日／4 で 30 日の投稿・コメント禁止／5 で仮停止
- 90 日で失効（操作の記録には残る）。個人情報の掲載・なりすましは 1 回で仮停止。管理者は取り消せる（理由必須）。過去分は数えない
- しきい値（3 人・90 日・5 つ・各日数）は設定値

### 自動対応（3.10.8）
- 投稿・コメント：異なる通報者 3 人で自動非公開（確認待ち）＋管理者に通知。直近 90 日に「問題なし」が 3 件以上の通報者は数えない
- アカウント：有効なストライク 5 で仮停止＋管理者に通知。管理者が確定か解除

### 本人への通知（3.9.1）
- 非公開化・削除・ストライク・投稿禁止・停止のたびに、理由（と解除日）を通知。通報者は伝えない

## 受入条件

- [ ] 通報だけではストライクも停止も起きないこと
- [ ] 「非公開化」を確定すると投稿者に 1 ストライク付き、本人に理由が通知されること
- [ ] 有効なストライクが 2 になった時点から投稿・コメントができなくなり、解除日が本人に見えること
- [ ] 異なる通報者 3 人で投稿が自動的に非公開になり、管理者に通知が届くこと。同じ人が 3 回通報しても起きないこと
- [ ] 「問題なし」が 3 件以上ある通報者の通報は、3 人の数に入らないこと
- [ ] 有効なストライク 5 で仮停止になり、管理者が確定・解除できること
- [ ] 個人情報の掲載・なりすましで確定すると 1 回で仮停止になること
- [ ] 91 日前のストライクが数に入らないこと
- [ ] ~~マイページの「アカウントの状態」で、制限・ストライク・履歴が見えること~~ → **2026-10-04 に廃止**（代わりに「通知で理由が届くこと」「投稿禁止中は投稿画面に解除日が出ること」で確かめる。上の 2 つめ・3 つめの条件と重なる）
- [ ] スポット情報の誤りで「登録者に修正を依頼」すると登録者に通知が届き、直すと通報が対応済みになること
