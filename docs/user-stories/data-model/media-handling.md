# 画像・動画の取り扱いの共通実装確認

> 出典: [requirement.md](../../requirement.md) 5.4

## ユーザーストーリー

開発者として、写真・動画のアップロード処理（EXIF除去・縮小画像生成・動画サムネイル生成）が要件定義書5.4の仕様に沿って共通実装され、プロフィールアイコン・投稿写真の両方から再利用されていることを保証したい。なぜなら、機能ごとに個別実装すると、EXIF除去漏れなどのセキュリティ・プライバシー上の不備が生じかねないから。

## 詳細

5.4に列挙された画像・動画の取り扱い仕様は、以下の既存タスクで実装済みである。新規タスクは不要。

| 項目 | 内容 | 実装状況 |
|---|---|---|
| 保存先 | Supabase Storage | 実装済み（F-AC-04 Task3） |
| 写真の受付形式・サイズ上限 | JPEG／PNGのみ、1点あたり10MB。Route Handlers側でファイルの実体を検証 | 実装済み（F-AC-04 Task3） |
| EXIF | 位置情報（GPS情報）を除去した上で保存・配信する | 実装済み（F-AC-04 Task3） |
| 縮小画像 | 長辺1200pxの表示用画像を自動生成する | 実装済み（F-AC-04 Task3） |
| 向き | EXIF Orientationを考慮し、正しい向きで縮小画像を生成する | 実装済み（F-AC-04 Task3） |
| 動画の受付形式・サイズ・長さ上限 | MP4のみ、1点あたり最大100MB、再生時間1分以内 | 実装済み（F-PO-01 Task4） |
| 動画のサムネイル | アップロード時に先頭フレームを抽出し、一覧・詳細画面ではそのサムネイル画像を表示する | 実装済み（F-PO-01 Task4） |
| 動画の処理 | ffmpegで先頭フレーム抽出。EXIF相当の位置情報メタデータも同じ処理内で除去する | 実装済み（F-PO-01 Task4） |
| 添付点数 | 写真・動画あわせて1投稿あたり上限なし | 実装済み（F-PO-01 Task4） |

[F-AC-04 Task3（画像アップロード共通処理）](../../tasks/account/profile-edit/03-image-upload-processing-common.md)は、プロフィールアイコンだけでなく投稿写真からも再利用される共通モジュールとして設計されている（[F-PO-01 Task4](../../tasks/posts/post-creation/04-media-upload-integration.md)参照）。

## 受入条件

- [ ] 写真の受付形式（JPEG/PNG）・サイズ上限（10MB）がRoute Handlers側で検証されること（F-AC-04 Task3で実装済み）
- [ ] EXIF位置情報除去・向き補正・長辺1200px縮小画像生成が行われること（F-AC-04 Task3で実装済み）
- [ ] 動画の受付形式（MP4）・サイズ上限（100MB）・再生時間上限（1分）が検証されること（F-PO-01 Task4で実装済み）
- [ ] 動画アップロード時にffmpegで先頭フレームのサムネイルが生成されること（F-PO-01 Task4で実装済み）
- [ ] プロフィールアイコンと投稿写真の両方が同一の共通処理（F-AC-04 Task3のモジュール）を利用していること
