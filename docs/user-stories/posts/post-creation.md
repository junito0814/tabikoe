# F-PO-01 投稿作成

> 出典: [requirement.md](../../requirement.md) 3.3.1, 3.3.2, 3.3.6

## ユーザーストーリー

ログイン済みの利用者として、訪れたスポットについての投稿（旅行タイトル・スポット名・カテゴリ・日付・滞在時間・費用・星評価・写真・動画・感想・公開設定）を作成したい。なぜなら、自分の旅の記録を残し、他の利用者と共有したいから。

> 旅行タイトルの詳細仕様は [trip-title.md](trip-title.md)、スポット指定の詳細仕様は [spot-selection.md](spot-selection.md) を参照。

## 詳細

- 入力項目と規則：
  - 旅行タイトル（必須・200文字まで）
  - スポット名（必須・200文字まで）
  - カテゴリ（必須・単一選択：グルメ／観光スポット／体験・アクティビティ／宿泊施設／イベント会場）
  - 日付（任意・投稿時点までの過去日のみ、未来日不可、JST固定）
  - 滞在時間（必須・単一選択：30分以内／1時間以内／2時間以内／3時間以内／それ以上）
  - 費用（任意・整数・円・1人あたり・0〜999,999、無料は0）
  - 星評価（必須・1〜5の整数）
  - 写真・動画（必須1点以上・枚数上限なし。写真は1点10MBまでJPEG/PNG、動画は1点100MBまでMP4・1分以内）
  - 感想（任意・4,000文字まで）
  - 公開設定（必須・単一選択：公開（デフォルト）／非公開）
- 文字数は書記素クラスタ単位でカウントする（絵文字・結合文字は1文字として扱う）。
- 投稿作成はログイン必須。作成頻度は1ユーザーにつき1時間20件までに制限する。
- 写真アップロードの処理フロー：ブラウザ→Route Handlers→sharpでEXIF位置情報除去・向き補正・縮小画像生成→Supabase Storageへ保存→URLをDBに記録。
- 動画アップロードの処理フロー（要件定義書v2.9）：Vercelの本文上限（4.5MB）のため、ブラウザ→署名付きURLでSupabase Storageへ直接アップロード→Route HandlersがStorage上のファイルをffmpegで検証・位置情報メタデータ除去・先頭フレーム抽出→処理済み動画で上書き・サムネイル保存→投稿作成時にパスをDBに記録。タスクは [video-upload](../../tasks/posts/video-upload/00-index.md) に分割。
- 費用は「1人あたり」の金額として保存し、検索・絞り込み時はレンジ判定（〜1,000円等）に利用する。

## 受入条件

- [ ] 必須項目を入力した投稿の作成ができ、費用が数値（1人あたり）で保存されること
- [ ] 写真アップロード時、EXIF位置情報が除去され、向きが正しい縮小画像が生成されること
- [ ] 動画（MP4またはMOV形式、100MBまで、1分以内）をアップロードでき、先頭フレームのサムネイルが自動生成されること
- [ ] 写真・動画をあわせて6点以上添付した投稿が正しく保存されること
- [ ] 1ユーザーにつき1時間20件を超える投稿作成が拒否されること
- [ ] 感想が4,000文字（書記素クラスタ単位）を超える場合は保存できないこと
- [ ] 公開設定のデフォルトが「公開」であること
