# F-PO-01 投稿作成

> 出典: [requirement.md](../../requirement.md) 3.3.1, 3.3.2, 3.3.6（v3.0）

## ユーザーストーリー

ログイン済みの利用者として、いまいる場所や訪れたスポットについての投稿を、地図で位置を決めながら 1 画面で作成したい。なぜなら、旅先で見つけた場所をその場で残し、次に来る人の参考にしたいから。

> v1 で実装済みの投稿フォーム（`PostForm`）と写真アップロードはそのまま使う。本ストーリーで変えるのは「上 1/3 に地図が付く」「配置を詰める」「カテゴリ 7 つ・日付必須・MOV 対応」の 3 点。旅行タイトルの詳細は [trip-title.md](trip-title.md)、位置とスポットの決め方は [spot-selection.md](spot-selection.md)、下書きは [draft.md](draft.md)、入口は [post-entry-points.md](post-entry-points.md) を参照。

## 詳細

- 画面構成（SC-03）：上 1/3 が地図（中央固定ピン）、下 2/3 がフォーム。下部に「投稿する」「下書きに保存」を固定表示する。フォームを上に引くと全画面（地図は隠れる）、下に引くと 1：2 に戻る。パソコン幅では地図とフォームを左右 1：2 に並べる。
- 入力項目と規則（項目・順序・必須条件は v1 と同じ。変更点は太字）：
  - 旅行タイトル（必須・200文字まで。ラベルと入力欄を横並び）
  - スポット名（必須・200文字まで。地図の位置で自動的に埋まる。ラベルと入力欄を横並び）
  - カテゴリ（必須・**ドロップダウン**・**7 つ：グルメ／観光スポット／自然・景勝地／体験・アクティビティ／エンタメ・イベント／ショッピング／宿泊施設**）
  - 日付（**必須・初期値は今日**。しおりから開いた場合はその Day の日付。未来日不可、JST固定）
  - 滞在時間（必須・**ドロップダウン**：30分以内／1時間以内／2時間以内／3時間以内／それ以上）
  - 費用（任意・整数・円・1人あたり・0〜999,999、無料は0）。日付／滞在時間、費用／星評価はそれぞれ 2 列に並べる
  - 星評価（必須・1〜5の整数）
  - 写真・動画（必須1点以上・枚数上限なし。写真は1点10MBまでJPEG/PNG、動画は1点100MBまで **MP4 または MOV**・1分以内。**選んだ写真・動画はその場にサムネイルで並び、× で外せる**）
  - 感想（任意・4,000文字まで。2 行から始めて入力で伸びる）
  - 公開設定（必須：公開（デフォルト）／非公開。感想のラベル行の右端に置く）
  - 位置（自動・必須：地図のピンの緯度経度。既存スポットを選んだ場合はそのスポットの座標）
  - 状態（自動：「投稿する」＝公開、「下書きに保存」＝下書き）
- 注意文（写り込み・個人情報）は 1 行に畳み、「詳しく」で全文を出す。
- 写真を 1〜3 点選んだ状態なら、下 2/3 の中でスクロールなしに全項目が見えること。
- 文字数は書記素クラスタ単位でカウントする。投稿作成はログイン必須。作成頻度は1ユーザーにつき1時間20件まで（下書きの保存は別枠）。
- MOV はサーバー側で ffmpeg により MP4 へ変換して保存する（変換の可否は要件定義書 9 章 #5・#8）。
- 既存の「イベント会場」カテゴリの投稿は「エンタメ・イベント」へ移行する（マイグレーション。[table-catalog](../data-model/table-catalog.md)）。

## 受入条件

- [ ] SC-03 が上 1/3 の地図と下 2/3 のフォームで構成され、下部に「投稿する」「下書きに保存」が固定表示されること
- [ ] カテゴリが 7 つのドロップダウンから選べ、既存の「イベント会場」の投稿が「エンタメ・イベント」として表示・絞り込みされること（受入条件67）
- [ ] 日付の初期値が今日で、必須として扱われること（受入条件7）
- [ ] 必須項目を入力した投稿の作成ができ、費用が数値（1人あたり）で保存され、位置がピンの座標で保存されること
- [ ] 選んだ写真・動画がその場にサムネイル表示され、× で外せること
- [ ] 動画（MP4・MOV、100MBまで、1分以内）をアップロードでき、先頭フレームのサムネイルが自動生成され、MOV が MP4 に変換されて保存されること（受入条件35）
- [ ] 写真を 1〜3 点選んだ状態で、フォーム部分をスクロールせずに全項目が見えること
- [ ] 1ユーザーにつき1時間20件を超える投稿作成が拒否されること
