# F-PO-01 投稿の起点

> 出典: [requirement.md](../../requirement.md) 3.3.8（v3.0で新設）

## ユーザーストーリー

ログイン済みの利用者として、検索トップ・地図・しおり・投稿詳細のどこからでも、位置やスポットが埋まった状態で投稿画面を開きたい。なぜなら、入口ごとに同じ入力を繰り返したくないから。

## 詳細

SC-03 へは次の入口から入る。メニューバーに「投稿」は置かない（[menu-bar](../shared-ui/menu-bar.md)）。URL は `/posts/new` にクエリで初期状態を渡す（`?lat=&lng=`、`?spot=`、`?itinerary=&spot=`、編集は `/posts/[id]/edit`）。

| 起点 | 地図の初期位置 | スポット名欄 | その他 |
|---|---|---|---|
| 検索トップ（SC-00）「いまいる場所に投稿する」 | 現在地（中央固定ピン） | 50m以内の登録済みスポット、無ければ「この場所（新しい場所）」 | 日付＝今日 |
| 地図（SC-02）「ここに投稿」 | 現在地 | 同上 | 同上 |
| 地図（SC-02）の長押しで立てたピンの「ここに投稿」 | 長押しした点 | 同上 | 同上 |
| 地図の既存ピンの吹き出し「投稿する」／スポット別一覧の「投稿する」／投稿詳細の「自分も投稿する」 | そのスポット（固定） | そのスポット | — |
| しおり（SC-23）のスポットの「投稿する」 | そのスポット（固定） | そのスポット | 旅行タイトル＝しおりの旅行、日付＝その Day の日付（未定・期間未設定なら今日） |
| 下書きの「続きを書く」 | 下書きの位置 | 保存していた内容 | 保存していた内容 |
| 自分の投稿の編集 | 投稿のスポット | 投稿のスポット | 「変更」→「新しい場所」で選び直せる |

- 「いまいる場所に投稿する」「ここに投稿」は地図画面を挟まず SC-03 を直接開く。地図に投稿専用のモードは設けない。
- 位置情報が拒否された場合は東京駅周辺で開き、地図を動かす案内を出す（[spot-selection](spot-selection.md)）。

## 受入条件

- [ ] 「いまいる場所に投稿する」を押すと、地図画面を挟まず現在地にピンが刺さった SC-03 が開くこと。位置情報を拒否すると東京駅周辺で開き、案内が表示されること（受入条件49）
- [ ] 地図で「ここに投稿」を押す、または長押しすると、その位置にピンが刺さった SC-03 が直接開くこと（受入条件48）
- [ ] 投稿詳細の「自分も投稿する」・既存ピンの「投稿する」でそのスポットが確定した SC-03 が開くこと（受入条件56）
- [ ] しおりのスポットの「投稿する」で、スポット・旅行タイトル・訪問日（その Day の日付）が入力済みの SC-03 が開くこと（受入条件63）
- [ ] 下書きの「続きを書く」で保存時の状態が復元されること
