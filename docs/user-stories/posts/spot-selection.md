# F-PO-01 スポット指定（検索・手動登録）

> 出典: [requirement.md](../../requirement.md) 3.3.5

## ユーザーストーリー

ログイン済みの利用者として、投稿作成時にスポットを検索して選択する、または候補が見つからない場合は地図上で手動登録したい。なぜなら、正確な位置情報を投稿に紐付けたいから。

## 詳細

**候補選択・手動登録の基本仕様**

- 自前のオートコンプリートUIで、Google Places APIの検索候補とSupabase上の手動登録スポットを統合して表示する。
- 表示順序は投稿数が多い順。Google由来・手動登録あわせて最大5件。
- 候補に該当がない場合、スポット名を手動入力し、地図上でピンを立てて位置（緯度経度）を指定する。
- ピンの初期位置は現在地とし、ユーザーが微調整する。
- 手動登録したスポットはSupabaseに保存され、以降は他ユーザーの検索候補にも表示される。
- 重複登録の防止：手動登録時、半径50m以内に既存スポットがある場合は新規登録を許可せず、既存スポットの選択を促す。

**スポット手動登録画面（SC-19）の仕様**

- 投稿作成画面（SC-03）でスポット候補に該当がなかった場合、「候補が見つかりません。地図でスポットを登録する」という導線からSC-19（モーダル）を開く。
- 地図の初期位置は現在地（SC-02の全体マップと同じGoogle Mapsコンポーネントを再利用）。
- 画面中央に固定されたピンに対して地図側をドラッグ・ピンチ操作し、ピンの指す位置を調整する（「中央固定ピン」方式）。
- 右上の現在地ボタンで、いつでも現在地に地図を戻せる。
- 「この位置でスポットを登録」を押すと、その時点の地図中心の緯度経度でスポットが登録され、投稿作成画面に戻る。この時点で重複登録防止ルール（半径50m以内チェック）を実行する。
- SC-19は独立した画面IDを持つが、SC-03から開くモーダルとして実装し、単体でのURLアクセスは想定しない。

## 受入条件

- [ ] Google Places候補からのスポット選択ができること
- [ ] 候補にないスポットの手動登録ができること
- [ ] スポット候補が見つからない場合、SC-19の地図上でピンを操作して新規スポットを登録できること
- [ ] 半径50m以内に既存スポットがある場合、登録が拒否され既存スポットの選択が促されること
- [ ] 手動登録したスポットが以降の他ユーザーの検索候補にも表示されること
