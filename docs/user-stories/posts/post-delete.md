# F-PO-03 投稿削除

> 出典: [requirement.md](../../requirement.md) 3.3.3

## ユーザーストーリー

投稿者本人として、自分の投稿を削除したい。なぜなら、不要になった投稿を整理したいから。

## 詳細

- 操作権限は投稿者本人のみ。共同アルバム内であっても、他ユーザーの投稿は削除できない（オーナーであっても同様）。
- 削除時の連動：紐づくコメント・いいね・写真・動画を同時に削除する。
- 削除時のアルバム：旅行（アルバム）自体は残存する。紐づく投稿が0件になった場合、アルバム一覧に表示しない。
- 削除時のバッジ：投稿数・いいね数が獲得条件を下回っても、獲得済みバッジは失われない。

## 受入条件

- [ ] 投稿者本人が投稿を削除できること（投稿者本人以外は削除できない）
- [ ] 削除に伴い、紐づくコメント・いいね・写真・動画が同時に削除されること
- [ ] 削除により紐づく投稿が0件になった旅行（アルバム）は、アルバム一覧に表示されなくなること
- [ ] 投稿削除により投稿数・いいね数が獲得条件を下回っても、獲得済みバッジは失われないこと
