# F-PO-02 投稿編集

> 出典: [requirement.md](../../requirement.md) 3.3.3

## ユーザーストーリー

投稿者本人として、自分の投稿を編集したい。なぜなら、内容の誤りを修正したり、後から写真・動画を追加したりしたいから。

## 詳細

- 編集可能項目：投稿の全項目（旅行タイトル・スポット名・カテゴリ・日付・滞在時間・費用・星評価・写真・動画・感想・公開設定）。
- 写真・動画は投稿編集画面で個別に削除・追加が可能。枚数上限はない。
- 編集しても投稿日時（新着順の基準）は更新しない。
- 操作権限は投稿者本人のみ。共同アルバム内であっても、他ユーザーの投稿は編集できない（オーナーであっても同様）。

## 受入条件

- [ ] 投稿の全項目を編集できること
- [ ] 写真・動画を個別に削除・追加でき、枚数上限がないこと
- [ ] 編集しても投稿日時（新着順の基準）が更新されないこと
- [ ] 投稿者本人以外は編集できない（共同アルバムのオーナーであっても他人の投稿は編集できない）こと
