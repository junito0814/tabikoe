# F-PO-04 下書き

> 出典: [requirement.md](../../requirement.md) 3.3.7, 5.3（v3.0で新設）

## ユーザーストーリー

ログイン済みの利用者として、旅先で時間がないときに位置だけでも下書きに残し、あとで続きを書いて投稿したい。なぜなら、その場で全項目を埋めるのは難しく、あとから思い出せなくなるから。

## 詳細

- 「下書きに保存」は必須項目が埋まっていなくても押せる（位置だけの下書きが成立する）。戻る・閉じるで SC-03 を離れた場合も、入力があれば自動で下書きに残す（確認は出さない）。
- 保持する内容：位置（緯度経度）、選択済みスポット（あれば）、入力途中の全項目、添付済みの写真・動画。
- 下書きは緯度経度だけを持ち、スポットは作らない（`posts.status = 'draft'`、`spot_id` は NULL 可、`lat`／`lng` に位置）。公開時にスポットを確定して `spot_id` を埋める。
- 公開範囲：本人にのみ表示する。他ユーザーの地図・一覧・検索・写真切替・API 応答には一切含めない。RLS でも本人以外の参照を禁止する。
- 表示場所：自分の地図（SC-02・SC-12）に灰色の破線ピン、マイページ（SC-06）の先頭に「下書き N 件」の一覧（[my-page](../records/my-page.md)）。
- 続きを書く：破線ピンまたはマイページの一覧から SC-03 を保存時の状態で開く。
- 投稿：下書きから「投稿する」と通常の投稿になり、投稿日時（`published_at`）はその時点。バッジ判定・通知・しおりの自動チェックはこの時点で行う。
- 上限：1 ユーザーにつき 20 件。超える場合は保存を拒否し、既存の下書きの整理を促す。
- 削除：本人がマイページの一覧から削除できる。自動では消さない（30 日リマインドは要件定義書 9 章 #7、範囲外）。
- レート制限：下書きの保存は 1 ユーザーにつき 1 時間 60 件（自動保存を含む）。
- 投稿数バッジ・マイページの投稿数には下書きを含めない。

## 受入条件

- [ ] 必須項目が空のまま「下書きに保存」でき、途中で閉じても下書きが残り、自分の地図の破線ピンとマイページの先頭から続きを書けること（受入条件51）
- [ ] 下書きが他のユーザーの地図・一覧・検索・API 応答に一切含まれないこと。21 件目の下書き保存が拒否されること（受入条件52）
- [ ] 下書きを「投稿する」と通常の投稿になり、投稿日時がその時点になること（受入条件53）
- [ ] 下書きの時点ではスポットが作られず、公開時にスポットが確定すること
- [ ] 下書きがマイページの投稿数・投稿数バッジに数えられないこと
- [ ] 1 時間 60 件を超える下書き保存が拒否されること
