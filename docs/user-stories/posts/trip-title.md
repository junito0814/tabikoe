# F-PO-01 旅行タイトルによる投稿のグルーピング

> 出典: [requirement.md](../../requirement.md) 3.3.4（v3.0）

## ユーザーストーリー

ログイン済みの利用者として、投稿作成時に旅行タイトルを指定し、同じ旅行の投稿をひとつにまとめて管理したい。なぜなら、旅行ごとに投稿を振り返れるアルバムとして扱いたいから。

## 詳細

- 旅行は「旅行ID」で管理し、1つの旅行IDに1つの旅行タイトル（表示名）が紐づく。
- 投稿作成時、当該ユーザーが過去に作成した旅行タイトルと、参加中のアルバム・しおりの旅行タイトルをオートコンプリート候補として表示する。
- 候補から選択した場合は既存の旅行IDに投稿を追加し、候補にない名称を入力した場合は新しい旅行IDを採番して作成する。
- 一致判定は前後の空白を除去（トリム）した上での完全一致とする。
- 旅行タイトルの一意性は同一ユーザー内でのみ有効（他ユーザーとは独立して管理）。
- オーナーが旅行タイトルを変更できる。変更すると、その旅行IDに紐づく全投稿の表示名と、同じ旅行のしおり（[itinerary-basics](../itinerary/itinerary-basics.md)）に反映される。
- **仮タイトル（v3.0）**：旅行タイトルが空のまま投稿・下書き保存した場合、「今日の投稿（9/16）」のような仮タイトルで旅行を自動作成する。同日の 2 件目以降は同じ旅行に入る。マイページでは仮タイトルのままの投稿に付け直しを促す。
- **しおりとの関係（v3.0）**：しおりは旅行 ID と 1 対 1。しおりから投稿した場合、旅行タイトルはしおりの旅行が入力済みになる。
- 表示範囲は以下の2箇所のみ：本人のマイページ投稿一覧（SC-06）、アルバム画面（SC-09、アルバムの名称として）。投稿一覧（SC-04）・投稿詳細（SC-05）・他ユーザーのプロフィール画面には表示しない。

## 受入条件

- [ ] 過去に作成した旅行タイトルがオートコンプリート候補として表示されること
- [ ] 候補にない名称を入力すると新しい旅行として作成されること
- [ ] 前後の空白を除去した完全一致で既存旅行と判定されること
- [ ] 旅行タイトルは同一ユーザー内でのみ一意に管理されること
- [ ] オーナーが旅行タイトルを変更すると、紐づく全投稿の表示名に反映されること
- [ ] マイページの投稿一覧に旅行タイトルが表示され、それ以外の画面（投稿一覧・投稿詳細・他ユーザープロフィール）には表示されないこと
- [ ] 旅行タイトルを空のまま投稿すると「今日の投稿（M/D）」の旅行が自動で作られ、同日の 2 件目が同じ旅行に入ること
- [ ] 参加中のアルバム・しおりの旅行タイトルが候補に出ること
