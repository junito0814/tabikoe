# F-RC-01 マイページ

> 出典: [requirement.md](../../requirement.md) 3.6.1（v3.0で変更）

## ユーザーストーリー

ログイン済みの利用者として、書きかけの下書きと自分の投稿・保存した場所を 1 つの画面から辿りたい。なぜなら、自分の手元にあるものはマイページに集まっていてほしいから。

> v1 で実装済みの `/mypage`（`my-page.ts`）を土台に、下書きの段と遷移メニューを変える。

## 詳細

画面構成は上から順に以下のとおり。

| 順序 | 表示内容 |
|---|---|
| 1 | プロフィール（アイコン画像・ユーザー名・プロフィール編集への導線） |
| 2 | 下書き（下書きがあるときだけ表示。「下書き N 件」と最新 3 件（スポット名または「名前のない場所」・保存日時・サムネイル）、「続きを書く」。[draft](../posts/draft.md)） |
| 3 | サマリー（投稿数・獲得いいね総数） |
| 4 | 遷移メニュー 4 つ（行きたい／アルバム／マイマップ／ステータスバッジ）。しおりへの導線はメニューバーに置き、ここには置かない |
| 5 | 自分の投稿一覧（新着順。非公開投稿を含む。旅行タイトルを表示し、旅行単位で絞り込み可。仮タイトルのままの投稿には付け直しを促す） |

- 投稿数は非公開投稿を含め、下書きは含めない件数とする。
- 「行きたい」は [wishlist](wishlist.md)（一覧／地図）へ、「マイマップ」は [my-map](my-map.md) へ遷移する。

## 受入条件

- [ ] マイページに、プロフィール・下書き（あるときだけ）・サマリー・遷移メニュー 4 つ・自分の投稿一覧がこの順で表示されること
- [ ] 下書きがあるとき先頭に「下書き N 件」と最新 3 件が表示され、「続きを書く」で SC-03 が開くこと（受入条件51）
- [ ] 投稿数に非公開投稿が含まれ、下書きが含まれないこと
- [ ] 仮タイトル「今日の投稿（M/D）」のままの投稿に付け直しを促す表示が出ること
- [ ] 遷移メニューから、行きたい・アルバム・マイマップ・ステータスバッジのそれぞれへ遷移でき、しおりへの導線が無いこと
