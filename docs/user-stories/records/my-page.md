# F-RC-01 マイページ

> 出典: [requirement.md](../../requirement.md) 3.6.1

## ユーザーストーリー

ログイン済みの利用者として、自分のこれまでの投稿や活動を1つの画面で振り返りたい。なぜなら、自分の旅の記録の全体像を把握し、アルバムやマイマップなど関連機能へすぐに移動したいから。

## 詳細

マイページ（SC-06）は、ログインユーザー自身のデータを振り返るためのハブ画面とする。画面構成は上から順に以下のとおり。

| 順序 | 表示内容 |
|---|---|
| 1 | プロフィール（アイコン画像・ユーザー名・プロフィール編集への導線） |
| 2 | サマリー（投稿数・獲得いいね総数） |
| 3 | 遷移メニュー（アルバム／マイマップ／「行きたい」スポット一覧／ステータスバッジ） |
| 4 | 自分の投稿一覧（新着順。非公開投稿も含む。旅行タイトルを表示し、旅行単位で絞り込み可） |

- 投稿数は非公開投稿を含めた件数とする。
- プロフィール（アイコン・ユーザー名）の表示元、および編集画面への導線は [profile-edit](../account/profile-edit.md)（F-AC-04）の成果物を利用する。
- 投稿一覧に表示する旅行タイトルの取得・絞り込みロジックは [trip-title](../posts/trip-title.md)（F-PO-01）の成果物を利用する。旅行タイトルをマイページに表示すること自体は trip-title の受入条件で既に検証されているため、本ストーリーでは投稿一覧の取得・絞り込みAPIを対象とする。
- 遷移メニューの「ステータスバッジ」は本カテゴリ外の別ストーリー（F-BG、`badges`カテゴリ）への導線であり、当該ストーリーの成果物ができ次第組み込む。

## 受入条件

- [ ] マイページに、プロフィール・サマリー（投稿数・獲得いいね総数）・遷移メニュー・自分の投稿一覧がこの順で表示されること
- [ ] 投稿数に非公開投稿が含まれること
- [ ] 自分の投稿一覧が新着順に表示され、旅行単位で絞り込みができること
- [ ] 遷移メニューから、アルバム・マイマップ・「行きたい」スポット一覧・ステータスバッジのそれぞれへ遷移できること
