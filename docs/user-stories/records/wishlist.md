# F-RC-05 保存先の 2 択と「行きたい」

> 出典: [requirement.md](../../requirement.md) 3.6.4（v3.0で変更）

## ユーザーストーリー

ログイン済みの利用者として、気になったスポットを「＋」一つで、まだ旅行が決まっていなければ「行きたい」に、決まっていればそのしおりの Day に入れたい。なぜなら、保存の仕方を考えずに集めておき、あとで旅程に組み込みたいから。

> v1 で実装済みの `wishlist` テーブル・保存 API・`/wishlist` を土台に、保存先シートと一覧／地図の切替、しおりへの振り分けを加える。

## 詳細

- 「＋」ボタンを投稿カード（SC-04）・投稿詳細（SC-05）・スポット別一覧の見出し・地図のピンの吹き出しに置く。押すと保存先を選ぶシートが 1 枚開く。
- 保存先シート：上段に「行きたいスポット」（件数付き）、下段に自分がオーナーまたはメンバーのしおり（更新が新しい順）と「＋ 新しいしおりを作る」（[itinerary-basics](../itinerary/itinerary-basics.md)）。チェックを付ける／外すだけで保存・削除が確定し、両方に入れてもよい。しおりにチェックすると、そのしおりに期間があれば Day の選択（Day 1／…／未定）が展開する（省略時は未定）。閉じると「〈しおり名〉に保存しました [しおりを見る]」のトースト。
- 追加モード中（[add-spots](../itinerary/add-spots.md)）はシートを出さず、「＋」でそのしおりの開いていた Day に直接入る。
- 保存単位はスポット。投稿の有無を問わず、Google Places API由来のスポットも保存できる。
- 行きたいスポットは 1 ユーザーに 1 つで、名前の変更・削除はできない。
- 一覧画面（SC-08）：マイページの「行きたい」から開く。一覧／地図の切替を持つ。一覧はスポット単位で、スポット名・代表写真（投稿が無ければプレースホルダ）・都道府県・投稿件数を表示し、押すとスポット別の投稿一覧へ。地図は SC-02 と同じ地図に行きたいスポットの赤ピンだけを出す。
- しおりへ振り分け：SC-08 の各スポット（地図では吹き出し）の「＋」で、しおりと Day を選ぶシートを開いて追加する。追加しても行きたいスポットからは消えない。不要になったら「解除」。
- SC-02・SC-12 では「保存済み」の赤ピンとして表示する（[pin-display-rules](../shared-ui/pin-display-rules.md)）。

## 受入条件

- [ ] 「＋」から行きたいスポット／しおりの保存先シートが開き、チェックだけで保存・解除が確定すること。しおりに期間があれば Day を選べること（受入条件13）
- [ ] 同じスポットを行きたいとしおりの両方に入れられること
- [ ] マイページの「行きたい」で一覧／地図を切り替えられ、各スポットの「＋」でしおりと Day を選んで追加でき、追加しても行きたいから消えないこと（受入条件66）
- [ ] 投稿がないスポットにはプレースホルダ画像が表示され、Google Places API由来のスポットも保存できること
- [ ] 追加モード中は保存先シートが出ず、「＋」で直接しおりに入ること（受入条件61）
