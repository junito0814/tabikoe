# F-RC-02 アルバム写真一覧（album-photos）

> 出典: [requirement.md](../../requirement.md) 3.6.2「写真・動画一覧」（v2.11で追加）、4.5.5

## ユーザーストーリー

アルバムのメンバーとして、アルバム内の投稿に添付された写真・動画だけをまとめて見たい。地図でスポットを選んで「写真」を押したときと同じ見え方で、旅行の写真をさっと見返したいから。

## 詳細

- アルバム画面（SC-09）の「写真」タグから、アルバム写真一覧画面（SC-21、`/albums/[id]/photos`）へ遷移する。
- 当該旅行に紐づく全投稿の写真・動画を、投稿をまたいで投稿日時の新しい順（同一投稿内は添付順）に、正方形サムネイルのグリッドで表示する。動画には再生アイコンを重ねる。40点ずつ追加読み込みする。
- メンバー限定の画面のため、3.6.3 に従い公開・非公開を問わず含める。管理者が非公開化した投稿・写真は含めない。アルバム内ではブロック関係による除外を行わない（3.8.2 の例外）。
- メンバー以外が URL で直接アクセスした場合は 404（存在自体を伏せる）。
- タップすると 4.5.5 のモーダルで表示し、読み込み済みの一覧全体を ←→ で移動できる。モーダル内の「この投稿を見る」で投稿詳細（SC-05）へ遷移する。
- 画面本体はスポット写真一覧（SC-13）と共通のコンポーネントを使い、見出し・戻り先・取得元だけを変える。

## 受入条件

- [ ] アルバム画面の「写真」から、そのアルバムの全投稿（非公開投稿を含む）の写真・動画が新着順のグリッドで一覧表示されること（8章 受入条件45）
- [ ] タップでモーダル表示され、←→で一覧全体を移動でき、「この投稿を見る」で投稿詳細へ遷移できること
- [ ] メンバー以外は 404 になること
- [ ] 管理者が非公開化した投稿・写真が含まれないこと
