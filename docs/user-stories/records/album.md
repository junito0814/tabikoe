# F-RC-02 アルバム

> 出典: [requirement.md](../../requirement.md) 3.6.2（v3.0で導線を追加）

## ユーザーストーリー

ログイン済みの利用者として、同じ旅行の投稿をアルバムとしてまとめて見返したい。なぜなら、旅行単位で写真や記録を振り返りたいから。

## 詳細

| 項目 | 内容 |
|---|---|
| グルーピング単位 | 旅行ID |
| 表示内容 | 当該旅行に紐づく投稿・写真・動画、および[album-collaboration](album-collaboration.md)（F-RC-03）で定義するメンバー一覧 |
| 投稿0件時 | アルバム一覧に表示しない（アルバムを明示的に削除する操作は設けない） |
| アルバム名変更 | 旅行タイトルの変更として実現する。オーナーのみ操作可 |
| 投稿の移動 | 投稿編集画面で旅行タイトルを変更することで実現する。ただし移動先の旅行のオーナー・メンバーである場合に限る |

- 旅行（`trips`）テーブル・旅行IDの採番・旅行タイトルの一意性管理は [trip-title](../posts/trip-title.md)（F-PO-01）で実装済み。アルバム名変更は trip-title の旅行タイトル変更 Route Handler をそのまま利用する。
- 投稿が0件になった旅行をアルバム一覧から除外するロジックは、投稿削除（[post-delete](../posts/post-delete.md)、F-PO-03）側で実装済み（`HAVING COUNT(posts) > 0`相当の条件）。本ストーリーのアルバム一覧取得はこの条件をそのまま利用する。
- アルバムのメンバー・権限（オーナー／編集者／閲覧者）および招待の仕組みは [album-collaboration](album-collaboration.md)（F-RC-03）を参照。
- アルバムのメンバーは、投稿の公開／非公開設定にかかわらずアルバム内では全投稿を閲覧できる（詳細は album-collaboration 参照）。
- 投稿・写真・動画の表示レイアウトは [media-layout](../shared-ui/media-layout.md) の`MediaGrid`コンポーネントを再利用する。
- **しおりとの導線（v3.0）**：同じ旅行 ID のしおりがあり、自分がそのメンバーのとき、アルバム画面に「しおりを見る」を出す（[itinerary-basics](../itinerary/itinerary-basics.md)）。しおりのメンバーでなければ出さない。

## 受入条件

- [ ] アルバム画面に、当該旅行の投稿・写真・動画・メンバー一覧が表示されること
- [ ] 投稿が0件の旅行はアルバム一覧に表示されないこと
- [ ] オーナーがアルバム名（旅行タイトル）を変更すると、紐づく全投稿の表示名に反映されること
- [ ] オーナー以外のユーザーはアルバム名を変更できないこと
- [ ] 投稿編集画面で旅行タイトルを変更すると、移動先の旅行のオーナー・メンバーである場合に限り投稿が移動すること
