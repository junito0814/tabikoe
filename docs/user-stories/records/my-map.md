# F-RC-06 マイマップ

> 出典: [requirement.md](../../requirement.md) 3.6.5

## ユーザーストーリー

ログイン済みの利用者として、自分が投稿したスポットと「行きたい」保存したスポットを地図上で見返したい。なぜなら、自分の旅の軌跡と今後行きたい場所を1つの地図で把握したいから。

## 詳細

| 項目 | 内容 |
|---|---|
| 概要 | 自分の投稿があるスポットと「行きたい」保存したスポットを、地図上に区別して表示する |
| 表示切り替え | 自分の投稿のみ／「行きたい」スポットのみ／両方（デフォルト）から選択する |
| 表示対象 | ログインユーザー自身の投稿があるスポット（非公開投稿を含む）、および「行きたい」保存したスポット |
| ピンの区別 | 投稿済みと「行きたい」を、色および形状・アイコンの両方で区別する。色のみに依存しない |
| 両方に該当する場合 | 投稿がある場合は「投稿済み」として表示する（「行きたい」登録は保持される） |
| ピン操作 | 投稿済みピンは自分の投稿詳細（SC-05）へ、「行きたい」ピンは投稿カード一覧画面（SC-04）へ遷移する |
| 読み込み件数 | 表示中の地図範囲内のピンを最大100件まで読み込む |
| 遷移元 | マイページ |
| 実装方針 | SC-02（全体マップ）のマップ機能を共通部品として再利用し、取得条件のみを変更する |

- ピンの視覚的区別（アイコン・色定義、地図コンポーネントへの組み込みインターフェース）は [pin-display-rules](../shared-ui/pin-display-rules.md) で定義済み。本ストーリーはこのインターフェースを利用する側。
- 地図の基本コンポーネント（ズーム・パン等）は `map-search`カテゴリの地図表示（F-MP-01）の成果物を再利用する。
- 「行きたい」保存データは [wishlist](wishlist.md)（F-RC-05）を参照する。
- ピン操作時の遷移先（投稿詳細・投稿カード一覧）は、それぞれ `browsing`カテゴリの投稿詳細閲覧（F-VW-01）、`map-search`カテゴリのピン操作（F-MP-03）の画面。

## 受入条件

- [ ] マイマップで、自分の投稿のみ／「行きたい」のみ／両方の表示切り替えができること
- [ ] 非公開投稿があるスポットも、自分のマイマップには表示されること
- [ ] 投稿済みピンと「行きたい」ピンが色・形状の両方で区別されること
- [ ] 投稿とお気に入りの両方に該当するスポットは「投稿済み」ピンとして表示されること
- [ ] 投稿済みピンをタップすると自分の投稿詳細へ、「行きたい」ピンをタップすると投稿カード一覧へ遷移すること
- [ ] 表示中の地図範囲内のピンが最大100件まで読み込まれること
