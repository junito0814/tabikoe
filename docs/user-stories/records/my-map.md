# F-RC-06 マイマップ

> 出典: [requirement.md](../../requirement.md) 3.6.5（v3.0で変更）

## ユーザーストーリー

ログイン済みの利用者として、自分が投稿したスポット・書きかけの下書き・保存した場所を地図上で見返したい。なぜなら、自分の旅の軌跡と今後行きたい場所を 1 つの地図で把握したいから。

> v1 で実装済みの `/mymap`（`MyMapScreen`、`get-my-map-pins.ts`）を土台に、下書きとしおりのスポットを加える。

## 詳細

| 項目 | 内容 |
|---|---|
| 概要 | 自分の投稿があるスポット、下書き、保存済み（行きたい・しおり）のスポットを、地図上に区別して表示する |
| 表示切り替え | 自分の投稿のみ／保存済みのみ／両方（デフォルト）。下書きは常に表示する |
| 表示対象 | 自分の投稿があるスポット（非公開を含む）、自分の下書き、行きたいスポット、自分がオーナーまたはメンバーのしおりのスポット |
| ピンの区別 | [pin-display-rules](../shared-ui/pin-display-rules.md)。投稿済みと保存済みの両方に該当する場合は投稿済み |
| ピン操作 | 投稿済み→自分の投稿詳細（SC-05）、保存済み→投稿一覧（SC-04）、下書き→SC-03（続きを書く） |
| 読み込み件数 | 表示中の地図範囲内のピンを最大100件 |
| 遷移元 | マイページ |

## 受入条件

- [ ] マイマップで、自分の投稿のみ／保存済みのみ／両方の切り替えが動作し、下書きが常に破線ピンで表示されること（受入条件14）
- [ ] しおりに入れたスポットが保存済みピンとして表示されること
- [ ] 投稿済みと保存済みの両方に該当するスポットが投稿済みピンとして表示されること
- [ ] 投稿済み・保存済み・下書きの各ピンから規定の画面へ遷移すること
