# F-RC-03 アルバムの共同編集・招待

> 出典: [requirement.md](../../requirement.md) 3.6.3

## ユーザーストーリー

アルバムのオーナーとして、旅行の同行者を招待し、一緒にアルバムへ投稿を追加してもらいたい。なぜなら、旅の記録を同行者と共同で作り上げたいから。

## 詳細

**権限の種類**

| 権限 | できること |
|---|---|
| オーナー | アルバムの作成者。旅行タイトルの変更、招待リンクの発行・無効化、メンバーの権限変更・削除ができる。自分の投稿の追加・編集・削除ができる（他人の投稿は削除できない） |
| 編集者 | そのアルバムに自分の投稿を追加できる。自分の投稿のみ編集・削除できる |
| 閲覧者 | 投稿・写真・メンバー一覧の閲覧のみ可能 |

投稿者本人以外は他人の投稿を編集・削除できないというルール自体は、[post-edit](../posts/post-edit.md)・[post-delete](../posts/post-delete.md)（F-PO-02・F-PO-03）で既に「投稿者本人のみ」として実装済みであり、アルバム内でも特別な緩和は行わない（オーナーであっても他人の投稿は削除できない）。本ストーリーが新たに扱うのは、招待によるメンバー参加とアルバム内での可視性のみである。

**アルバム内での公開設定の扱い**

アルバムのメンバー（オーナー・編集者・閲覧者）は、そのアルバムに含まれる投稿について、投稿者が設定した公開／非公開の別にかかわらず、全ての投稿を閲覧できる。「非公開」は、アルバムに属さない第三者から隠すためのものであり、アルバムメンバー間の可視性を制限するものではない。

**招待の仕組み**

| 項目 | 内容 |
|---|---|
| 招待方法 | オーナーが招待リンクを発行する。発行時に付与する権限（編集者／閲覧者）を選択する |
| 有効期限 | 招待リンクの有効期限は7日間。オーナーはいつでも手動で無効化できる |
| 招待の受諾 | リンクを開いたユーザーがログインすると、指定された権限でアルバムのメンバーに加わる |
| メンバー管理 | オーナーは、参加中のメンバーの権限変更、およびメンバーの削除（アルバムからの除外）ができる |
| メンバーからの退出 | 編集者・閲覧者は、自分の意思でアルバムから退出できる。退出後もそれまでの自分の投稿はアルバムに残る |
| アルバムの終了 | オーナーによる明示的な「アルバム削除」操作は設けない。紐づく投稿が0件になった時点でアルバム一覧から自動的に表示されなくなる（[post-delete](../posts/post-delete.md)で実装済み） |

- オーナーが退会した場合の新オーナー自動選出（オーナー継承ルール）は、退会処理の一部として [account-deletion](../account/account-deletion.md)（F-AC-05）で既に実装済み。本ストーリーでは扱わない。
- 招待受諾・権限変更・メンバー削除の発生時にアプリ内通知を送る仕組みは、[notification-triggers](../notifications/notification-triggers.md)（F-NT-01、`notifications`カテゴリ）の共通通知作成関数を利用する。

## 受入条件

- [ ] オーナーが招待リンク（付与権限を選択可）を発行できること
- [ ] リンクを開いたユーザーがログインすると、指定された権限でアルバムのメンバーになれること
- [ ] 招待リンクが発行から7日で無効になること。オーナーはいつでも手動で無効化できること
- [ ] 編集者は自分の投稿のみ編集・削除でき、他メンバーの投稿は編集・削除できないこと
- [ ] オーナーがメンバーの権限変更・削除を行えること
- [ ] 編集者・閲覧者が自分の意思でアルバムから退出でき、退出後もそれまでの自分の投稿はアルバムに残ること
- [ ] アルバムメンバーは、投稿の公開／非公開にかかわらずアルバム内の全投稿を閲覧できること
