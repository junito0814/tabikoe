# ソースコードのフォルダ構成

`src/` のどのフォルダが何を担当しているかの一覧です。**フォルダ単位**でまとめています（ファイルは 600 以上あり、1 つずつ書くとすぐ古くなるため）。

機能の仕様から探すときは [README.md](README.md) →  `user-stories/` → `tasks/` の順にたどってください。各ソースファイルの冒頭には、どのタスク文書に対応するかの「出典」コメントが入っています。

## 3 つの層

| 層 | 置くもの | 置かないもの |
|---|---|---|
| `app/` | URL に対応する画面（`page.tsx`）と API（`route.ts`） | 見た目の作り込み・判断のロジック |
| `components/` | 画面の部品（見た目と操作） | DB への問い合わせ・外部 API の呼び出し |
| `lib/` | 判断・データの取得・外部サービスとのやり取り | 画面（JSX） |

判断（ルール）は `lib/` の**純粋関数**に切り出す方針です（AGENTS.md 13）。画面やデータの取り方が変わっても、そこだけテストすれば済むようにするためです。

## 全体

```
src/
├── proxy.ts                  全リクエストが最初に通る関所。セッションの検証と更新、30 日失効、
│                             停止中・登録待ち・再同意待ちの締め出し、/admin を管理者以外に見せない（404）、
│                             管理画面は二段階確認（aal2）と 60 分の期限も見る（Phase 18）
├── app/                      画面と API。フォルダ構成がそのまま URL になる
├── components/               画面の部品
└── lib/                      判断・データの取得・外部サービス
```

## app/ — 画面と API

```
app/
├── layout.tsx                全画面の外枠。メニューバーを 1 回だけ描く
├── page.tsx                  ホーム＝検索トップ（SC-00）。未ログインならログイン画面を出す
├── globals.css               配色（CSS 変数）とダークモード
├── fonts.ts / icon.svg / apple-icon.png   フォントとアプリのアイコン
│
├── login/                    ログイン（SC-01）
├── signup/                   同意・アカウント新規作成（SC-20）
├── consent/renew/            規約の再同意（SC-30）
├── terms/ · privacy/         利用規約・個人情報保護方針の本文（SC-31）
│
├── search/                   投稿一覧・検索結果（SC-04）
├── map/                      地図（SC-02。探すモード・スポット中心・しおり表示）
├── posts/new/ · posts/[id]/  投稿の作成と編集（SC-03）、投稿詳細（SC-05）
├── spots/[id]/               スポット別の投稿一覧・写真・スポットの修正（SC-29）
├── itineraries/              しおり一覧・詳細（SC-22・SC-23）
├── albums/                   アルバムとアルバム写真一覧（SC-09・SC-21）
├── wishlist/                 行きたい（SC-08）
├── mymap/                    あしあと（SC-12）
├── mypage/                   マイページ（SC-06）と下書き一覧
├── account/                  プロフィール編集（SC-07）・アカウントの状態（SC-28）
├── notifications/            通知一覧（SC-14）
├── badges/                   バッジ（SC-10）
├── report/                   通報フォーム
├── users/[id]/               ほかの利用者のページ
├── invitations/[token]/      アルバムの招待リンクの受諾
├── itinerary-invitations/    しおりの招待リンクの受諾
├── admin/                    管理画面（SC-15〜18・SC-24〜27）。左メニューの枠もここ
│   └── mfa/                  管理者の二段階確認（SC-32。QR で登録・6 桁で確認。Phase 18）
├── dev/                      開発用のプレビュー。本番の画面からは行けない
│
└── api/                      Route Handlers（ブラウザから呼ぶ API）
    ├── auth/                 ログイン・ログアウト・新規登録・コールバック
    ├── posts/                投稿の作成・編集・削除、写真、コメント、いいね、近くの投稿、検索
    ├── spots/                スポットの候補検索・位置からの解決・修正、「まだあった」報告
    ├── itineraries/          しおりの作成・Day・スポット・チェック・招待
    ├── trips/                アルバム（旅行）とメンバー
    ├── users/                自分の情報・投稿・下書き・あしあと・アカウントの状態、利用者検索
    ├── wishlist/             「行きたい」の保存と解除
    ├── notifications/        通知一覧と未読件数
    ├── reports/              通報の受付
    ├── blocks/               ブロック
    ├── badges/               バッジ
    ├── invitations/ · invitation-responses/ · itinerary-invitations/   招待の発行・受諾・辞退
    ├── legal/                規約の本文と同意の記録
    ├── geocode/              地名の候補と座標化（Google を経由して呼ぶ）
    ├── health-db/            DB の疎通確認
    └── admin/                管理者だけが呼ぶ API（通報対応・利用者・非公開の復元・規約・操作の記録）
```

## components/ — 画面の部品

```
components/
├── layout/       共通メニューバー、上 1/3 地図＋下 2/3 シートの枠、シートの指の操作
├── search/       検索トップ（SC-00）と行き先の入力欄
├── posts/        投稿画面（SC-03）・投稿詳細（SC-05）・投稿カード・絞り込み・削除
├── map/          地図本体（Google Maps の共通部品）・地図画面・あしあと・見るだけの地図・凡例
├── pins/         ピンの絵と色の決め方（画面用と地図マーカー用で 1 つの定義を共有）
├── spots/        スポットの候補入力・手動登録・スポットの修正（SC-29）・「まだあった」
├── itineraries/  しおり詳細・Day タブ・時刻・並べ替え・招待
├── albums/       アルバム・アルバム写真一覧・招待の受諾
├── save/         保存先の 2 択（行きたい／しおり）のシートとボタン
├── wishlist/     「行きたい」の一覧とボタン
├── mypage/       マイページ・下書きの段・自分の投稿一覧・遷移メニュー
├── account/      アカウントの状態（SC-28）
├── auth/         ログイン画面・同意画面・同意のチェック欄
├── legal/        規約の本文（SC-31）と再同意（SC-30）
├── admin/        管理画面すべて（枠・ダッシュボード・通報・利用者・非公開・規約・操作の記録・二段階確認）
├── comments/     コメント欄（返信つき）
├── likes/        いいねボタン
├── reports/      通報フォームと通報への導線
├── blocks/       ブロックのボタンと一覧
├── invitations/  アプリ内招待の相手選び
├── notifications/ 通知一覧
├── badges/       バッジ一覧と獲得トースト
├── media/        写真・動画の並べ方、拡大モーダル、選択中のサムネイル
├── notices/      エラー表示・フラッシュ・投稿時の注意喚起
├── ui/           汎用の部品（シート・時刻ピッカー・トースト）
├── skeleton/     読み込み中の骨組み
├── brand/        ロゴ
└── trips/        アルバム名の入力欄
```

## lib/ — 判断・データの取得・外部サービス

```
lib/
├── auth/         ログイン状態の読み取り、同意、登録待ち・再同意の判定、最終利用日、遷移先の決定
├── supabase/     DB クライアント（ブラウザ用・サーバー用・service_role 用）と環境変数の確認
├── posts/        投稿の入力規則・下書き・投稿カード・検索・写真・公開時の処理
├── spots/        スポットの検索・位置からの解決・確定・状態の報告
├── search/       検索トップの候補・行き先の解決・一覧の読み込みと表示状態
├── map/          地図のピンの取得、地図の状態の保存と復元、戻り先の名前、スポットのカテゴリ
├── itineraries/  しおりの取得・Day の計算・追加モード・自動チェック・招待・権限
├── trips/        アルバム（旅行）の解決と「日常」アルバム
├── albums/       アルバムの取得・写真・メンバー・招待
├── wishlist/     「行きたい」の取得と表示用の整形
├── comments/     コメントの入力規則と取得（返信つき）
├── likes/        いいね
├── badges/       バッジのカタログと判定
├── notifications/ 通知の種類・作成・一覧・管理者への通知
├── reports/      通報の入力規則と対象の確認
├── blocks/       ブロック中の利用者
├── invitations/  アプリ内招待
├── moderation/   ストライクのルール・自動非公開・仮停止・投稿禁止・アカウントの状態・スポット修正依頼
├── admin/        管理画面のデータ（ダッシュボード・通報・利用者・非公開・操作の記録）と二段階確認の判定
├── legal/        規約の本文・版・同意の記録・管理画面用の操作・Markdown の読み取り
├── announcements/ お知らせの入力規則
├── users/        利用者の情報・マイページの集計・利用者検索・退会の後始末
├── geo/          都道府県リスト・移動手段と所要時間・現在地の取得
├── google/       Google の API（地名検索・場所・経路）とその結果の使い回し
├── image/ · video/ 写真の縮小と動画の取り扱い
├── rate-limit/   レート制限
├── logs/         操作ログ（要件 7.5）
├── api/          ブラウザから API を呼ぶ共通処理（401 の行き先の出し分け）
├── http/         リクエスト元の IP
└── text/         文字数の数え方（絵文字を 1 文字として数える）
```

## 更新のしかた
